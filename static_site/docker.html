📚 Estrutura do Curso

7 Módulos + 2 Labs Práticos

Siga os módulos na ordem. Execute todos os comandos no seu terminal. Ao final, realize os laboratórios práticos.

Módulo 01Iniciante

Conceitos Fundamentais e Instalação

O que é Docker, conceitos-chave (imagem, container, Dockerfile, registry), instalação e primeiros comandos essenciais.
Módulo 02Iniciante/Intermediário

Imagens e Dockerfile

Gerenciar imagens, construir imagens customizadas com Dockerfile, instruções, build, .dockerignore e boas práticas.
Módulo 03Intermediário

Volumes e Persistência de Dados

Volumes nomeados, bind mounts, tmpfs, backup/restauração e transferência de dados entre host e container.
Módulo 04Intermediário

Redes no Docker

Drivers de rede (bridge, host, none, overlay), comunicação entre containers, DNS interno, portas e aliases.
Módulo 05Intermediário/Avançado

Docker Compose

Aplicações multi-container, docker-compose.yml, comandos, healthcheck, profiles, variáveis de ambiente e scaling.
Módulo 06Avançado

Otimização, Segurança e Boas Práticas

Multi-stage build, cache de camadas, segurança (usuário não-root, scan de vulnerabilidades), monitoramento e limites de recursos.
Módulo 07Avançado

Docker em Produção e CI/CD

Registry privado, estratégias de tagging, GitHub Actions, GitLab CI, Docker Swarm, troubleshooting e manutenção.
Pré-requisitos: Computador com Windows 10+, macOS ou Linux. Acesso à internet. Vontade de aprender!
