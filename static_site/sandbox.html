Como funciona

Por que roda sem instalar nada?

🧩 Pyodide (WebAssembly)

O CPython foi compilado para WebAssembly, um formato que o navegador executa nativamente. Você tem Python real — não uma simulação — direto no browser.

💰 Custo zero

Como tudo roda no seu dispositivo, não há servidores nem cobrança. O sandbox escala para qualquer número de alunos sem gerar custo de infraestrutura.

🔒 Seguro e isolado

O código roda numa caixa de areia (sandbox) do navegador, sem acesso ao seu sistema de arquivos ou à internet. Experimente sem riscos.
