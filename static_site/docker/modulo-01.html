🐳 Docker — Módulo 01

Conceitos Fundamentais e Instalação

Entenda o que é Docker, por que ele revolucionou o desenvolvimento de software, instale no seu sistema e execute seus primeiros containers.

O que é Docker?

Docker é uma plataforma de containerização que permite empacotar aplicações e suas dependências em unidades padronizadas chamadas containers. Diferente de máquinas virtuais, containers compartilham o kernel do sistema operacional host, tornando-os extremamente leves e rápidos.

Por que Docker importa?

ConsistênciaDev → Prod

"Funciona na minha máquina" deixa de ser problema. O container é idêntico em qualquer ambiente.

IsolamentoSegurança

Cada container tem seu próprio filesystem, rede e processos isolados do host e de outros containers.

VelocidadePerformance

Containers iniciam em segundos (vs minutos de uma VM). Ideal para CI/CD e microserviços.

PortabilidadeMulti-cloud

Execute em qualquer lugar: laptop, servidor on-premises, AWS, Azure, GCP — sem alterações.

Conceitos-chave

ConceitoDescrição
ImagemTemplate somente-leitura com o sistema de arquivos e configurações. É o "blueprint" do container.
ContainerInstância em execução de uma imagem. Possui estado próprio e pode ser iniciado, parado e removido.
DockerfileArquivo de texto com instruções para construir uma imagem customizada passo a passo.
RegistryRepositório de imagens (Docker Hub, ECR, GCR). Permite compartilhar e versionar imagens.
VolumeMecanismo para persistir dados além do ciclo de vida do container.
NetworkRede virtual que permite comunicação entre containers e com o mundo externo.

Instalação do Docker

Linux (Ubuntu/Debian)

Remover versões antigasLimpeza
sudo apt-get remove docker docker-engine docker.io containerd runc
Instalar dependênciasPré-requisitos
sudo apt-get update
sudo apt-get install -y \
  ca-certificates \
  curl \
  gnupg \
  lsb-release
Adicionar chave GPG oficialRepositório
sudo mkdir -p /etc/apt/keyrings
curl -fsSL https://download.docker.com/linux/ubuntu/gpg | \
  sudo gpg --dearmor -o /etc/apt/keyrings/docker.gpg
Adicionar repositório DockerAPT
echo \
  "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.gpg] \
  https://download.docker.com/linux/ubuntu \
  $(lsb_release -cs) stable" | \
  sudo tee /etc/apt/sources.list.d/docker.list > /dev/null
Instalar Docker EngineInstalação
sudo apt-get update
sudo apt-get install -y docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
Pós-instalação (sem sudo)Permissões
sudo usermod -aG docker $USER
newgrp docker

Windows

Baixe e instale o Docker Desktop for Windows em docker.com. Requisitos: Windows 10/11 64-bit com WSL 2 habilitado ou Hyper-V.

macOS

Baixe e instale o Docker Desktop for Mac em docker.com. Disponível para chips Intel e Apple Silicon (M1/M2/M3).

Primeiros Comandos Essenciais

docker run — Criar e executar containers

docker runBásico

Cria e inicia um container a partir de uma imagem.

# Execução simples
docker run nginx

# Modo interativo com terminal
docker run -it ubuntu bash

# Modo detached (background)
docker run -d nginx

# Mapear porta host:container
docker run -d -p 8080:80 nginx

# Nomear o container
docker run -d --name meu-nginx -p 8080:80 nginx

# Remover automaticamente ao parar
docker run --rm -it alpine sh
Flags importantesReferência
FlagDescrição
-itInterativo + pseudo-TTY (terminal)
-dDetached — executa em background
-p host:containerMapeia porta do host para o container
--nameDefine um nome para o container
--rmRemove o container ao finalizar
-e VAR=valorDefine variável de ambiente
-v host:containerMonta volume ou bind mount
--networkConecta a uma rede específica

docker ps — Listar containers

docker psListar

Lista containers em execução. Use flags para ver todos ou filtrar.

# Containers em execução
docker ps

# Todos os containers (incluindo parados)
docker ps -a

# Apenas IDs dos containers
docker ps -q

# Todos os IDs (para scripts)
docker ps -aq

docker stop / start / restart — Controlar containers

docker stopParar

Envia SIGTERM e depois SIGKILL (após timeout) para parar o container graciosamente.

# Parar um container
docker stop meu-nginx

# Parar múltiplos containers
docker stop container1 container2

# Parar todos os containers em execução
docker stop $(docker ps -q)
docker start / restartIniciar

Inicia um container parado ou reinicia um container em execução.

# Iniciar container parado
docker start meu-nginx

# Reiniciar container
docker restart meu-nginx

docker rm — Remover containers

docker rmRemover

Remove containers parados. Use -f para forçar remoção de containers em execução.

# Remover container parado
docker rm meu-nginx

# Forçar remoção (mesmo em execução)
docker rm -f meu-nginx

# Remover todos os containers parados
docker container prune

# Remover todos os containers (forçado)
docker rm -f $(docker ps -aq)

docker logs — Ver logs do container

docker logsLogs

Exibe a saída (stdout/stderr) de um container. Essencial para debugging.

# Ver todos os logs
docker logs meu-nginx

# Seguir logs em tempo real (like tail -f)
docker logs -f meu-nginx

# Últimas N linhas
docker logs --tail 50 meu-nginx

# Com timestamps
docker logs -t meu-nginx

# Combinar flags
docker logs -f --tail 100 -t meu-nginx

docker exec — Executar comandos em container ativo

docker execExecutar

Executa um comando dentro de um container em execução. Ideal para debugging e administração.

# Abrir shell interativo
docker exec -it meu-nginx bash

# Executar comando único
docker exec meu-nginx cat /etc/nginx/nginx.conf

# Executar como root
docker exec -u root meu-nginx apt-get update

# Definir variável de ambiente
docker exec -e MY_VAR=teste meu-nginx env

docker inspect — Detalhes do container

docker inspectInspecionar

Retorna informações detalhadas em JSON sobre um container, imagem, volume ou rede.

# Inspecionar container (JSON completo)
docker inspect meu-nginx

# Obter IP do container
docker inspect --format '{{range .NetworkSettings.Networks}}{{.IPAddress}}{{end}}' meu-nginx

# Ver mounts/volumes
docker inspect --format '{{json .Mounts}}' meu-nginx

# Ver variáveis de ambiente
docker inspect --format '{{json .Config.Env}}' meu-nginx

# Ver status
docker inspect --format '{{.State.Status}}' meu-nginx
