Introdução ao boto3 — O SDK AWS para Python

Compreenda a arquitetura do boto3, a diferença entre Client e Resource, como gerenciar sessões e credenciais, e quando usar boto3 em vez de CLI ou Terraform.

O que é o boto3?

O boto3 é o SDK (Software Development Kit) oficial da Amazon Web Services para Python. Ele permite que desenvolvedores criem, configurem e gerenciem serviços AWS programaticamente. Com o boto3, você pode automatizar praticamente qualquer operação disponível no console AWS ou na CLI, integrando serviços cloud diretamente em suas aplicações Python.

🎯 Por que usar boto3?

  • Automação completa: Automatize tarefas repetitivas como backups, deploys e monitoramento
  • Integração nativa: Use Python para orquestrar múltiplos serviços AWS em um único script
  • Produção: Construa ferramentas internas, pipelines CI/CD e sistemas de auto-recuperação
  • Flexibilidade: Acesse 100% da API AWS com tipagem dinâmica e respostas em dicionários Python
  • Ecossistema: Combine com pandas, asyncio, click e outras bibliotecas Python

Arquitetura do boto3: Client vs Resource

O boto3 oferece duas interfaces distintas para interagir com serviços AWS. Entender a diferença é fundamental para escolher a abordagem correta em cada situação.

Característica Client (Baixo Nível) Resource (Alto Nível)
Interface Mapeamento 1:1 com a API HTTP da AWS Abstração orientada a objetos
Retorno Dicionários Python (dict) Objetos Resource com atributos
Cobertura 100% dos serviços e operações AWS Apenas alguns serviços (S3, EC2, DynamoDB, SQS, SNS, IAM)
Paginação Manual com Paginators Automática via coleções
Waiters Disponível via get_waiter() Disponível via wait_until_*()
Performance Menor overhead Ligeiramente mais lento
Recomendação Produção, scripts complexos, todos os serviços Prototipagem rápida, código mais legível

Session — Gerenciamento de Conexões

A Session é o objeto central do boto3 que mantém configuração de estado, incluindo credenciais, região padrão e perfil. Toda chamada a boto3.client() ou boto3.resource() usa uma sessão padrão implícita, mas criar sessões explícitas é uma prática recomendada para produção.

class AWSMultiAccountManager:
    """Gerencia conexões com múltiplas contas AWS."""
    
    def __init__(self):
        self.sessions = {}
    
    def get_session(self, account_name: str, profile: str = None, 
                    region: str = 'us-east-1') -> boto3.Session:
        """Obtém ou cria uma sessão para uma conta específica."""
        key = f"{account_name}:{region}"
        
        if key not in self.sessions:
            self.sessions[key] = boto3.Session(
                profile_name=profile or account_name,
                region_name=region
            )
        
        return self.sessions[key]
    
    def get_client(self, account_name: str, service: str, 
                   **kwargs) -> object:
        """Obtém um client para um serviço em uma conta específica."""
        session = self.get_session(account_name, **kwargs)
        return session.client(service)

Cadeia de Credenciais e IAM Roles

O boto3 procura credenciais em uma ordem específica. Entender essa cadeia é crucial para configurar seus ambientes corretamente e seguir as melhores práticas de segurança.

⚠️ Ordem de Precedência das Credenciais

  1. Parâmetros explícitos passados para Session() ou client()
  2. Variáveis de ambiente: AWS_ACCESS_KEY_ID, AWS_SECRET_ACCESS_KEY, AWS_SESSION_TOKEN
  3. Arquivo de credenciais compartilhado: ~/.aws/credentials
  4. Arquivo de configuração: ~/.aws/config
  5. Assume Role provider (configurado em ~/.aws/config)
  6. Boto2 config file: /etc/boto.cfg e ~/.boto
  7. Instance Metadata Service (IMDS): IAM Role da instância EC2
  8. Container credentials: ECS Task Role

boto3 vs AWS CLI vs Terraform — Quando usar cada um

Cada ferramenta tem seu caso de uso ideal. Entender quando usar cada uma é essencial para um workflow DevOps eficiente.

STS — Assume Role e Credenciais Temporárias

O AWS Security Token Service (STS) permite obter credenciais temporárias com permissões limitadas. Este é o padrão recomendado para acesso cross-account e para seguir o princípio do menor privilégio.

📋 STS Assume Role — Implementação Completa

import boto3
import json
from datetime import datetime, timezone
from botocore.exceptions import ClientError, BotoCoreError


class STSCredentialManager:
    """
    Gerenciador de credenciais temporárias via STS.
    Implementa assume_role com cache e renovação automática.
    """
    
    def __init__(self, base_session: boto3.Session = None):
        """
        Inicializa o gerenciador de credenciais.
        
        Args:
            base_session: Sessão base para fazer chamadas STS.
                         Se None, usa a sessão padrão.
        """
        self.base_session = base_session or boto3.Session()
        self.sts_client = self.base_session.client('sts')
        self._credential_cache = {}
    
    def assume_role(
        self,
        role_arn: str,
        session_name: str = 'boto3-automation',
        duration_seconds: int = 3600,
        external_id: str = None,
        policy: dict = None,
        mfa_serial: str = None,
        mfa_token: str = None
    ) -> boto3.Session:
        """
        Assume uma IAM Role e retorna uma nova sessão com credenciais temporárias.
        
        Args:
            role_arn: ARN da role a ser assumida
            session_name: Nome identificador da sessão
            duration_seconds: Duração das credenciais (900-43200 segundos)
            external_id: ID externo para proteção confused deputy
            policy: Política inline para restringir permissões
            mfa_serial: ARN do dispositivo MFA
            mfa_token: Código MFA atual
            
        Returns:
            boto3.Session com credenciais temporárias
            
        Raises:
            ClientError: Se não for possível assumir a role
        """
        # Verificar cache
        cache_key = f"{role_arn}:{session_name}"
        if cache_key in self._credential_cache:
            cached = self._credential_cache[cache_key]
            if cached['expiration'] > datetime.now(timezone.utc):
                return cached['session']
        
        # Montar parâmetros da chamada
        params = {
            'RoleArn': role_arn,
            'RoleSessionName': session_name,
            'DurationSeconds': duration_seconds
        }
        
        if external_id:
            params['ExternalId'] = external_id
        
        if policy:
            params['Policy'] = json.dumps(policy)
        
        if mfa_serial and mfa_token:
            params['SerialNumber'] = mfa_serial
            params['TokenCode'] = mfa_token
        
        try:
            response = self.sts_client.assume_role(**params)
            credentials = response['Credentials']
            
            # Criar nova sessão com credenciais temporárias
            session = boto3.Session(
                aws_access_key_id=credentials['AccessKeyId'],
                aws_secret_access_key=credentials['SecretAccessKey'],
                aws_session_token=credentials['SessionToken'],
                region_name=self.base_session.region_name
            )
            
            # Cachear credenciais
            self._credential_cache[cache_key] = {
                'session': session,
                'expiration': credentials['Expiration'],
                'assumed_role_arn': response['AssumedRoleUser']['Arn']
            }
            
            print(f"✅ Role assumida com sucesso: {role_arn}")
            print(f"   Sessão: {response['AssumedRoleUser']['Arn']}")
            print(f"   Expira em: {credentials['Expiration']}")
            
            return session
            
        except ClientError as e:
            error_code = e.response['Error']['Code']
            if error_code == 'AccessDenied':
                print(f"❌ Acesso negado ao assumir role: {role_arn}")
                print(f"   Verifique a trust policy da role")
            elif error_code == 'MalformedPolicyDocument':
                print(f"❌ Política inline inválida")
            elif error_code == 'RegionDisabledException':
                print(f"❌ Região desabilitada para STS")
            else:
                print(f"❌ Erro ao assumir role: {e}")
            raise
    
    def get_caller_identity(self) -> dict:
        """Retorna a identidade atual (Account, Arn, UserId)."""
        try:
            identity = self.sts_client.get_caller_identity()
            return {
                'account': identity['Account'],
                'arn': identity['Arn'],
                'user_id': identity['UserId']
            }
        except ClientError as e:
            print(f"❌ Erro ao obter identidade: {e}")
            raise
    
    def assume_role_chain(self, role_arns: list) -> boto3.Session:
        """
        Assume múltiplas roles em cadeia (role chaining).
        Útil para acesso a contas com múltiplos hops.
        
        Args:
            role_arns: Lista de ARNs de roles para assumir em sequência
            
        Returns:
            Sessão final após assumir todas as roles
        """
        current_session = self.base_session
        
        for i, role_arn in enumerate(role_arns):
            print(f"🔗 Assumindo role {i+1}/{len(role_arns)}: {role_arn}")
            sts = current_session.client('sts')
            
            response = sts.assume_role(
                RoleArn=role_arn,
                RoleSessionName=f'chain-hop-{i+1}',
                DurationSeconds=3600
            )
            
            credentials = response['Credentials']
            current_session = boto3.Session(
                aws_access_key_id=credentials['AccessKeyId'],
                aws_secret_access_key=credentials['SecretAccessKey'],
                aws_session_token=credentials['SessionToken']
            )
        
        return current_session

Tratamento de Erros com botocore.exceptions

O tratamento adequado de erros é essencial em scripts de automação AWS. O boto3 utiliza exceções específicas do botocore que fornecem informações detalhadas sobre falhas.

📋 Padrão Completo de Tratamento de Erros

import boto3
from botocore.exceptions import (
    ClientError,
    BotoCoreError,
    NoCredentialsError,
    PartialCredentialsError,
    EndpointConnectionError,
    ConnectTimeoutError,
    ReadTimeoutError,
    WaiterError,
    ParamValidationError
)
import logging

# Configurar logging
logging.basicConfig(
    level=logging.INFO,
    format='%(asctime)s - %(name)s - %(levelname)s - %(message)s'
)
logger = logging.getLogger('aws-automation')


def safe_aws_call(func):
    """
    Decorator para tratamento padronizado de erros AWS.
    Captura exceções comuns e fornece mensagens claras.
    """
    def wrapper(*args, **kwargs):
        try:
            return func(*args, **kwargs)
        
        except NoCredentialsError:
            logger.error(
                "❌ Credenciais AWS não encontradas. "
                "Configure ~/.aws/credentials ou variáveis de ambiente."
            )
            return None
        
        except PartialCredentialsError as e:
            logger.error(f"❌ Credenciais incompletas: {e}")
            return None
        
        except EndpointConnectionError as e:
            logger.error(
                f"❌ Não foi possível conectar ao endpoint AWS: {e}. "
                "Verifique sua conexão de rede e região."
            )
            return None
        
        except ConnectTimeoutError:
            logger.error(
                "❌ Timeout na conexão com AWS. "
                "Verifique sua rede ou aumente o connect_timeout."
            )
            return None
        
        except ReadTimeoutError:
            logger.error(
                "❌ Timeout na leitura da resposta AWS. "
                "A operação pode ter sido executada parcialmente."
            )
            return None
        
        except ClientError as e:
            error_code = e.response['Error']['Code']
            error_message = e.response['Error']['Message']
            http_status = e.response['ResponseMetadata']['HTTPStatusCode']
            request_id = e.response['ResponseMetadata']['RequestId']
            
            logger.error(
                f"❌ Erro AWS [{error_code}] (HTTP {http_status}): "
                f"{error_message} | RequestId: {request_id}"
            )
            
            # Tratamento específico por código de erro
            if error_code == 'AccessDenied':
                logger.info("💡 Verifique as permissões IAM do usuário/role.")
            elif error_code == 'ThrottlingException':
                logger.info("💡 Rate limit atingido. Implemente backoff exponencial.")
            elif error_code == 'ResourceNotFoundException':
                logger.info("💡 O recurso especificado não existe.")
            elif error_code == 'ValidationException':
                logger.info("💡 Parâmetros inválidos na requisição.")
            
            return None
        
        except ParamValidationError as e:
            logger.error(f"❌ Parâmetros inválidos: {e}")
            return None
        
        except BotoCoreError as e:
            logger.error(f"❌ Erro interno do botocore: {e}")
            return None
        
        except Exception as e:
            logger.error(f"❌ Erro inesperado: {type(e).__name__}: {e}")
            return None
    
    return wrapper

import time
import random

def retry_with_backoff(func, max_retries=5, base_delay=1.0, max_delay=60.0):
    """
    Executa uma função com retry e backoff exponencial com jitter.
    
    Args:
        func: Função a ser executada
        max_retries: Número máximo de tentativas
        base_delay: Delay base em segundos
        max_delay: Delay máximo em segundos
    """
    retryable_errors = [
        'ThrottlingException',
        'TooManyRequestsException',
        'RequestLimitExceeded',
        'ProvisionedThroughputExceededException',
        'InternalServerError',
        'ServiceUnavailable'
    ]
    
    for attempt in range(max_retries):
        try:
            return func()
        except ClientError as e:
            error_code = e.response['Error']['Code']
            
            if error_code not in retryable_errors:
                raise  # Não fazer retry para erros não-transientes
            
            if attempt == max_retries - 1:
                raise  # Última tentativa, propagar o erro
            
            # Calcular delay com jitter
            delay = min(base_delay * (2 ** attempt), max_delay)
            jitter = random.uniform(0, delay * 0.1)
            total_delay = delay + jitter
            
            logger.warning(
                f"⚠️ Tentativa {attempt + 1}/{max_retries} falhou "
                f"({error_code}). Retry em {total_delay:.2f}s..."
            )
            time.sleep(total_delay)

import boto3
import os
import mimetypes
from botocore.exceptions import ClientError
from boto3.s3.transfer import TransferConfig
from concurrent.futures import ThreadPoolExecutor, as_completed
import hashlib


class S3FileManager:
    """Gerenciador de arquivos S3 com upload/download otimizados."""
    
    def __init__(self, bucket: str, region: str = 'sa-east-1'):
        self.bucket = bucket
        self.s3_client = boto3.client('s3', region_name=region)
        self.s3_resource = boto3.resource('s3', region_name=region)
        
        # Configuração de transfer otimizada
        self.transfer_config = TransferConfig(
            multipart_threshold=8 * 1024 * 1024,   # 8MB - usar multipart acima disso
            max_concurrency=10,                      # 10 threads paralelas
            multipart_chunksize=8 * 1024 * 1024,   # 8MB por parte
            num_download_attempts=5,                 # 5 tentativas de download
            use_threads=True                         # Usar threads
        )
    
    def upload_arquivo(self, arquivo_local: str, key: str = None,
                       metadata: dict = None, storage_class: str = 'STANDARD') -> str:
        """
        Faz upload de um arquivo para o S3.
        
        Args:
            arquivo_local: Caminho do arquivo local
            key: Chave no S3 (se None, usa o nome do arquivo)
            metadata: Metadados customizados
            storage_class: Classe de armazenamento
            
        Returns:
            URL do objeto no S3
        """
        if not os.path.exists(arquivo_local):
            raise FileNotFoundError(f"Arquivo não encontrado: {arquivo_local}")
        
        if key is None:
            key = os.path.basename(arquivo_local)
        
        # Detectar content type
        content_type, _ = mimetypes.guess_type(arquivo_local)
        content_type = content_type or 'application/octet-stream'
        
        # Calcular checksum MD5
        md5_hash = self._calcular_md5(arquivo_local)
        
        extra_args = {
            'ContentType': content_type,
            'ServerSideEncryption': 'AES256',
            'StorageClass': storage_class,
            'Metadata': {
                'md5-checksum': md5_hash,
                'uploaded-by': 'boto3-automation',
                **(metadata or {})
            }
        }
        
        # Upload com progresso
        file_size = os.path.getsize(arquivo_local)
        print(f"📤 Uploading: {arquivo_local} ({self._format_size(file_size)})")
        
        callback = ProgressCallback(file_size, 'Upload')
        
        self.s3_client.upload_file(
            Filename=arquivo_local,
            Bucket=self.bucket,
            Key=key,
            ExtraArgs=extra_args,
            Config=self.transfer_config,
            Callback=callback
        )
        
        url = f"s3://{self.bucket}/{key}"
        print(f"\n✅ Upload concluído: {url}")
        return url
    
    def download_arquivo(self, key: str, destino: str = None) -> str:
        """
        Faz download de um arquivo do S3.
        
        Args:
            key: Chave do objeto no S3
            destino: Caminho local de destino
            
        Returns:
            Caminho do arquivo baixado
        """
        if destino is None:
            destino = os.path.basename(key)
        
        # Criar diretório de destino se não existir
        os.makedirs(os.path.dirname(destino) or '.', exist_ok=True)
        
        # Obter tamanho do arquivo
        try:
            response = self.s3_client.head_object(Bucket=self.bucket, Key=key)
            file_size = response['ContentLength']
        except ClientError as e:
            if e.response['Error']['Code'] == '404':
                raise FileNotFoundError(f"Objeto não encontrado: s3://{self.bucket}/{key}")
            raise
        
        print(f"📥 Downloading: s3://{self.bucket}/{key} ({self._format_size(file_size)})")
        
        callback = ProgressCallback(file_size, 'Download')
        
        self.s3_client.download_file(
            Bucket=self.bucket,
            Key=key,
            Filename=destino,
            Config=self.transfer_config,
            Callback=callback
        )
        
        print(f"\n✅ Download concluído: {destino}")
        return destino
    
    def upload_diretorio(self, diretorio_local: str, prefixo_s3: str = '',
                         max_workers: int = 10) -> list:
        """
        Faz upload de um diretório inteiro para o S3 com paralelismo.
        
        Args:
            diretorio_local: Caminho do diretório local
            prefixo_s3: Prefixo no S3 para os arquivos
            max_workers: Número de workers paralelos
        """
        arquivos = []
        for root, dirs, files in os.walk(diretorio_local):
            for filename in files:
                filepath = os.path.join(root, filename)
                relative_path = os.path.relpath(filepath, diretorio_local)
                s3_key = os.path.join(prefixo_s3, relative_path).replace('\\', '/')
                arquivos.append((filepath, s3_key))
        
        print(f"📂 Uploading {len(arquivos)} arquivos de '{diretorio_local}'...")
        
        resultados = []
        falhas = []
        
        with ThreadPoolExecutor(max_workers=max_workers) as executor:
            futures = {
                executor.submit(self._upload_single, filepath, key): (filepath, key)
                for filepath, key in arquivos
            }
            
            for future in as_completed(futures):
                filepath, key = futures[future]
                try:
                    future.result()
                    resultados.append(key)
                except Exception as e:
                    falhas.append((filepath, str(e)))
        
        print(f"\n✅ Upload concluído: {len(resultados)} sucesso, {len(falhas)} falhas")
        
        if falhas:
            print("❌ Arquivos com falha:")
            for filepath, erro in falhas:
                print(f"   - {filepath}: {erro}")
        
        return resultados
    
    def gerar_presigned_url(self, key: str, expiracao: int = 3600,
                           operacao: str = 'get_object') -> str:
        """
        Gera uma URL pré-assinada para acesso temporário.
        
        Args:
            key: Chave do objeto
            expiracao: Tempo de expiração em segundos
            operacao: 'get_object' para download, 'put_object' para upload
        """
        try:
            params = {'Bucket': self.bucket, 'Key': key}
            
            if operacao == 'put_object':
                params['ContentType'] = 'application/octet-stream'
            
            url = self.s3_client.generate_presigned_url(
                ClientMethod=operacao,
                Params=params,
                ExpiresIn=expiracao
            )
            
            print(f"🔗 URL pré-assinada gerada (expira em {expiracao}s)")
            return url
            
        except ClientError as e:
            print(f"❌ Erro ao gerar URL: {e}")
            return None
    
    def listar_objetos(self, prefixo: str = '', max_keys: int = None) -> list:
        """Lista objetos com paginação automática."""
        objetos = []
        paginator = self.s3_client.get_paginator('list_objects_v2')
        
        params = {'Bucket': self.bucket, 'Prefix': prefixo}
        
        for page in paginator.paginate(**params):
            if 'Contents' not in page:
                continue
            
            for obj in page['Contents']:
                objetos.append({
                    'key': obj['Key'],
                    'tamanho': obj['Size'],
                    'modificado': obj['LastModified'],
                    'storage_class': obj.get('StorageClass', 'STANDARD')
                })
                
                if max_keys and len(objetos) >= max_keys:
                    return objetos
        
        return objetos
    
    def _upload_single(self, filepath, key):
        """Upload de um único arquivo (usado em upload paralelo)."""
        content_type, _ = mimetypes.guess_type(filepath)
        self.s3_client.upload_file(
            Filename=filepath,
            Bucket=self.bucket,
            Key=key,
            ExtraArgs={
                'ContentType': content_type or 'application/octet-stream',
                'ServerSideEncryption': 'AES256'
            }
        )
    
    def _calcular_md5(self, filepath: str) -> str:
        """Calcula hash MD5 de um arquivo."""
        hash_md5 = hashlib.md5()
        with open(filepath, 'rb') as f:
            for chunk in iter(lambda: f.read(8192), b''):
                hash_md5.update(chunk)
        return hash_md5.hexdigest()
    
    @staticmethod
    def _format_size(size_bytes: int) -> str:
        """Formata tamanho em bytes para formato legível."""
        for unit in ['B', 'KB', 'MB', 'GB', 'TB']:
            if size_bytes < 1024:
                return f"{size_bytes:.2f} {unit}"
            size_bytes /= 1024
        return f"{size_bytes:.2f} PB"


class ProgressCallback:
    """Callback para exibir progresso de transferência."""
    
    def __init__(self, total_size: int, operation: str = 'Transfer'):
        self.total_size = total_size
        self.transferred = 0
        self.operation = operation
    
    def __call__(self, bytes_transferred):
        self.transferred += bytes_transferred
        percentage = (self.transferred / self.total_size) * 100
        bar_length = 40
        filled = int(bar_length * self.transferred / self.total_size)
        bar = '█' * filled + '░' * (bar_length - filled)
        print(f"\r   {self.operation}: [{bar}] {percentage:.1f}%", end='', flush=True)

def backup_automatizado(
    diretorio_origem: str,
    bucket_destino: str,
    prefixo: str = 'backups/',
    manter_ultimos: int = 7
):
    """
    Script de backup automatizado com rotação.
    
    Args:
        diretorio_origem: Diretório a ser backupeado
        bucket_destino: Bucket S3 de destino
        prefixo: Prefixo no S3
        manter_ultimos: Número de backups a manter
    """
    from datetime import datetime
    import tarfile
    import tempfile
    
    timestamp = datetime.now().strftime('%Y%m%d_%H%M%S')
    backup_key = f"{prefixo}{timestamp}/backup.tar.gz"
    
    # Criar arquivo tar.gz temporário
    with tempfile.NamedTemporaryFile(suffix='.tar.gz', delete=False) as tmp:
        tmp_path = tmp.name
    
    try:
        # Comprimir diretório
        print(f"📦 Comprimindo '{diretorio_origem}'...")
        with tarfile.open(tmp_path, 'w:gz') as tar:
            tar.add(diretorio_origem, arcname=os.path.basename(diretorio_origem))
        
        # Upload para S3
        manager = S3FileManager(bucket_destino)
        manager.upload_arquivo(
            tmp_path,
            key=backup_key,
            metadata={'tipo': 'backup-automatico', 'origem': diretorio_origem},
            storage_class='STANDARD_IA'
        )
        
        # Rotação de backups antigos
        print(f"\n🔄 Verificando rotação de backups (manter últimos {manter_ultimos})...")
        objetos = manager.listar_objetos(prefixo=prefixo)
        
        # Agrupar por data
        backups = sorted(
            set(obj['key'].split('/')[1] for obj in objetos if '/' in obj['key']),
            reverse=True
        )
        
        if len(backups) > manter_ultimos:
            s3_client = boto3.client('s3')
            for backup_antigo in backups[manter_ultimos:]:
                prefix_antigo = f"{prefixo}{backup_antigo}/"
                objetos_antigos = manager.listar_objetos(prefixo=prefix_antigo)
                
                for obj in objetos_antigos:
                    s3_client.delete_object(Bucket=bucket_destino, Key=obj['key'])
                
                print(f"   🗑️ Backup removido: {backup_antigo}")
        
        print(f"\n✅ Backup concluído: s3://{bucket_destino}/{backup_key}")
        
    finally:
        # Limpar arquivo temporário
        if os.path.exists(tmp_path):
            os.remove(tmp_path)

        subnet_id: str = None,
        user_data: str = None,
        iam_profile: str = None,
        tags: dict = None,
        volume_size: int = 20,
        aguardar: bool = True
    ) -> dict:
        """
        Lança uma nova instância EC2 com configuração completa.
        
        Args:
            nome: Nome da instância (tag Name)
            ami_id: ID da AMI
            tipo: Tipo da instância
            key_name: Nome do key pair
            security_group_ids: Lista de IDs de security groups
            subnet_id: ID da subnet
            user_data: Script de inicialização
            iam_profile: Nome do instance profile IAM
            tags: Tags adicionais
            volume_size: Tamanho do volume EBS em GB
            aguardar: Se True, aguarda a instância ficar running
        """
        # Montar tags
        all_tags = {'Name': nome, 'ManagedBy': 'boto3', 'CreatedAt': datetime.now().isoformat()}
        if tags:
            all_tags.update(tags)
        
        tag_specs = [{
            'ResourceType': 'instance',
            'Tags': [{'Key': k, 'Value': v} for k, v in all_tags.items()]
        }]
        
        # Montar parâmetros
        params = {
            'ImageId': ami_id,
            'InstanceType': tipo,
            'MinCount': 1,
            'MaxCount': 1,
            'TagSpecifications': tag_specs,
            'BlockDeviceMappings': [{
                'DeviceName': '/dev/xvda',
                'Ebs': {
                    'VolumeSize': volume_size,
                    'VolumeType': 'gp3',
                    'Encrypted': True,
                    'DeleteOnTermination': True
                }
            }],
            'MetadataOptions': {
                'HttpTokens': 'required',         # IMDSv2 obrigatório
                'HttpEndpoint': 'enabled',
                'HttpPutResponseHopLimit': 1
            }
        }
        
        if key_name:
            params['KeyName'] = key_name
        if security_group_ids:
            params['SecurityGroupIds'] = security_group_ids
        if subnet_id:
            params['SubnetId'] = subnet_id
        if user_data:
            params['UserData'] = user_data
        if iam_profile:
            params['IamInstanceProfile'] = {'Name': iam_profile}
        
        try:
            response = self.ec2_client.run_instances(**params)
            instance_id = response['Instances'][0]['InstanceId']

            print(f"   Tipo: {tipo} | AMI: {ami_id}")
            
            # Aguardar instância ficar running
            if aguardar:
                print(f"   ⏳ Aguardando instância ficar running...")
                waiter = self.ec2_client.get_waiter('instance_running')
                waiter.wait(
                    InstanceIds=[instance_id],
                    WaiterConfig={'Delay': 5, 'MaxAttempts': 60}
                )
                
                # Obter IP público
                desc = self.ec2_client.describe_instances(InstanceIds=[instance_id])
                instance_info = desc['Reservations'][0]['Instances'][0]

            raise

    def criar_security_group(self, nome: str, descricao: str, vpc_id: str,
                            regras_ingress: list = None) -> str:
        """
        Cria um Security Group com regras de ingress.
        
        Args:

            descricao: Descrição
            vpc_id: ID da VPC
            regras_ingress: Lista de regras (ex: [{'port': 22, 'cidr': '0.0.0.0/0', 'protocol': 'tcp'}])
        """
        try:
            response = self.ec2_client.create_security_group(
                GroupName=nome,
                Description=descricao,
                VpcId=vpc_id,
                TagSpecifications=[{
                    'ResourceType': 'security-group',
                    'Tags': [
                        {'Key': 'Name', 'Value': nome},
                        {'Key': 'ManagedBy', 'Value': 'boto3'}
                    ]
                }]
            )
            
            sg_id = response['GroupId']

            # Adicionar regras de ingress
            if regras_ingress:
                ip_permissions = []
                for regra in regras_ingress:
                    permission = {
                        'IpProtocol': regra.get('protocol', 'tcp'),
                        'FromPort': regra['port'],
                        'ToPort': regra.get('to_port', regra['port']),

                    }
                    ip_permissions.append(permission)
                
                self.ec2_client.authorize_security_group_ingress(
                    GroupId=sg_id,
                    IpPermissions=ip_permissions
                )
                print(f"   ✓ {len(regras_ingress)} regras de ingress adicionadas")
            
            return sg_id
            
        except ClientError as e:
            if e.response['Error']['Code'] == 'InvalidGroup.Duplicate':
                print(f"ℹ️ Security Group '{nome}' já existe")
                # Buscar ID existente
                response = self.ec2_client.describe_security_groups(
                    Filters=[
                        {'Name': 'group-name', 'Values': [nome]},
                        {'Name': 'vpc-id', 'Values': [vpc_id]}
                    ]
                )
                return response['SecurityGroups'][0]['GroupId']
            raise
    
    def criar_ami(self, instance_id: str, nome: str, descricao: str = '',

import boto3
import json
import zipfile
import os
import tempfile
import hashlib
import base64
from botocore.exceptions import ClientError
from datetime import datetime


class LambdaManager:
    """
    Gerenciador completo de funções AWS Lambda.
    Suporta criação, atualização, invocação e deploy automatizado.
    """
    
    def __init__(self, region: str = 'sa-east-1'):
        self.region = region
        self.lambda_client = boto3.client('lambda', region_name=region)
        self.iam_client = boto3.client('iam', region_name=region)
    
    def listar_funcoes(self, prefixo: str = None) -> list:
        """Lista todas as funções Lambda com detalhes."""
        funcoes = []
        paginator = self.lambda_client.get_paginator('list_functions')
        
        for page in paginator.paginate():
            for func in page['Functions']:
                if prefixo and not func['FunctionName'].startswith(prefixo):
                    continue
                
                funcoes.append({
                    'nome': func['FunctionName'],
                    'runtime': func.get('Runtime', 'N/A'),
                    'handler': func.get('Handler', 'N/A'),
                    'memoria': func['MemorySize'],
                    'timeout': func['Timeout'],
                    'tamanho_codigo': func['CodeSize'],
                    'ultima_modificacao': func['LastModified'],
                    'arn': func['FunctionArn'],
                    'descricao': func.get('Description', ''),
                    'estado': func.get('State', 'Active')
                })
        
        return funcoes
    
    def invocar_funcao(self, nome: str, payload: dict = None,
                       tipo: str = 'RequestResponse', log_type: str = 'Tail') -> dict:
        """
        Invoca uma função Lambda.
        
        Args:
            nome: Nome ou ARN da função
            payload: Dados de entrada (evento)
            tipo: 'RequestResponse' (síncrono) ou 'Event' (assíncrono)
            log_type: 'Tail' para incluir logs na resposta
            
        Returns:
            Resposta da invocação com payload e logs
        """
        params = {
            'FunctionName': nome,
            'InvocationType': tipo,
            'LogType': log_type
        }
        
        if payload:
            params['Payload'] = json.dumps(payload).encode('utf-8')
        
        try:
            response = self.lambda_client.invoke(**params)
            
            # Processar resposta
            resultado = {
                'status_code': response['StatusCode'],
                'executed_version': response.get('ExecutedVersion', '$LATEST'),
                'function_error': response.get('FunctionError'),
            }
            
            # Decodificar payload de resposta
            if 'Payload' in response:
                payload_response = json.loads(response['Payload'].read().decode('utf-8'))
                resultado['payload'] = payload_response
            
            # Decodificar logs
            if 'LogResult' in response:
                logs = base64.b64decode(response['LogResult']).decode('utf-8')
                resultado['logs'] = logs
            
            if resultado['function_error']:
                print(f"⚠️ Função executou com erro: {resultado['function_error']}")
            else:
                print(f"✅ Função '{nome}' invocada com sucesso")
            
            return resultado
            
        except ClientError as e:
            error_code = e.response['Error']['Code']
            if error_code == 'ResourceNotFoundException':
                print(f"❌ Função '{nome}' não encontrada")
            elif error_code == 'TooManyRequestsException':
                print(f"❌ Rate limit atingido para invocação")
            else:
                print(f"❌ Erro ao invocar função: {e}")
            raise
    
    def criar_funcao(
        self,
        nome: str,
        runtime: str = 'python3.12',
        handler: str = 'lambda_function.lambda_handler',
        role_arn: str = None,
        codigo_dir: str = None,
        codigo_zip: str = None,
        descricao: str = '',
        memoria: int = 256,
        timeout: int = 30,
        env_vars: dict = None,
        layers: list = None,
        vpc_config: dict = None,
        tags: dict = None
    ) -> dict:
        """
        Cria uma nova função Lambda.
        
        Args:
            nome: Nome da função
            runtime: Runtime (python3.12, nodejs20.x, etc.)
            handler: Handler da função
            role_arn: ARN da IAM Role de execução
            codigo_dir: Diretório com o código (será zipado)
            codigo_zip: Caminho para um arquivo zip existente
            descricao: Descrição da função
            memoria: Memória em MB (128-10240)
            timeout: Timeout em segundos (1-900)
            env_vars: Variáveis de ambiente
            layers: Lista de ARNs de layers
            vpc_config: Configuração de VPC
            tags: Tags da função
        """
        # Preparar código
        if codigo_dir:
            zip_bytes = self._zipar_diretorio(codigo_dir)
        elif codigo_zip:
            with open(codigo_zip, 'rb') as f:
                zip_bytes = f.read()
        else:
            raise ValueError("Forneça codigo_dir ou codigo_zip")
        
        # Se role_arn não fornecido, criar role básica
        if not role_arn:
            role_arn = self._criar_role_basica(nome)
        
        params = {
            'FunctionName': nome,
            'Runtime': runtime,
            'Role': role_arn,
            'Handler': handler,
            'Code': {'ZipFile': zip_bytes},
            'Description': descricao,
            'MemorySize': memoria,
            'Timeout': timeout,
            'Publish': True,
            'PackageType': 'Zip',
            'Architectures': ['arm64'],  # Graviton2 - melhor custo-benefício
            'Tags': tags or {'ManagedBy': 'boto3-automation'}
        }
        
        if env_vars:
            params['Environment'] = {'Variables': env_vars}
        
        if layers:
            params['Layers'] = layers
        
        if vpc_config:
            params['VpcConfig'] = vpc_config
        
        try:
            response = self.lambda_client.create_function(**params)
            
            print(f"✅ Função Lambda criada: {nome}")
            print(f"   ARN: {response['FunctionArn']}")
            print(f"   Runtime: {runtime} | Memória: {memoria}MB | Timeout: {timeout}s")
            print(f"   Tamanho: {len(zip_bytes) / 1024:.1f} KB")
            
            # Aguardar função ficar ativa
            waiter = self.lambda_client.get_waiter('function_active_v2')
            waiter.wait(FunctionName=nome)
            print(f"   ✅ Função ativa e pronta para invocação")
            
            return {
                'arn': response['FunctionArn'],
                'version': response['Version'],
                'code_sha256': response['CodeSha256']
            }
            
        except ClientError as e:
            if e.response['Error']['Code'] == 'ResourceConflictException':
                print(f"ℹ️ Função '{nome}' já existe. Use atualizar_codigo() para atualizar.")
            else:
                print(f"❌ Erro ao criar função: {e}")
            raise
    
    def atualizar_codigo(self, nome: str, codigo_dir: str = None,
                         codigo_zip: str = None, publicar: bool = True) -> dict:
        """Atualiza o código de uma função Lambda existente."""
        if codigo_dir:
            zip_bytes = self._zipar_diretorio(codigo_dir)
        elif codigo_zip:
            with open(codigo_zip, 'rb') as f:
                zip_bytes = f.read()
        else:
            raise ValueError("Forneça codigo_dir ou codigo_zip")
        
        try:
            response = self.lambda_client.update_function_code(
                FunctionName=nome,
                ZipFile=zip_bytes,
                Publish=publicar
            )
            
            print(f"✅ Código atualizado: {nome}")
            print(f"   Versão: {response['Version']}")
            print(f"   SHA256: {response['CodeSha256'][:16]}...")
            
            return {
                'version': response['Version'],
                'code_sha256': response['CodeSha256']
            }
            
        except ClientError as e:
            print(f"❌ Erro ao atualizar código: {e}")
            raise
    
    def atualizar_configuracao(self, nome: str, **kwargs) -> dict:
        """Atualiza a configuração de uma função Lambda."""
        params = {'FunctionName': nome}
        
        mapeamento = {
            'memoria': 'MemorySize',
            'timeout': 'Timeout',
            'handler': 'Handler',
            'runtime': 'Runtime',
            'descricao': 'Description',
            'role_arn': 'Role',
            'layers': 'Layers'
        }
        
        for key, value in kwargs.items():
            if key in mapeamento and value is not None:
                params[mapeamento[key]] = value
        
        if 'env_vars' in kwargs:
            params['Environment'] = {'Variables': kwargs['env_vars']}
        
        try:
            response = self.lambda_client.update_function_configuration(**params)
            print(f"✅ Configuração atualizada: {nome}")
            return response
        except ClientError as e:
            print(f"❌ Erro ao atualizar configuração: {e}")
            raise
    
    def _zipar_diretorio(self, diretorio: str) -> bytes:
        """Cria um arquivo zip a partir de um diretório."""
        zip_buffer = tempfile.NamedTemporaryFile(suffix='.zip', delete=False)
        
        with zipfile.ZipFile(zip_buffer.name, 'w', zipfile.ZIP_DEFLATED) as zf:
            for root, dirs, files in os.walk(diretorio):
                # Ignorar __pycache__ e .git
                dirs[:] = [d for d in dirs if d not in ('__pycache__', '.git', '.venv')]
                
                for file in files:
                    if file.endswith('.pyc'):
                        continue
                    filepath = os.path.join(root, file)
                    arcname = os.path.relpath(filepath, diretorio)
                    zf.write(filepath, arcname)
        
        with open(zip_buffer.name, 'rb') as f:
            zip_bytes = f.read()
        
        os.unlink(zip_buffer.name)
        return zip_bytes
    
    def _criar_role_basica(self, function_name: str) -> str:
        """Cria uma IAM Role básica para Lambda."""
        role_name = f"lambda-role-{function_name}"
        
        trust_policy = {
            "Version": "2012-10-17",
            "Statement": [{
                "Effect": "Allow",
                "Principal": {"Service": "lambda.amazonaws.com"},
                "Action": "sts:AssumeRole"
            }]
        }
        
        try:
            response = self.iam_client.create_role(
                RoleName=role_name,
                AssumeRolePolicyDocument=json.dumps(trust_policy),
                Description=f"Role de execução para Lambda {function_name}"
            )
            
            # Anexar política básica de logs
            self.iam_client.attach_role_policy(
                RoleName=role_name,
                PolicyArn='arn:aws:iam::aws:policy/service-role/AWSLambdaBasicExecutionRole'
            )
            
            # Aguardar propagação da role
            import time
            time.sleep(10)
            
            return response['Role']['Arn']
            
        except ClientError as e:
            if e.response['Error']['Code'] == 'EntityAlreadyExists':
                response = self.iam_client.get_role(RoleName=role_name)
                return response['Role']['Arn']
            raise

class LambdaDeployPipeline:
    """Pipeline de deploy para funções Lambda com versionamento e aliases."""
    
    def __init__(self, region: str = 'sa-east-1'):
        self.lambda_client = boto3.client('lambda', region_name=region)
        self.manager = LambdaManager(region)
    
    def deploy(self, nome: str, codigo_dir: str, alias: str = 'live',
               descricao_versao: str = '') -> dict:
        """
        Deploy completo com versionamento e alias.
        
        1. Atualiza o código
        2. Publica uma nova versão
        3. Atualiza o alias para a nova versão
        """
        print(f"🚀 Iniciando deploy de '{nome}'...")
        print(f"{'='*50}")
        
        # 1. Atualizar código
        resultado = self.manager.atualizar_codigo(nome, codigo_dir=codigo_dir, publicar=True)
        nova_versao = resultado['version']
        
        # 2. Atualizar descrição da versão
        if descricao_versao:
            self.lambda_client.update_function_configuration(
                FunctionName=nome,
                Description=descricao_versao
            )
        
        # 3. Criar ou atualizar alias
        try:
            self.lambda_client.update_alias(
                FunctionName=nome,
                Name=alias,
                FunctionVersion=nova_versao,
                Description=f"Deploy {datetime.now().isoformat()}"
            )
            print(f"   ✅ Alias '{alias}' atualizado para versão {nova_versao}")
        except ClientError:
            self.lambda_client.create_alias(
                FunctionName=nome,
                Name=alias,
                FunctionVersion=nova_versao,
                Description=f"Deploy {datetime.now().isoformat()}"
            )
            print(f"   ✅ Alias '{alias}' criado apontando para versão {nova_versao}")
        
        print(f"{'='*50}")
        print(f"✅ Deploy concluído! Versão: {nova_versao}, Alias: {alias}")
        
        return {'version': nova_versao, 'alias': alias}
    
    def rollback(self, nome: str, alias: str = 'live', versoes_atras: int = 1):
        """Faz rollback para uma versão anterior."""
        # Listar versões
        response = self.lambda_client.list_versions_by_function(FunctionName=nome)
        versoes = [v for v in response['Versions'] if v['Version'] != '$LATEST']
        versoes.sort(key=lambda v: int(v['Version']), reverse=True)
        
        if len(versoes) <= versoes_atras:
            print(f"❌ Não há versões suficientes para rollback")
            return
        
        versao_alvo = versoes[versoes_atras]['Version']
        
        self.lambda_client.update_alias(
            FunctionName=nome,
            Name=alias,
            FunctionVersion=versao_alvo
        )

from botocore.exceptions import ClientError
from boto3.dynamodb.conditions import Key, Attr
from boto3.dynamodb.types import TypeDeserializer, TypeSerializer
from decimal import Decimal
from datetime import datetime

class DynamoDBManager:
    """
    Gerenciador completo de DynamoDB com operações CRUD,
    batch operations, queries e scans otimizados.
    """
    
    def __init__(self, region: str = 'sa-east-1'):
        self.region = region
        self.dynamodb_client = boto3.client('dynamodb', region_name=region)
        self.dynamodb_resource = boto3.resource('dynamodb', region_name=region)
    
    def criar_tabela(
        self,
        nome: str,
        partition_key: tuple,
        sort_key: tuple = None,
        gsi: list = None,
        billing_mode: str = 'PAY_PER_REQUEST',
        rcu: int = None,
        wcu: int = None,
        ttl_attribute: str = None,
        stream: bool = False
    ) -> object:
        """
        Cria uma tabela DynamoDB.
        
        Args:
            nome: Nome da tabela
            partition_key: Tupla (nome, tipo) - tipo: 'S', 'N', 'B'
            sort_key: Tupla (nome, tipo) opcional
            gsi: Lista de GSIs [{name, partition_key, sort_key, projection}]
            billing_mode: 'PAY_PER_REQUEST' ou 'PROVISIONED'
            rcu: Read Capacity Units (se PROVISIONED)
            wcu: Write Capacity Units (se PROVISIONED)
            ttl_attribute: Nome do atributo TTL
            stream: Habilitar DynamoDB Streams
        """
        # Definir chaves
        key_schema = [
            {'AttributeName': partition_key[0], 'KeyType': 'HASH'}
        ]
        attribute_definitions = [
            {'AttributeName': partition_key[0], 'AttributeType': partition_key[1]}
        ]
        
        if sort_key:
            key_schema.append(
                {'AttributeName': sort_key[0], 'KeyType': 'RANGE'}
            )
            attribute_definitions.append(
                {'AttributeName': sort_key[0], 'AttributeType': sort_key[1]}
            )
        
        params = {
            'TableName': nome,
            'KeySchema': key_schema,
            'AttributeDefinitions': attribute_definitions,
            'BillingMode': billing_mode,
            'Tags': [
                {'Key': 'ManagedBy', 'Value': 'boto3-automation'},
                {'Key': 'CreatedAt', 'Value': datetime.now().isoformat()}
            ]
        }
        
        # Capacidade provisionada
        if billing_mode == 'PROVISIONED':
            params['ProvisionedThroughput'] = {
                'ReadCapacityUnits': rcu or 5,
                'WriteCapacityUnits': wcu or 5
            }
        
        # Global Secondary Indexes
        if gsi:
            gsi_definitions = []
            for index in gsi:
                gsi_def = {
                    'IndexName': index['name'],
                    'KeySchema': [
                        {'AttributeName': index['partition_key'][0], 'KeyType': 'HASH'}
                    ],
                    'Projection': {'ProjectionType': index.get('projection', 'ALL')}
                }
                
                # Adicionar atributo ao attribute_definitions
                attr_def = {'AttributeName': index['partition_key'][0], 
                           'AttributeType': index['partition_key'][1]}
                if attr_def not in attribute_definitions:
                    attribute_definitions.append(attr_def)
                
                if 'sort_key' in index:
                    gsi_def['KeySchema'].append(
                        {'AttributeName': index['sort_key'][0], 'KeyType': 'RANGE'}
                    )
                    attr_def = {'AttributeName': index['sort_key'][0], 
                               'AttributeType': index['sort_key'][1]}
                    if attr_def not in attribute_definitions:
                        attribute_definitions.append(attr_def)
                
                if billing_mode == 'PROVISIONED':
                    gsi_def['ProvisionedThroughput'] = {
                        'ReadCapacityUnits': 5,
                        'WriteCapacityUnits': 5
                    }
                
                gsi_definitions.append(gsi_def)
            
            params['GlobalSecondaryIndexes'] = gsi_definitions
        
        # DynamoDB Streams
        if stream:
            params['StreamSpecification'] = {
                'StreamEnabled': True,
                'StreamViewType': 'NEW_AND_OLD_IMAGES'
            }
        
        try:
            table = self.dynamodb_resource.create_table(**params)
            print(f"⏳ Criando tabela '{nome}'...")
            
            # Aguardar tabela ficar ativa
            table.wait_until_exists()
            print(f"✅ Tabela '{nome}' criada com sucesso!")
            
            # Configurar TTL
            if ttl_attribute:
                self.dynamodb_client.update_time_to_live(
                    TableName=nome,
                    TimeToLiveSpecification={
                        'Enabled': True,
                        'AttributeName': ttl_attribute
                    }
                )
                print(f"   ✓ TTL habilitado no atributo '{ttl_attribute}'")
            
            return table
            
        except ClientError as e:
            if e.response['Error']['Code'] == 'ResourceInUseException':
                print(f"ℹ️ Tabela '{nome}' já existe")
                return self.dynamodb_resource.Table(nome)
            raise
    
    def put_item(self, tabela: str, item: dict, condition: str = None) -> bool:
        """
        Insere ou substitui um item na tabela.
        
        Args:
            tabela: Nome da tabela
            item: Dicionário com os dados
            condition: Expressão de condição (ex: 'attribute_not_exists(pk)')
        """
        table = self.dynamodb_resource.Table(tabela)
        
        # Converter floats para Decimal (DynamoDB não suporta float)
        item = self._convert_to_decimal(item)
        
        # Adicionar metadados
        item['_created_at'] = datetime.now().isoformat()
        item['_updated_at'] = datetime.now().isoformat()
        
        params = {'Item': item}
        if condition:
            params['ConditionExpression'] = condition
        
        try:
            table.put_item(**params)
            return True
        except ClientError as e:
            if e.response['Error']['Code'] == 'ConditionalCheckFailedException':
                print(f"⚠️ Condição não atendida: item pode já existir")
                return False
            raise
    
    def get_item(self, tabela: str, key: dict, consistent: bool = False) -> dict:
        """Obtém um item pela chave primária."""
        table = self.dynamodb_resource.Table(tabela)
        
        params = {
            'Key': key,
            'ConsistentRead': consistent
        }
        
        response = table.get_item(**params)
        item = response.get('Item')
        
        if item:
            return self._convert_from_decimal(item)
        return None
    
    def update_item(self, tabela: str, key: dict, updates: dict,
                    condition: str = None) -> dict:
        """
        Atualiza atributos específicos de um item.
        
        Args:
            tabela: Nome da tabela
            key: Chave primária do item
            updates: Dicionário com atributos a atualizar
            condition: Expressão de condição
        """
        table = self.dynamodb_resource.Table(tabela)
        
        # Construir UpdateExpression dinamicamente
        update_parts = []
        expression_values = {}
        expression_names = {}
        
        updates['_updated_at'] = datetime.now().isoformat()
        
        for i, (attr, value) in enumerate(updates.items()):
            placeholder_name = f"#attr{i}"
            placeholder_value = f":val{i}"
            
            expression_names[placeholder_name] = attr
            expression_values[placeholder_value] = self._convert_to_decimal(value) \
                if isinstance(value, (dict, list)) else \
                Decimal(str(value)) if isinstance(value, float) else value
            
            update_parts.append(f"{placeholder_name} = {placeholder_value}")
        
        update_expression = "SET " + ", ".join(update_parts)
        
        params = {
            'Key': key,
            'UpdateExpression': update_expression,
            'ExpressionAttributeNames': expression_names,
            'ExpressionAttributeValues': expression_values,
            'ReturnValues': 'ALL_NEW'
        }
        
        if condition:
            params['ConditionExpression'] = condition
        
        try:
            response = table.update_item(**params)
            return self._convert_from_decimal(response.get('Attributes', {}))
        except ClientError as e:
            if e.response['Error']['Code'] == 'ConditionalCheckFailedException':
                print(f"⚠️ Condição não atendida para update")
                return None
            raise
    
    def delete_item(self, tabela: str, key: dict, condition: str = None) -> bool:
        """Deleta um item pela chave primária."""
        table = self.dynamodb_resource.Table(tabela)
        
        params = {'Key': key, 'ReturnValues': 'ALL_OLD'}
        if condition:
            params['ConditionExpression'] = condition
        
        try:
            response = table.delete_item(**params)
            return 'Attributes' in response
        except ClientError as e:
            if e.response['Error']['Code'] == 'ConditionalCheckFailedException':
                return False
            raise
    
    def query(self, tabela: str, partition_key_name: str, partition_key_value,
              sort_key_condition=None, index_name: str = None,
              filter_expression=None, limit: int = None,
              scan_forward: bool = True) -> list:
        """
        Executa uma query eficiente na tabela.
        
        Args:
            tabela: Nome da tabela
            partition_key_name: Nome do atributo da partition key
            partition_key_value: Valor da partition key
            sort_key_condition: Condição para sort key (boto3.dynamodb.conditions.Key)
            index_name: Nome do GSI (se aplicável)
            filter_expression: Filtro pós-query
            limit: Limite de itens retornados
            scan_forward: True para ASC, False para DESC
        """
        table = self.dynamodb_resource.Table(tabela)
        
        key_condition = Key(partition_key_name).eq(partition_key_value)
        if sort_key_condition:
            key_condition = key_condition & sort_key_condition
        
        params = {
            'KeyConditionExpression': key_condition,
            'ScanIndexForward': scan_forward
        }
        
        if index_name:
            params['IndexName'] = index_name
        if filter_expression:
            params['FilterExpression'] = filter_expression
        if limit:
            params['Limit'] = limit
        
        # Paginação automática
        items = []
        while True:
            response = table.query(**params)
            items.extend(response.get('Items', []))
            
            if 'LastEvaluatedKey' not in response:
                break
            if limit and len(items) >= limit:
                break
            
            params['ExclusiveStartKey'] = response['LastEvaluatedKey']
        
        return [self._convert_from_decimal(item) for item in items]
    
    def batch_write(self, tabela: str, items: list, operacao: str = 'put') -> dict:
        """
        Escrita em batch (até 25 itens por vez).
        
        Args:
            tabela: Nome da tabela
            items: Lista de itens para inserir ou chaves para deletar
            operacao: 'put' ou 'delete'
        """
        table = self.dynamodb_resource.Table(tabela)
        
        sucesso = 0
        falhas = 0
        
        # Processar em lotes de 25
        for i in range(0, len(items), 25):
            batch = items[i:i+25]
            
            with table.batch_writer() as writer:
                for item in batch:
                    try:
                        if operacao == 'put':
                            item = self._convert_to_decimal(item)
                            item['_created_at'] = datetime.now().isoformat()
                            writer.put_item(Item=item)
                        elif operacao == 'delete':
                            writer.delete_item(Key=item)
                        sucesso += 1
                    except Exception as e:
                        falhas += 1
                        print(f"   ⚠️ Falha no item: {e}")
        
        print(f"✅ Batch {operacao}: {sucesso} sucesso, {falhas} falhas")
        return {'sucesso': sucesso, 'falhas': falhas}
    
    def _convert_to_decimal(self, obj):
        """Converte floats para Decimal recursivamente."""
        if isinstance(obj, float):
            return Decimal(str(obj))
        elif isinstance(obj, dict):
            return {k: self._convert_to_decimal(v) for k, v in obj.items()}
        elif isinstance(obj, list):
            return [self._convert_to_decimal(i) for i in obj]
        return obj
    
    def _convert_from_decimal(self, obj):
        """Converte Decimals para float/int recursivamente."""
        if isinstance(obj, Decimal):
            if obj == int(obj):
                return int(obj)
            return float(obj)
        elif isinstance(obj, dict):
            return {k: self._convert_from_decimal(v) for k, v in obj.items()}
        elif isinstance(obj, list):
            return [self._convert_from_decimal(i) for i in obj]
        return obj

import boto3
import json
import time
from botocore.exceptions import ClientError
from datetime import datetime
from concurrent.futures import ThreadPoolExecutor
import uuid
import signal
import sys


class SQSManager:
    """
    Gerenciador completo de filas SQS.
    Suporta filas Standard e FIFO com DLQ.
    """
    
    def __init__(self, region: str = 'sa-east-1'):
        self.region = region
        self.sqs_client = boto3.client('sqs', region_name=region)
        self.sqs_resource = boto3.resource('sqs', region_name=region)
    
    def criar_fila(
        self,
        nome: str,
        fifo: bool = False,
        visibility_timeout: int = 30,
        message_retention: int = 345600,
        max_message_size: int = 262144,
        delay_seconds: int = 0,
        dlq_arn: str = None,
        max_receive_count: int = 3
    ) -> str:
        """
        Cria uma fila SQS com configuração completa.
        
        Args:
            nome: Nome da fila (para FIFO, deve terminar com .fifo)
            fifo: Se True, cria fila FIFO
            visibility_timeout: Tempo que mensagem fica invisível após recebida (seg)
            message_retention: Retenção de mensagens (seg, max 14 dias = 1209600)
            max_message_size: Tamanho máximo da mensagem (bytes, max 256KB)
            delay_seconds: Delay padrão para mensagens (seg, max 900)
            dlq_arn: ARN da Dead Letter Queue
            max_receive_count: Recebimentos antes de enviar para DLQ
            
        Returns:
            URL da fila criada
        """
        # Ajustar nome para FIFO
        if fifo and not nome.endswith('.fifo'):
            nome = f"{nome}.fifo"
        
        attributes = {
            'VisibilityTimeout': str(visibility_timeout),
            'MessageRetentionPeriod': str(message_retention),
            'MaximumMessageSize': str(max_message_size),
            'DelaySeconds': str(delay_seconds)
        }
        
        if fifo:
            attributes['FifoQueue'] = 'true'
            attributes['ContentBasedDeduplication'] = 'true'
        
        # Configurar DLQ (Redrive Policy)
        if dlq_arn:
            attributes['RedrivePolicy'] = json.dumps({
                'deadLetterTargetArn': dlq_arn,
                'maxReceiveCount': str(max_receive_count)
            })
        
        try:
            response = self.sqs_client.create_queue(
                QueueName=nome,
                Attributes=attributes,
                tags={
                    'ManagedBy': 'boto3-automation',
                    'CreatedAt': datetime.now().isoformat()
                }
            )
            
            queue_url = response['QueueUrl']
            print(f"✅ Fila criada: {nome}")
            print(f"   URL: {queue_url}")
            print(f"   Tipo: {'FIFO' if fifo else 'Standard'}")
            
            return queue_url
            
        except ClientError as e:
            if e.response['Error']['Code'] == 'QueueAlreadyExists':
                # Retornar URL da fila existente
                response = self.sqs_client.get_queue_url(QueueName=nome)
                return response['QueueUrl']
            raise
    
    def criar_fila_com_dlq(self, nome: str, fifo: bool = False) -> dict:
        """Cria uma fila com sua respectiva DLQ."""
        # 1. Criar DLQ
        dlq_nome = f"{nome}-dlq" if not fifo else f"{nome}-dlq.fifo"
        dlq_url = self.criar_fila(dlq_nome, fifo=fifo, message_retention=1209600)
        
        # Obter ARN da DLQ
        dlq_attrs = self.sqs_client.get_queue_attributes(
            QueueUrl=dlq_url,
            AttributeNames=['QueueArn']
        )
        dlq_arn = dlq_attrs['Attributes']['QueueArn']
        
        # 2. Criar fila principal com redrive policy
        fila_url = self.criar_fila(
            nome, fifo=fifo,
            dlq_arn=dlq_arn,
            max_receive_count=3
        )
        
        print(f"\n📋 Configuração completa:")
        print(f"   Fila principal: {fila_url}")
        print(f"   DLQ: {dlq_url}")
        print(f"   Max receive count: 3")
        
        return {'queue_url': fila_url, 'dlq_url': dlq_url, 'dlq_arn': dlq_arn}
    
    def enviar_mensagem(self, queue_url: str, corpo: dict,
                        delay: int = 0, atributos: dict = None,
                        group_id: str = None, dedup_id: str = None) -> str:
        """
        Envia uma mensagem para a fila.
        
        Args:
            queue_url: URL da fila
            corpo: Corpo da mensagem (será serializado como JSON)
            delay: Delay em segundos (0-900)
            atributos: Atributos da mensagem
            group_id: MessageGroupId (obrigatório para FIFO)
            dedup_id: MessageDeduplicationId (para FIFO sem dedup automático)
            
        Returns:
            MessageId da mensagem enviada
        """
        params = {
            'QueueUrl': queue_url,
            'MessageBody': json.dumps(corpo, default=str),
            'DelaySeconds': delay
        }
        
        if atributos:
            params['MessageAttributes'] = {
                key: {
                    'DataType': 'String',
                    'StringValue': str(value)
                } for key, value in atributos.items()
            }
        
        if group_id:
            params['MessageGroupId'] = group_id
        
        if dedup_id:
            params['MessageDeduplicationId'] = dedup_id
        
        try:
            response = self.sqs_client.send_message(**params)
            return response['MessageId']
        except ClientError as e:
            print(f"❌ Erro ao enviar mensagem: {e}")
            raise
    
    def enviar_batch(self, queue_url: str, mensagens: list) -> dict:
        """
        Envia mensagens em batch (até 10 por vez).
        
        Args:
            mensagens: Lista de dicts com 'corpo' e opcionalmente 'atributos'
        """
        sucesso = 0
        falhas = 0
        
        for i in range(0, len(mensagens), 10):
            batch = mensagens[i:i+10]
            
            entries = []
            for j, msg in enumerate(batch):
                entry = {
                    'Id': str(j),
                    'MessageBody': json.dumps(msg.get('corpo', msg), default=str)
                }
                if 'delay' in msg:
                    entry['DelaySeconds'] = msg['delay']
                entries.append(entry)
            
            response = self.sqs_client.send_message_batch(
                QueueUrl=queue_url,
                Entries=entries
            )
            
            sucesso += len(response.get('Successful', []))
            falhas += len(response.get('Failed', []))
        
        print(f"📨 Batch enviado: {sucesso} sucesso, {falhas} falhas")
        return {'sucesso': sucesso, 'falhas': falhas}
    
    def receber_mensagens(self, queue_url: str, max_messages: int = 10,
                          wait_time: int = 20, visibility_timeout: int = 30) -> list:
        """
        Recebe mensagens da fila com long polling.
        
        Args:
            queue_url: URL da fila
            max_messages: Máximo de mensagens (1-10)
            wait_time: Tempo de long polling em segundos (0-20)
            visibility_timeout: Tempo de visibilidade após recebimento
        """
        try:
            response = self.sqs_client.receive_message(
                QueueUrl=queue_url,
                MaxNumberOfMessages=min(max_messages, 10),
                WaitTimeSeconds=wait_time,
                VisibilityTimeout=visibility_timeout,
                AttributeNames=['All'],
                MessageAttributeNames=['All']
            )

            for msg in response.get('Messages', []):
                mensagens.append({

                    'receipt_handle': msg['ReceiptHandle'],
                    'corpo': json.loads(msg['Body']),
                    'atributos': msg.get('MessageAttributes', {}),
                    'sistema': msg.get('Attributes', {}),
                    'approximate_receive_count': int(
                        msg.get('Attributes', {}).get('ApproximateReceiveCount', 0)
                    )
                })
            
            return mensagens
            
        except ClientError as e:
            print(f"❌ Erro ao receber mensagens: {e}")

class MessageConsumer:
    """Consumidor de mensagens SQS com graceful shutdown."""
    
    def __init__(self, queue_url: str, handler, workers: int = 3,
                 region: str = 'sa-east-1'):
        self.queue_url = queue_url
        self.handler = handler
        self.workers = workers
        self.sqs = SQSManager(region)
        self._running = True
        
        # Registrar handlers de sinal para graceful shutdown
        signal.signal(signal.SIGINT, self._shutdown)
        signal.signal(signal.SIGTERM, self._shutdown)
    
    def _shutdown(self, signum, frame):
        """Handler para graceful shutdown."""
        print(f"\n⚠️ Shutdown solicitado (signal {signum})...")
        self._running = False
    
    def iniciar(self):
        """Inicia o loop de consumo de mensagens."""
        print(f"🎧 Consumer iniciado (workers: {self.workers})")
        print(f"   Fila: {self.queue_url}")
        print(f"   Pressione Ctrl+C para parar\n")
        
        with ThreadPoolExecutor(max_workers=self.workers) as executor:
            while self._running:
                mensagens = self.sqs.receber_mensagens(
                    self.queue_url,
                    max_messages=self.workers,
                    wait_time=20
                )
                
                if not mensagens:
                    continue
                
                # Processar mensagens em paralelo
                futures = {
                    executor.submit(self._processar, msg): msg
                    for msg in mensagens
                }
                
                for future in futures:
                    msg = futures[future]
                    try:
                        future.result(timeout=30)
                        # Deletar mensagem após processamento bem-sucedido
                        self.sqs.deletar_mensagem(
                            self.queue_url, msg['receipt_handle']
                        )
                    except Exception as e:
                        print(f"   ❌ Falha ao processar: {e}")
        
        print("👋 Consumer encerrado graciosamente")
    
    def _processar(self, mensagem: dict):
        """Processa uma mensagem individual."""
        self.handler(mensagem['corpo'])

import boto3

from datetime import datetime, timezone, timedelta

    def criar_usuario(self, username: str, path: str = '/',

                      programmatic_access: bool = True) -> dict:
        """
        Cria um usuário IAM com configurações de acesso.
        
        Args:
            username: Nome do usuário
            path: Caminho organizacional
            console_access: Se True, cria senha para console
            programmatic_access: Se True, cria access keys
        """
        resultado = {'username': username}
        
        try:
            # Criar usuário
            all_tags = {'CreatedBy': 'boto3-automation', 'CreatedAt': datetime.now().isoformat()}
            if tags:
                all_tags.update(tags)
            
            self.iam_client.create_user(
                UserName=username,
                Path=path,
                Tags=[{'Key': k, 'Value': v} for k, v in all_tags.items()]
            )
            print(f"✅ Usuário criado: {username}")
            
            # Configurar acesso ao console
            if console_access:
                import secrets
                import string
                
                # Gerar senha temporária segura
                chars = string.ascii_letters + string.digits + '!@#$%^&*'
                senha_temp = ''.join(secrets.choice(chars) for _ in range(16))
                
                self.iam_client.create_login_profile(
                    UserName=username,
                    Password=senha_temp,
                    PasswordResetRequired=True
                )
                resultado['senha_temporaria'] = senha_temp
                print(f"   ✓ Acesso ao console habilitado (senha temporária gerada)")
            
            # Criar access keys
            if programmatic_access:
                response = self.iam_client.create_access_key(UserName=username)
                resultado['access_key'] = {
                    'access_key_id': response['AccessKey']['AccessKeyId'],
                    'secret_access_key': response['AccessKey']['SecretAccessKey']
                }
                print(f"   ✓ Access key criada: {response['AccessKey']['AccessKeyId']}")
            
            return resultado
            
        except ClientError as e:
            if e.response['Error']['Code'] == 'EntityAlreadyExists':
                print(f"ℹ️ Usuário '{username}' já existe")
                return {'username': username, 'exists': True}
            raise
    
    def listar_usuarios(self, detalhado: bool = False) -> list:
        """Lista todos os usuários IAM."""
        usuarios = []
        paginator = self.iam_client.get_paginator('list_users')
        
        for page in paginator.paginate():
            for user in page['Users']:
                info = {
                    'username': user['UserName'],
                    'user_id': user['UserId'],
                    'arn': user['Arn'],
                    'criado_em': user['CreateDate'].isoformat(),
                    'path': user['Path']
                }
                
                if detalhado:
                    # Obter último login
                    try:
                        login_profile = self.iam_client.get_login_profile(
                            UserName=user['UserName']
                        )
                        info['console_access'] = True
                    except ClientError:
                        info['console_access'] = False
                    
                    # Obter access keys
                    keys = self.iam_client.list_access_keys(UserName=user['UserName'])
                    info['access_keys'] = [{
                        'id': k['AccessKeyId'],
                        'status': k['Status'],
                        'criado': k['CreateDate'].isoformat()
                    } for k in keys['AccessKeyMetadata']]
                    
                    # Obter grupos
                    groups = self.iam_client.list_groups_for_user(UserName=user['UserName'])
                    info['grupos'] = [g['GroupName'] for g in groups['Groups']]
                    
                    # MFA

                    info['mfa_habilitado'] = len(mfa['MFADevices']) > 0

    # ROLES
    # ══════════════════════════════════════════════════════════
    
    def criar_role(self, nome: str, servico: str, politicas: list = None,
                   descricao: str = '', max_session: int = 3600) -> str:
        """
        Cria uma IAM Role para um serviço AWS.
        
        Args:
            nome: Nome da role
            servico: Serviço principal (lambda, ec2, ecs-tasks, etc.)
            politicas: Lista de ARNs de políticas gerenciadas
            max_session: Duração máxima da sessão
            
        Returns:
            ARN da role criada
        """
        trust_policy = {
            "Version": "2012-10-17",
            "Statement": [{
                "Effect": "Allow",
                "Principal": {
                    "Service": f"{servico}.amazonaws.com"
                },
                "Action": "sts:AssumeRole"
            }]
        }
        
        try:
            response = self.iam_client.create_role(
                RoleName=nome,
                AssumeRolePolicyDocument=json.dumps(trust_policy),
                Description=descricao or f"Role para {servico}",
                MaxSessionDuration=max_session,
                Tags=[
                    {'Key': 'ManagedBy', 'Value': 'boto3-automation'},
                    {'Key': 'Service', 'Value': servico}
                ]
            )
            
            role_arn = response['Role']['Arn']
            print(f"✅ Role criada: {nome} ({role_arn})")
            
            # Anexar políticas
            if politicas:
                for policy_arn in politicas:
                    self.iam_client.attach_role_policy(
                        RoleName=nome,

def criar_waiter_customizado(client, operation, accepted_states, 
                             failure_states=None, delay=10, max_attempts=30):
    """
    Cria um waiter customizado para qualquer operação.
    
    Args:
        client: boto3 client
        operation: Nome da operação para polling
        accepted_states: Estados que indicam sucesso
        failure_states: Estados que indicam falha

                'maxAttempts': max_attempts,
                'acceptors': [
                    {

                        'expected': state,

                    } for state in accepted_states

            }
        }

        for state in failure_states:

                'matcher': 'pathAny',
                'expected': state,
                'state': 'failure',
                'argument': 'Reservations[].Instances[].State.Name'
            })
    
    waiter_model = WaiterModel(waiter_config)
    return create_waiter_with_client('CustomWaiter', waiter_model, client)

import time

def aguardar_estado(client, verificar_func, timeout=300, intervalo=10):
    """
    Polling manual com timeout e callback.
    
    Args:
        client: boto3 client
        verificar_func: Função que retorna True quando o estado desejado é atingido
        timeout: Timeout total em segundos
        intervalo: Intervalo entre verificações
    """
    inicio = time.time()
    tentativa = 0
    
    while time.time() - inicio < timeout:
        tentativa += 1
        
        try:
            if verificar_func():
                tempo_total = time.time() - inicio
                print(f"✅ Estado desejado atingido em {tempo_total:.1f}s ({tentativa} tentativas)")
                return True
        except Exception as e:
            print(f"   ⚠️ Tentativa {tentativa}: {e}")
        
        time.sleep(intervalo)
    
    raise TimeoutError(f"Timeout de {timeout}s atingido após {tentativa} tentativas")

Operações Multi-Região e Paralelas

Para aplicações globais, é comum precisar executar operações em múltiplas regiões AWS simultaneamente. Combinando boto3 com threading, você pode paralelizar operações e reduzir drasticamente o tempo de execução.

import boto3
from concurrent.futures import ThreadPoolExecutor, as_completed
from botocore.config import Config
import time


class MultiRegionExecutor:
    """
    Executor de operações em múltiplas regiões AWS simultaneamente.
    """
    
    REGIOES_PRINCIPAIS = [
        'us-east-1', 'us-west-2', 'eu-west-1', 'eu-central-1',
        'ap-southeast-1', 'ap-northeast-1', 'sa-east-1'
    ]
    
    def __init__(self, regioes: list = None, max_workers: int = 10):
        self.regioes = regioes or self.REGIOES_PRINCIPAIS
        self.max_workers = max_workers
        self.config = Config(
            retries={'max_attempts': 3, 'mode': 'adaptive'},
            connect_timeout=5,
            read_timeout=10
        )
    
    def executar_em_todas_regioes(self, servico: str, operacao: str,
                                  **kwargs) -> dict:
        """
        Executa uma operação em todas as regiões configuradas.
        
        Args:
            servico: Nome do serviço (ec2, s3, lambda, etc.)
            operacao: Nome da operação
            **kwargs: Parâmetros da operação
            
        Returns:
            Dict com resultados por região
        """
        resultados = {}
        
        def executar_na_regiao(regiao):
            client = boto3.client(servico, region_name=regiao, config=self.config)
            method = getattr(client, operacao)
            return regiao, method(**kwargs)
        
        with ThreadPoolExecutor(max_workers=self.max_workers) as executor:
            futures = {
                executor.submit(executar_na_regiao, regiao): regiao
                for regiao in self.regioes
            }
            
            for future in as_completed(futures):
                regiao = futures[future]
                try:
                    _, resultado = future.result()
                    resultados[regiao] = {'sucesso': True, 'dados': resultado}
                except Exception as e:
                    resultados[regiao] = {'sucesso': False, 'erro': str(e)}
        
        return resultados
    
    def inventario_global(self) -> dict:
        """
        Gera inventário global de recursos em todas as regiões.
        Inclui EC2, RDS, Lambda e S3.
        """
        print("🌍 Gerando inventário global de recursos AWS...")
        print(f"   Regiões: {len(self.regioes)}")
        
        inventario = {
            'ec2_instances': {},
            'lambda_functions': {},
            'rds_instances': {},
            'total_por_regiao': {}
        }
        
        def coletar_ec2(regiao):
            ec2 = boto3.client('ec2', region_name=regiao, config=self.config)
            instances = []
            paginator = ec2.get_paginator('describe_instances')
            for page in paginator.paginate():
                for res in page['Reservations']:
                    instances.extend(res['Instances'])
            return regiao, 'ec2', instances
        
        def coletar_lambda(regiao):
            lmb = boto3.client('lambda', region_name=regiao, config=self.config)
            functions = []
            paginator = lmb.get_paginator('list_functions')
            for page in paginator.paginate():
                functions.extend(page['Functions'])
            return regiao, 'lambda', functions
        
        def coletar_rds(regiao):
            rds = boto3.client('rds', region_name=regiao, config=self.config)
            instances = []
            paginator = rds.get_paginator('describe_db_instances')
            for page in paginator.paginate():
                instances.extend(page['DBInstances'])
            return regiao, 'rds', instances
        
        # Executar coleta em paralelo
        with ThreadPoolExecutor(max_workers=self.max_workers) as executor:
            futures = []
            for regiao in self.regioes:
                futures.append(executor.submit(coletar_ec2, regiao))
                futures.append(executor.submit(coletar_lambda, regiao))
                futures.append(executor.submit(coletar_rds, regiao))
            
            for future in as_completed(futures):
                try:
                    regiao, tipo, recursos = future.result()
                    
                    if tipo == 'ec2':
                        inventario['ec2_instances'][regiao] = len(recursos)
                    elif tipo == 'lambda':
                        inventario['lambda_functions'][regiao] = len(recursos)
                    elif tipo == 'rds':
                        inventario['rds_instances'][regiao] = len(recursos)
                    
                except Exception as e:
                    pass  # Ignorar erros de regiões não habilitadas
        
        # Totais
        inventario['totais'] = {
            'ec2': sum(inventario['ec2_instances'].values()),
            'lambda': sum(inventario['lambda_functions'].values()),
            'rds': sum(inventario['rds_instances'].values())
        }
        
        # Imprimir resumo
        print(f"\n📊 Inventário Global:")
        print(f"   EC2 Instances: {inventario['totais']['ec2']}")
        print(f"   Lambda Functions: {inventario['totais']['lambda']}")
        print(f"   RDS Instances: {inventario['totais']['rds']}")
        
        for regiao in self.regioes:
            ec2_count = inventario['ec2_instances'].get(regiao, 0)
            lambda_count = inventario['lambda_functions'].get(regiao, 0)
            rds_count = inventario['rds_instances'].get(regiao, 0)
            
            if ec2_count + lambda_count + rds_count > 0:

import threading

class RateLimiter:
    """Rate limiter baseado em token bucket para APIs AWS."""
    
    def __init__(self, rate: float, burst: int = None):
        """
        Args:
            rate: Requisições por segundo permitidas
            burst: Máximo de requisições em burst
        """
        self.rate = rate
        self.burst = burst or int(rate)
        self.tokens = self.burst
        self.last_time = time.time()
        self.lock = threading.Lock()
    
    def acquire(self):
        """Adquire um token (bloqueia se necessário)."""
        while True:
            with self.lock:
                now = time.time()
                elapsed = now - self.last_time
                self.last_time = now
                
                # Adicionar tokens baseado no tempo decorrido
                self.tokens = min(
                    self.burst,
                    self.tokens + elapsed * self.rate
                )
                
                if self.tokens >= 1:
                    self.tokens -= 1
                    return
            
            # Aguardar próximo token
            time.sleep(1.0 / self.rate)

# Uso com operações AWS
limiter = RateLimiter(rate=10)  # 10 req/s

def operacao_limitada(client, bucket, key):
    limiter.acquire()  # Espera se necessário
    return client.get_object(Bucket=bucket, Key=key)

class StateManager:
    """Gerencia o estado da infraestrutura em DynamoDB."""
    
    TABLE_NAME = 'infra-cli-state'

        self.dynamodb = boto3.resource('dynamodb', region_name=region)
        self.table = self._garantir_tabela()
    
    def _garantir_tabela(self):
        """Cria tabela de estado se não existir."""

            )

            print(f"   ✅ Tabela de estado criada: {self.TABLE_NAME}")
            return table
        except ClientError as e:
            if e.response['Error']['Code'] == 'ResourceInUseException':
                return self.dynamodb.Table(self.TABLE_NAME)
            raise
    
    def salvar_recurso(self, stack_id: str, resource_type: str,
                       resource_id: str, metadata: dict = None):
        """Salva informações de um recurso no estado."""
        item = {
            'stack_id': stack_id,
            'resource_id': resource_id,
            'resource_type': resource_type,
            'created_at': datetime.now(timezone.utc).isoformat(),
            'metadata': metadata or {}
        }
        self.table.put_item(Item=json.loads(json.dumps(item), parse_float=Decimal))
    
    def listar_recursos(self, stack_id: str) -> list:
        """Lista todos os recursos de uma stack."""
        from boto3.dynamodb.conditions import Key
        response = self.table.query(
            KeyConditionExpression=Key('stack_id').eq(stack_id)
        )
        return response.get('Items', [])
    
    def remover_recurso(self, stack_id: str, resource_id: str):
        """Remove um recurso do estado."""
        self.table.delete_item(
            Key={'stack_id': stack_id, 'resource_id': resource_id}
        )
    
    def remover_stack(self, stack_id: str):
        """Remove toda a stack do estado."""
        recursos = self.listar_recursos(stack_id)
        with self.table.batch_writer() as batch:
            for recurso in recursos:
                batch.delete_item(
                    Key={
                        'stack_id': recurso['stack_id'],
                        'resource_id': recurso['resource_id']
                    }
                )


class VPCProvisioner:
    """Provisiona uma VPC completa com subnets e routing."""
    
    def __init__(self, region: str = 'sa-east-1'):
        self.region = region
        self.ec2 = boto3.client('ec2', region_name=region)
    
    def criar_vpc_completa(self, stack_id: str, cidr: str = '10.0.0.0/16',
                           nome: str = 'infra-cli') -> dict:
        """
        Cria VPC completa com:
        - 2 subnets públicas
        - 2 subnets privadas
        - Internet Gateway
        - Route Tables
        """
        recursos = {}
        
        # 1. Criar VPC
        print(f"\n🏗️ Criando VPC ({cidr})...")
        vpc = self.ec2.create_vpc(
            CidrBlock=cidr,
            TagSpecifications=[{
                'ResourceType': 'vpc',
                'Tags': [
                    {'Key': 'Name', 'Value': f'{nome}-vpc'},
                    {'Key': 'StackId', 'Value': stack_id},
                    {'Key': 'ManagedBy', 'Value': 'infra-cli'}
                ]
            }]
        )
        vpc_id = vpc['Vpc']['VpcId']
        recursos['vpc_id'] = vpc_id
        print(f"   ✅ VPC: {vpc_id}")
        
        # Habilitar DNS
        self.ec2.modify_vpc_attribute(VpcId=vpc_id, EnableDnsHostnames={'Value': True})
        self.ec2.modify_vpc_attribute(VpcId=vpc_id, EnableDnsSupport={'Value': True})
        
        # 2. Criar Internet Gateway
        print(f"   🌐 Criando Internet Gateway...")
        igw = self.ec2.create_internet_gateway(
            TagSpecifications=[{
                'ResourceType': 'internet-gateway',
                'Tags': [
                    {'Key': 'Name', 'Value': f'{nome}-igw'},
                    {'Key': 'StackId', 'Value': stack_id}
                ]
            }]
        )
        igw_id = igw['InternetGateway']['InternetGatewayId']
        self.ec2.attach_internet_gateway(InternetGatewayId=igw_id, VpcId=vpc_id)
        recursos['igw_id'] = igw_id
        print(f"   ✅ IGW: {igw_id}")
        
        # 3. Criar Subnets
        azs = self.ec2.describe_availability_zones(
            Filters=[{'Name': 'state', 'Values': ['available']}]
        )['AvailabilityZones'][:2]
        
        subnets_publicas = []
        subnets_privadas = []
        
        for i, az in enumerate(azs):
            # Subnet pública
            pub_subnet = self.ec2.create_subnet(
                VpcId=vpc_id,
                CidrBlock=f'10.0.{i*10}.0/24',
                AvailabilityZone=az['ZoneName'],
                TagSpecifications=[{
                    'ResourceType': 'subnet',
                    'Tags': [
                        {'Key': 'Name', 'Value': f'{nome}-public-{az["ZoneName"]}'},
                        {'Key': 'StackId', 'Value': stack_id},
                        {'Key': 'Tier', 'Value': 'public'}
                    ]
                }]
            )
            pub_id = pub_subnet['Subnet']['SubnetId']
            subnets_publicas.append(pub_id)
            
            # Habilitar auto-assign IP público
            self.ec2.modify_subnet_attribute(
                SubnetId=pub_id,
                MapPublicIpOnLaunch={'Value': True}
            )
            
            # Subnet privada
            priv_subnet = self.ec2.create_subnet(
                VpcId=vpc_id,
                CidrBlock=f'10.0.{i*10+1}.0/24',
                AvailabilityZone=az['ZoneName'],
                TagSpecifications=[{
                    'ResourceType': 'subnet',
                    'Tags': [
                        {'Key': 'Name', 'Value': f'{nome}-private-{az["ZoneName"]}'},
                        {'Key': 'StackId', 'Value': stack_id},
                        {'Key': 'Tier', 'Value': 'private'}
                    ]
                }]
            )
            priv_id = priv_subnet['Subnet']['SubnetId']
            subnets_privadas.append(priv_id)
        
        recursos['subnets_publicas'] = subnets_publicas
        recursos['subnets_privadas'] = subnets_privadas
        print(f"   ✅ Subnets: {len(subnets_publicas)} públicas, {len(subnets_privadas)} privadas")
        
        # 4. Route Table pública
        print(f"   🛣️ Configurando routing...")
        rtb = self.ec2.create_route_table(
            VpcId=vpc_id,
            TagSpecifications=[{
                'ResourceType': 'route-table',
                'Tags': [{'Key': 'Name', 'Value': f'{nome}-public-rtb'}]
            }]
        )
        rtb_id = rtb['RouteTable']['RouteTableId']
        
        self.ec2.create_route(
            RouteTableId=rtb_id,
            DestinationCidrBlock='0.0.0.0/0',
            GatewayId=igw_id
        )
        
        for subnet_id in subnets_publicas:
            self.ec2.associate_route_table(RouteTableId=rtb_id, SubnetId=subnet_id)
        
        recursos['route_table_id'] = rtb_id
        print(f"   ✅ Route Table: {rtb_id}")
        
        return recursos

class EC2Provisioner:

                        tipo: str = 't3.micro') -> dict:
        """Cria instância EC2 com Security Group."""
        recursos = {}
        
        # 1. Security Group
        print(f"\n🖥️ Provisionando EC2...")
        sg = self.ec2.create_security_group(
            GroupName=f'{nome}-sg-{stack_id[:8]}',
            Description=f'Security Group para {nome}',
            VpcId=vpc_id,
            TagSpecifications=[{
                'ResourceType': 'security-group',
                'Tags': [
                    {'Key': 'Name', 'Value': f'{nome}-sg'},
                    {'Key': 'StackId', 'Value': stack_id}
                ]
            }]
        )
        sg_id = sg['GroupId']
        
        # Regras de ingress
        self.ec2.authorize_security_group_ingress(
            GroupId=sg_id,
            IpPermissions=[
                {'IpProtocol': 'tcp', 'FromPort': 22, 'ToPort': 22,
                 'IpRanges': [{'CidrIp': '0.0.0.0/0', 'Description': 'SSH'}]},
                {'IpProtocol': 'tcp', 'FromPort': 80, 'ToPort': 80,
                 'IpRanges': [{'CidrIp': '0.0.0.0/0', 'Description': 'HTTP'}]},
                {'IpProtocol': 'tcp', 'FromPort': 443, 'ToPort': 443,
                 'IpRanges': [{'CidrIp': '0.0.0.0/0', 'Description': 'HTTPS'}]}
            ]
        )
        recursos['security_group_id'] = sg_id
        print(f"   ✅ Security Group: {sg_id}")
        
        # 2. Buscar AMI mais recente do Amazon Linux 2023
        ami_response = self.ec2.describe_images(
            Owners=['amazon'],
            Filters=[
                {'Name': 'name', 'Values': ['al2023-ami-2023.*-x86_64']},
                {'Name': 'state', 'Values': ['available']}
            ]
        )
        ami_id = sorted(
            ami_response['Images'],
            key=lambda x: x['CreationDate'],
            reverse=True
        )[0]['ImageId']
        
        # 3. User Data script
        user_data = """#!/bin/bash
yum update -y
yum install -y httpd
systemctl start httpd
systemctl enable httpd
echo "
InfraCLI Server - Stack: {stack_id}
" > /var/www/html/index.html
echo "
Provisionado em: $(date)
" >> /var/www/html/index.html
""".format(stack_id=stack_id)
        
        # 4. Lançar instância
        response = self.ec2.run_instances(
            ImageId=ami_id,
            InstanceType=tipo,
            MinCount=1,
            MaxCount=1,
            SubnetId=subnet_id,
            SecurityGroupIds=[sg_id],
            UserData=user_data,
            MetadataOptions={
                'HttpTokens': 'required',
                'HttpEndpoint': 'enabled'
            },
            BlockDeviceMappings=[{
                'DeviceName': '/dev/xvda',
                'Ebs': {'VolumeSize': 20, 'VolumeType': 'gp3', 'Encrypted': True}
            }],
            TagSpecifications=[{
                'ResourceType': 'instance',
                'Tags': [
                    {'Key': 'Name', 'Value': nome},
                    {'Key': 'StackId', 'Value': stack_id},
                    {'Key': 'ManagedBy', 'Value': 'infra-cli'}
                ]
            }]
        )
        
        instance_id = response['Instances'][0]['InstanceId']
        recursos['instance_id'] = instance_id
        recursos['ami_id'] = ami_id
        recursos['instance_type'] = tipo

        print(f"   ⏳ Aguardando instância {instance_id}...")
        waiter = self.ec2.get_waiter('instance_running')
        waiter.wait(InstanceIds=[instance_id])
        
        # Obter IP
        desc = self.ec2.describe_instances(InstanceIds=[instance_id])
        ip = desc['Reservations'][0]['Instances'][0].get('PublicIpAddress', 'N/A')
        recursos['public_ip'] = ip
        
        print(f"   ✅ Instância: {instance_id} | IP: {ip}")
        
        return recursos


class S3Provisioner:
    """Provisiona buckets S3 com configuração de segurança."""
    
    def __init__(self, region: str = 'sa-east-1'):
        self.region = region
        self.s3 = boto3.client('s3', region_name=region)
    
    def criar_bucket(self, stack_id: str, nome_base: str = 'infra-cli') -> dict:
        """Cria bucket S3 com configurações de segurança."""
        recursos = {}
        
        bucket_name = f"{nome_base}-{stack_id[:8]}-{self.region}"
        print(f"\n📦 Criando bucket S3...")
        
        try:
            params = {'Bucket': bucket_name}
            if self.region != 'us-east-1':
                params['CreateBucketConfiguration'] = {
                    'LocationConstraint': self.region
                }
            
            self.s3.create_bucket(**params)
            
            # Criptografia
            self.s3.put_bucket_encryption(
                Bucket=bucket_name,
                ServerSideEncryptionConfiguration={
                    'Rules': [{'ApplyServerSideEncryptionByDefault': {
                        'SSEAlgorithm': 'AES256'
                    }, 'BucketKeyEnabled': True}]
                }
            )
            
            # Bloquear acesso público
            self.s3.put_public_access_block(
                Bucket=bucket_name,
                PublicAccessBlockConfiguration={
                    'BlockPublicAcls': True,
                    'IgnorePublicAcls': True,
                    'BlockPublicPolicy': True,
                    'RestrictPublicBuckets': True
                }
            )
            
            # Versionamento
            self.s3.put_bucket_versioning(
                Bucket=bucket_name,
                VersioningConfiguration={'Status': 'Enabled'}
            )
            
            # Tags
            self.s3.put_bucket_tagging(
                Bucket=bucket_name,
                Tagging={'TagSet': [
                    {'Key': 'StackId', 'Value': stack_id},
                    {'Key': 'ManagedBy', 'Value': 'infra-cli'}
                ]}
            )
            
            recursos['bucket_name'] = bucket_name
            print(f"   ✅ Bucket: {bucket_name}")
            print(f"      ✓ Criptografia AES256")
            print(f"      ✓ Acesso público bloqueado")
            print(f"      ✓ Versionamento habilitado")
            
        except ClientError as e:
            print(f"   ❌ Erro ao criar bucket: {e}")
        
        return recursos


class CostEstimator:
    """Estima custos mensais da infraestrutura provisionada."""
    
    # Preços aproximados (us-east-1, pode variar)
    PRECOS = {
        'ec2': {
            't3.micro': 0.0104,    # por hora
            't3.small': 0.0208,
            't3.medium': 0.0416,
            't3.large': 0.0832,
            'm5.large': 0.096,
            'm5.xlarge': 0.192
        },
        's3': {
            'storage_gb': 0.023,        # por GB/mês
            'requests_1000': 0.005      # por 1000 requests
        },
        'ebs': {
            'gp3_gb': 0.08             # por GB/mês
        },
        'data_transfer': {
            'out_gb': 0.09             # por GB (primeiros 10TB)
        }
    }
    
    def estimar(self, recursos: dict) -> dict:
        """Estima custo mensal baseado nos recursos."""
        custos = {}
        
        # EC2
        if 'instance_type' in recursos:
            tipo = recursos['instance_type']
            preco_hora = self.PRECOS['ec2'].get(tipo, 0.05)
            custos['ec2'] = preco_hora * 730  # horas/mês
        
        # EBS
        if 'ebs_size_gb' in recursos:
            custos['ebs'] = recursos['ebs_size_gb'] * self.PRECOS['ebs']['gp3_gb']
        else:
            custos['ebs'] = 20 * self.PRECOS['ebs']['gp3_gb']  # 20GB padrão
        
        # S3 (estimativa base)
        custos['s3'] = 1 * self.PRECOS['s3']['storage_gb']  # 1GB estimado
        
        # VPC (NAT Gateway se existir)
        if recursos.get('nat_gateway'):
            custos['nat_gateway'] = 0.045 * 730 + 0.045 * 100  # hora + dados
        
        total = sum(custos.values())
        
        return {
            'detalhamento': custos,
            'total_mensal': round(total, 2),
            'total_anual': round(total * 12, 2)
        }


class InfraCLI:
    """Orquestrador principal da CLI de infraestrutura."""
    
    def __init__(self, region: str = 'sa-east-1'):
        self.region = region
        self.state = StateManager(region)
        self.vpc_prov = VPCProvisioner(region)
        self.ec2_prov = EC2Provisioner(region)
        self.s3_prov = S3Provisioner(region)
        self.estimator = CostEstimator()
    
    def create(self, nome: str = 'minha-infra'):
        """Cria toda a infraestrutura."""
        stack_id = f"stack-{uuid.uuid4().hex[:12]}"
        
        print(f"{'='*60}")
        print(f"🚀 InfraCLI - Criando Stack: {stack_id}")
        print(f"   Nome: {nome} | Região: {self.region}")
        print(f"{'='*60}")
        
        todos_recursos = {'stack_id': stack_id}
        
        try:
            # 1. VPC
            vpc_recursos = self.vpc_prov.criar_vpc_completa(stack_id, nome=nome)
            todos_recursos.update(vpc_recursos)
            
            for key, value in vpc_recursos.items():
                if isinstance(value, str):
                    self.state.salvar_recurso(stack_id, 'vpc', value, {'tipo': key})
                elif isinstance(value, list):
                    for v in value:
                        self.state.salvar_recurso(stack_id, 'subnet', v, {'tipo': key})
            
            # 2. EC2
            ec2_recursos = self.ec2_prov.criar_instancia(
                stack_id, vpc_recursos['vpc_id'],
                vpc_recursos['subnets_publicas'][0], nome=f'{nome}-server'
            )
            todos_recursos.update(ec2_recursos)
            self.state.salvar_recurso(
                stack_id, 'ec2', ec2_recursos['instance_id'],
                ec2_recursos
            )
            
            # 3. S3
            s3_recursos = self.s3_prov.criar_bucket(stack_id, nome_base=nome)
            todos_recursos.update(s3_recursos)
            if 'bucket_name' in s3_recursos:
                self.state.salvar_recurso(
                    stack_id, 's3', s3_recursos['bucket_name']
                )
            
            # 4. Estimativa de custo
            estimativa = self.estimator.estimar(todos_recursos)
            
            # Resumo final
            print(f"\n{'='*60}")
            print(f"✅ STACK CRIADA COM SUCESSO!")
            print(f"{'='*60}")
            print(f"   Stack ID: {stack_id}")
            print(f"   VPC: {vpc_recursos['vpc_id']}")
            print(f"   EC2: {ec2_recursos['instance_id']} ({ec2_recursos.get('public_ip', 'N/A')})")
            print(f"   S3: {s3_recursos.get('bucket_name', 'N/A')}")
            print(f"\n   💰 Custo estimado: ${estimativa['total_mensal']}/mês (${estimativa['total_anual']}/ano)")
            print(f"\n   📝 Para destruir: python infra_cli.py destroy --stack-id {stack_id}")
            
            return todos_recursos
            
        except Exception as e:
            print(f"\n❌ ERRO durante criação: {e}")
            print(f"   Alguns recursos podem ter sido criados.")
            print(f"   Use: python infra_cli.py destroy --stack-id {stack_id}")
            raise
    
    def destroy(self, stack_id: str):
        """Destroi toda a infraestrutura de uma stack."""
        print(f"\n{'='*60}")
        print(f"🗑️ InfraCLI - Destruindo Stack: {stack_id}")
        print(f"{'='*60}")
        
        recursos = self.state.listar_recursos(stack_id)
        
        if not recursos:
            print(f"   ❌ Nenhum recurso encontrado para stack '{stack_id}'")
            return
        
        print(f"   Encontrados {len(recursos)} recursos para remover\n")
        
        ec2 = boto3.client('ec2', region_name=self.region)
        s3 = boto3.client('s3', region_name=self.region)
        s3_resource = boto3.resource('s3', region_name=self.region)
        
        # Ordem de destruição: EC2 → S3 → Subnets → IGW → VPC
        # 1. EC2
        for r in recursos:
            if r['resource_type'] == 'ec2':
                print(f"   🗑️ Terminando EC2: {r['resource_id']}")
                try:
                    ec2.terminate_instances(InstanceIds=[r['resource_id']])
                except ClientError:
                    pass
        
        # Aguardar termination
        ec2_ids = [r['resource_id'] for r in recursos if r['resource_type'] == 'ec2']
        if ec2_ids:
            waiter = ec2.get_waiter('instance_terminated')
            waiter.wait(InstanceIds=ec2_ids)
            print(f"   ✅ Instâncias EC2 terminadas")
        
        # 2. Security Groups
        time.sleep(5)  # Aguardar ENIs serem liberados
        for r in recursos:
            if r['resource_type'] == 'vpc' and r.get('metadata', {}).get('tipo') == 'security_group_id':
                print(f"   🗑️ Deletando SG: {r['resource_id']}")
                try:
                    ec2.delete_security_group(GroupId=r['resource_id'])
                except ClientError:
                    pass
        
        # 3. S3
        for r in recursos:
            if r['resource_type'] == 's3':
                print(f"   🗑️ Deletando bucket: {r['resource_id']}")
                try:
                    bucket = s3_resource.Bucket(r['resource_id'])
                    bucket.object_versions.delete()
                    bucket.delete()
                except ClientError:
                    pass
        
        # 4. Subnets, Route Tables, IGW, VPC
        # ... (lógica similar para cada tipo)
        
        # Limpar estado
        self.state.remover_stack(stack_id)
        
        print(f"\n✅ Stack '{stack_id}' destruída com sucesso!")
    
    def status(self, stack_id: str = None):
        """Mostra status da infraestrutura."""
        if stack_id:
            recursos = self.state.listar_recursos(stack_id)
            print(f"\n📊 Status da Stack: {stack_id}")
            print(f"   Recursos: {len(recursos)}")
            for r in recursos:
                print(f"   - [{r['resource_type']}] {r['resource_id']}")

            # Listar todas as stacks
            table = self.state.table
            response = table.scan(
                ProjectionExpression='stack_id',
                Select='SPECIFIC_ATTRIBUTES'
            )
            stacks = set(item['stack_id'] for item in response.get('Items', []))
            print(f"\n📊 Stacks encontradas: {len(stacks)}")
            for s in stacks:
                print(f"   - {s}")

from datetime import datetime
from botocore.exceptions import ClientError
import logging

logging.basicConfig(level=logging.INFO, format='%(asctime)s - %(levelname)s - %(message)s')
logger = logging.getLogger(__name__)


class BackupManager:
    def __init__(self, bucket: str, region: str = 'sa-east-1'):
        self.bucket = bucket
        self.s3 = boto3.client('s3', region_name=region)
    
    def executar_backup(self, diretorio: str, prefixo: str = 'backups',
                        manter: int = 7):
        """Executa backup completo com compressão e rotação."""
        agora = datetime.now()
        key = f"{prefixo}/{agora.strftime('%Y/%m/%d')}/backup_{agora.strftime('%H%M%S')}.tar.gz"
        
        # 1. Comprimir
        logger.info(f"Comprimindo '{diretorio}'...")
        with tempfile.NamedTemporaryFile(suffix='.tar.gz', delete=False) as tmp:
            tmp_path = tmp.name
        
        try:
            with tarfile.open(tmp_path, 'w:gz') as tar:
                tar.add(diretorio, arcname=os.path.basename(diretorio))
            
            tamanho = os.path.getsize(tmp_path)
            logger.info(f"Arquivo comprimido: {tamanho / 1024 / 1024:.2f} MB")
            
            # 2. Upload
            logger.info(f"Uploading para s3://{self.bucket}/{key}")
            self.s3.upload_file(
                tmp_path, self.bucket, key,
                ExtraArgs={'ServerSideEncryption': 'AES256'}
            )
            logger.info("Upload concluído!")
            
            # 3. Rotação
            self._rotacionar_backups(prefixo, manter)
            
        finally:
            os.unlink(tmp_path)
    
    def _rotacionar_backups(self, prefixo: str, manter: int):
        """Remove backups antigos mantendo apenas os N mais recentes."""
        paginator = self.s3.get_paginator('list_objects_v2')
        objetos = []
        
        for page in paginator.paginate(Bucket=self.bucket, Prefix=prefixo):
            objetos.extend(page.get('Contents', []))
        
        # Ordenar por data (mais recente primeiro)
        objetos.sort(key=lambda x: x['LastModified'], reverse=True)
        
        # Remover excedentes
        if len(objetos) > manter:
            for obj in objetos[manter:]:
                self.s3.delete_object(Bucket=self.bucket, Key=obj['Key'])
                logger.info(f"Backup antigo removido: {obj['Key']}")

import boto3
from datetime import datetime, timedelta, timezone


class EC2Monitor:
    def __init__(self, region: str = 'sa-east-1'):
        self.ec2 = boto3.client('ec2', region_name=region)
        self.cw = boto3.client('cloudwatch', region_name=region)
    
    def verificar_saude(self) -> dict:
        """Verifica saúde de todas as instâncias EC2."""
        # Listar instâncias running
        response = self.ec2.describe_instances(
            Filters=[{'Name': 'instance-state-name', 'Values': ['running']}]
        )
        
        instancias = []
        for res in response['Reservations']:
            for inst in res['Instances']:
                nome = next(
                    (t['Value'] for t in inst.get('Tags', []) if t['Key'] == 'Name'),
                    'Sem nome'
                )
                instancias.append({
                    'id': inst['InstanceId'],
                    'nome': nome,
                    'tipo': inst['InstanceType'],
                    'ip': inst.get('PublicIpAddress', 'N/A')
                })
        
        # Verificar status checks
        status_response = self.ec2.describe_instance_status(
            InstanceIds=[i['id'] for i in instancias]
        )
        
        status_map = {}
        for s in status_response['InstanceStatuses']:
            status_map[s['InstanceId']] = {
                'system': s['SystemStatus']['Status'],
                'instance': s['InstanceStatus']['Status']
            }
        
        # Verificar CPU via CloudWatch
        saudaveis = 0
        problematicas = []
        
        for inst in instancias:
            status = status_map.get(inst['id'], {})
            inst['system_status'] = status.get('system', 'unknown')
            inst['instance_status'] = status.get('instance', 'unknown')
            
            # CPU
            cpu = self._obter_cpu(inst['id'])
            inst['cpu_percent'] = cpu
            
            if inst['system_status'] == 'ok' and inst['instance_status'] == 'ok' and cpu < 80:
                saudaveis += 1
                inst['saude'] = '✅ Saudável'
            else:
                problematicas.append(inst)
                inst['saude'] = '⚠️ Atenção'
        
        # Publicar métrica
        self.cw.put_metric_data(
            Namespace='CustomMonitor/EC2',
            MetricData=[{
                'MetricName': 'HealthyInstances',
                'Value': saudaveis,
                'Unit': 'Count'
            }]
        )
        
        # Relatório
        print(f"\n{'='*70}")
        print(f"📊 Relatório EC2 - {datetime.now().strftime('%Y-%m-%d %H:%M')}")
        print(f"{'='*70}")
        print(f"{'ID':<22} {'Nome':<20} {'Tipo':<12} {'CPU%':<6} {'Status'}")
        print(f"{'-'*70}")
        for inst in instancias:
            print(f"{inst['id']:<22} {inst['nome']:<20} {inst['tipo']:<12} "
                  f"{inst['cpu_percent']:<6.1f} {inst['saude']}")
        print(f"\nTotal: {len(instancias)} | Saudáveis: {saudaveis} | Atenção: {len(problematicas)}")
        
        return {'total': len(instancias), 'saudaveis': saudaveis}
    
    def _obter_cpu(self, instance_id: str) -> float:
        """Obtém CPU média dos últimos 5 minutos."""
        response = self.cw.get_metric_statistics(
            Namespace='AWS/EC2',
            MetricName='CPUUtilization',
            Dimensions=[{'Name': 'InstanceId', 'Value': instance_id}],
            StartTime=datetime.now(timezone.utc) - timedelta(minutes=10),
            EndTime=datetime.now(timezone.utc),
            Period=300,
            Statistics=['Average']
        )
        datapoints = response.get('Datapoints', [])
        return datapoints[-1]['Average'] if datapoints else 0.0

import boto3
import json

from datetime import datetime


class NotificationSystem:
    """Sistema de notificações com SQS."""
    
    def __init__(self, region: str = 'sa-east-1'):
        self.sqs = boto3.client('sqs', region_name=region)
        self.queue_url = None
        self.dlq_url = None
        self._setup_queues()
    
    def _setup_queues(self):
        """Configura filas."""
        # DLQ
        dlq = self.sqs.create_queue(
            QueueName='notificacoes-dlq',
            Attributes={'MessageRetentionPeriod': '1209600'}
        )
        self.dlq_url = dlq['QueueUrl']
        
        # Obter ARN da DLQ
        dlq_attrs = self.sqs.get_queue_attributes(
            QueueUrl=self.dlq_url, AttributeNames=['QueueArn']
        )
        dlq_arn = dlq_attrs['Attributes']['QueueArn']
        
        # Fila principal
        main = self.sqs.create_queue(
            QueueName='notificacoes',
            Attributes={
                'VisibilityTimeout': '30',
                'RedrivePolicy': json.dumps({
                    'deadLetterTargetArn': dlq_arn,
                    'maxReceiveCount': '3'
                })
            }
        )
        self.queue_url = main['QueueUrl']
    
    def enviar_notificacao(self, tipo: str, destinatario: str, mensagem: str):
        """Envia notificação para a fila."""
        payload = {
            'id': str(uuid.uuid4()),
            'tipo': tipo,  # email, sms, push
            'destinatario': destinatario,
            'mensagem': mensagem,
            'timestamp': datetime.now().isoformat()
        }
        
        self.sqs.send_message(
            QueueUrl=self.queue_url,
            MessageBody=json.dumps(payload),
            MessageAttributes={
                'tipo': {'DataType': 'String', 'StringValue': tipo}
            }
        )
        print(f"📨 Notificação enviada: {tipo} → {destinatario}")
    
    def processar_notificacoes(self):
        """Consumer que processa notificações."""
        running = True
        
        def shutdown(sig, frame):
            nonlocal running
            running = False
            print("\n⏹️ Encerrando consumidor...")
        
        signal.signal(signal.SIGINT, shutdown)
        print("🎧 Consumidor de notificações iniciado (Ctrl+C para parar)")
        
        while running:
            response = self.sqs.receive_message(
                QueueUrl=self.queue_url,
                MaxNumberOfMessages=5,
                WaitTimeSeconds=10,
                MessageAttributeNames=['All']
            )
            
            for msg in response.get('Messages', []):
                try:
                    payload = json.loads(msg['Body'])
                    self._processar(payload)
                    
                    # Confirmar processamento
                    self.sqs.delete_message(
                        QueueUrl=self.queue_url,
                        ReceiptHandle=msg['ReceiptHandle']
                    )
                except Exception as e:
                    print(f"   ❌ Erro: {e} (será retentada)")
        
        print("👋 Consumidor encerrado")
    
    def _processar(self, payload: dict):
        """Processa uma notificação por tipo."""
        tipo = payload['tipo']
        
        if tipo == 'email':
            print(f"   📧 Email para {payload['destinatario']}: {payload['mensagem'][:50]}")
        elif tipo == 'sms':
            print(f"   📱 SMS para {payload['destinatario']}: {payload['mensagem'][:30]}")
        elif tipo == 'push':
            print(f"   🔔 Push para {payload['destinatario']}: {payload['mensagem'][:30]}")
        
        time.sleep(0.5)  # Simular processamento

import boto3
from boto3.dynamodb.conditions import Key, Attr
from decimal import Decimal
import uuid
import json


class ProductCatalog:
    """Catálogo de produtos com DynamoDB."""
    
    TABLE_NAME = 'product-catalog'
    
    def __init__(self, region: str = 'sa-east-1'):
        self.dynamodb = boto3.resource('dynamodb', region_name=region)
        self.table = self._setup_table()
    
    def _setup_table(self):
        """Cria tabela se não existir."""
        try:
            table = self.dynamodb.create_table(
                TableName=self.TABLE_NAME,
                KeySchema=[
                    {'AttributeName': 'categoria', 'KeyType': 'HASH'},
                    {'AttributeName': 'produto_id', 'KeyType': 'RANGE'}
                ],
                AttributeDefinitions=[
                    {'AttributeName': 'categoria', 'AttributeType': 'S'},
                    {'AttributeName': 'produto_id', 'AttributeType': 'S'},
                    {'AttributeName': 'preco', 'AttributeType': 'N'}
                ],
                GlobalSecondaryIndexes=[{
                    'IndexName': 'PrecoIndex',
                    'KeySchema': [
                        {'AttributeName': 'categoria', 'KeyType': 'HASH'},
                        {'AttributeName': 'preco', 'KeyType': 'RANGE'}
                    ],
                    'Projection': {'ProjectionType': 'ALL'}
                }],
                BillingMode='PAY_PER_REQUEST'
            )
            table.wait_until_exists()
            return table
        except Exception:
            return self.dynamodb.Table(self.TABLE_NAME)
    
    def criar_produto(self, categoria: str, nome: str, preco: float,
                      estoque: int = 0, descricao: str = '') -> dict:
        """Cria um novo produto."""
        produto = {
            'categoria': categoria,
            'produto_id': f'prod_{uuid.uuid4().hex[:8]}',
            'nome': nome,
            'preco': Decimal(str(preco)),
            'estoque': estoque,
            'descricao': descricao,
            'ativo': True,
            'created_at': str(uuid.uuid1().time)
        }
        
        self.table.put_item(Item=produto)
        print(f"✅ Produto criado: {produto['produto_id']} - {nome}")
        return produto
    
    def buscar_por_categoria(self, categoria: str, limit: int = 20) -> list:
        """Busca produtos por categoria."""
        response = self.table.query(
            KeyConditionExpression=Key('categoria').eq(categoria),
            Limit=limit
        )
        return response['Items']
    
    def buscar_por_faixa_preco(self, categoria: str,
                               preco_min: float, preco_max: float) -> list:
        """Busca produtos por faixa de preço usando GSI."""
        response = self.table.query(
            IndexName='PrecoIndex',
            KeyConditionExpression=(
                Key('categoria').eq(categoria) &
                Key('preco').between(Decimal(str(preco_min)), Decimal(str(preco_max)))
            )
        )
        return response['Items']
    
    def atualizar_estoque(self, categoria: str, produto_id: str, quantidade: int):
        """Atualiza estoque com operação atômica."""
        response = self.table.update_item(
            Key={'categoria': categoria, 'produto_id': produto_id},
            UpdateExpression='SET estoque = estoque + :qty',
            ExpressionAttributeValues={':qty': quantidade},
            ReturnValues='ALL_NEW'
        )
        novo_estoque = response['Attributes']['estoque']
        print(f"📦 Estoque atualizado: {produto_id} = {novo_estoque}")
        return response['Attributes']
    
    def importar_batch(self, produtos: list):
        """Importa produtos em batch."""
        with self.table.batch_writer() as batch:
            for p in produtos:
                p['preco'] = Decimal(str(p['preco']))
                p['produto_id'] = p.get('produto_id', f'prod_{uuid.uuid4().hex[:8]}')
                batch.put_item(Item=p)
        print(f"✅ {len(produtos)} produtos importados")

Exercício 5 — Deploy Automatizado Lambda

Objetivo: Criar um pipeline de deploy para funções Lambda com versionamento, aliases e rollback automático em caso de erro.

📝 Requisitos

  • Empacotar código Python em zip automaticamente
  • Criar/atualizar função Lambda
  • Publicar nova versão e atualizar alias 'live'
  • Testar invocação após deploy
  • Rollback automático se o teste falhar
  • Log de todas as operações
💡 Resposta 
import boto3
import zipfile
import os
import json
import tempfile
from botocore.exceptions import ClientError


class LambdaDeployer:
    """Pipeline de deploy Lambda com rollback."""
    
    def __init__(self, region: str = 'sa-east-1'):
        self.lambda_client = boto3.client('lambda', region_name=region)
    
    def deploy_com_teste(self, function_name: str, source_dir: str,
                         test_event: dict = None) -> bool:
        """
        Deploy com teste automático e rollback.
        
        Returns:
            True se deploy foi bem-sucedido
        """
        print(f"🚀 Deploy: {function_name}")
        
        # 1. Obter versão atual do alias (para rollback)
        versao_anterior = self._obter_versao_alias(function_name, 'live')
        
        # 2. Empacotar e atualizar código
        zip_bytes = self._empacotar(source_dir)
        
        response = self.lambda_client.update_function_code(
            FunctionName=function_name,
            ZipFile=zip_bytes,
            Publish=True
        )
        nova_versao = response['Version']
        print(f"   ✅ Código atualizado: versão {nova_versao}")
        
        # 3. Atualizar alias
        self._atualizar_alias(function_name, 'live', nova_versao)
        
        # 4. Testar
        if test_event:
            print(f"   🧪 Executando teste...")
            sucesso = self._testar_funcao(function_name, test_event)
            
            if not sucesso:
                print(f"   ❌ Teste FALHOU! Iniciando rollback...")
                if versao_anterior:
                    self._atualizar_alias(function_name, 'live', versao_anterior)
                    print(f"   ↩️ Rollback para versão {versao_anterior}")
                return False
            
            print(f"   ✅ Teste passou!")
        
        print(f"   🎉 Deploy concluído! Versão: {nova_versao}")
        return True
    
    def _empacotar(self, source_dir: str) -> bytes:
        """Empacota código em zip."""
        with tempfile.NamedTemporaryFile(suffix='.zip', delete=False) as tmp:
            with zipfile.ZipFile(tmp.name, 'w', zipfile.ZIP_DEFLATED) as zf:
                for root, dirs, files in os.walk(source_dir):
                    dirs[:] = [d for d in dirs if d != '__pycache__']
                    for f in files:
                        if f.endswith('.pyc'):
                            continue
                        path = os.path.join(root, f)
                        arcname = os.path.relpath(path, source_dir)
                        zf.write(path, arcname)
            
            with open(tmp.name, 'rb') as f:
                return f.read()
    
    def _obter_versao_alias(self, function_name: str, alias: str) -> str:
        """Obtém versão atual de um alias."""
        try:
            response = self.lambda_client.get_alias(
                FunctionName=function_name, Name=alias
            )
            return response['FunctionVersion']
        except ClientError:
            return None
    
    def _atualizar_alias(self, function_name: str, alias: str, version: str):
        """Cria ou atualiza alias."""
        try:
            self.lambda_client.update_alias(
                FunctionName=function_name, Name=alias,
                FunctionVersion=version
            )
        except ClientError:
            self.lambda_client.create_alias(
                FunctionName=function_name, Name=alias,
                FunctionVersion=version
            )
    
    def _testar_funcao(self, function_name: str, event: dict) -> bool:
        """Invoca função e verifica resultado."""
        try:
            response = self.lambda_client.invoke(
                FunctionName=function_name,
                Qualifier='live',
                Payload=json.dumps(event)
            )
            
            if response.get('FunctionError'):
                return False
            
            payload = json.loads(response['Payload'].read())
            status = payload.get('statusCode', 200)
            return 200 <= status < 400
            
        except Exception:
            return False

        else:
            print("   ✅ Root MFA habilitado")
        
        if summary.get('AccountAccessKeysPresent'):
            self._add_finding('CRITICAL', 'Root com access keys', -25)

        """Verifica MFA dos usuários."""
        users = self.iam.list_users()['Users']

                self.iam.get_login_profile(UserName=user['UserName'])

                mfa = self.iam.list_mfa_devices(UserName=user['UserName'])
                if not mfa['MFADevices']:
                    self._add_finding(
                        'HIGH',
                        f"Usuário '{user['UserName']}' sem MFA (console access)",
                        -10
                    )

from concurrent.futures import ThreadPoolExecutor, as_completed
from botocore.config import Config
import json
from datetime import datetime


class MultiRegionInventory:
    """Inventário de recursos AWS em múltiplas regiões."""
    
    def __init__(self):
        self.config = Config(retries={'max_attempts': 3, 'mode': 'adaptive'})
        self.regioes = self._obter_regioes()
    
    def _obter_regioes(self) -> list:
        """Obtém todas as regiões habilitadas."""
        ec2 = boto3.client('ec2', region_name='us-east-1')
        response = ec2.describe_regions(
            Filters=[{'Name': 'opt-in-status', 'Values': ['opt-in-not-required', 'opted-in']}]
        )
        return [r['RegionName'] for r in response['Regions']]
    
    def inventario_completo(self) -> dict:
        """Gera inventário completo em paralelo."""
        print(f"🌍 Inventário Global ({len(self.regioes)} regiões)")
        
        inventario = {}
        
        with ThreadPoolExecutor(max_workers=15) as executor:
            futures = {}
            
            for regiao in self.regioes:
                futures[executor.submit(self._coletar_ec2, regiao)] = (regiao, 'ec2')
                futures[executor.submit(self._coletar_lambda, regiao)] = (regiao, 'lambda')
                futures[executor.submit(self._coletar_dynamodb, regiao)] = (regiao, 'dynamodb')
            
            for future in as_completed(futures):
                regiao, servico = futures[future]
                try:
                    resultado = future.result()
                    if regiao not in inventario:
                        inventario[regiao] = {}
                    inventario[regiao][servico] = resultado
                except Exception:
                    pass
        
        # S3 é global
        inventario['global'] = {'s3': self._coletar_s3()}
        
        # Resumo
        self._imprimir_resumo(inventario)
        
        # Exportar
        with open('inventario_aws.json', 'w') as f:
            json.dump(inventario, f, indent=2, default=str)
        print(f"\n📄 Exportado para inventario_aws.json")
        
        return inventario
    
    def _coletar_ec2(self, regiao: str) -> list:
        ec2 = boto3.client('ec2', region_name=regiao, config=self.config)
        instances = []
        paginator = ec2.get_paginator('describe_instances')
        for page in paginator.paginate():
            for res in page['Reservations']:
                for inst in res['Instances']:
                    instances.append({
                        'id': inst['InstanceId'],
                        'type': inst['InstanceType'],
                        'state': inst['State']['Name']
                    })

    def _coletar_lambda(self, regiao: str) -> list:
        lmb = boto3.client('lambda', region_name=regiao, config=self.config)
        functions = []
        paginator = lmb.get_paginator('list_functions')
        for page in paginator.paginate():
            for func in page['Functions']:
                functions.append({
                    'name': func['FunctionName'],
                    'runtime': func.get('Runtime', 'N/A'),
                    'memory': func['MemorySize']
                })
        return functions
    
    def _coletar_dynamodb(self, regiao: str) -> list:
        ddb = boto3.client('dynamodb', region_name=regiao, config=self.config)
        tables = []
        paginator = ddb.get_paginator('list_tables')
        for page in paginator.paginate():
            tables.extend(page['TableNames'])
        return tables
    
    def _coletar_s3(self) -> list:
        s3 = boto3.client('s3')
        response = s3.list_buckets()
        return [b['Name'] for b in response['Buckets']]

        total_ec2 = sum(len(v.get('ec2', [])) for v in inventario.values())
        total_lambda = sum(len(v.get('lambda', [])) for v in inventario.values())
        total_ddb = sum(len(v.get('dynamodb', [])) for v in inventario.values())
        total_s3 = len(inventario.get('global', {}).get('s3', []))
        
        print(f"\n📊 Resumo:")
        print(f"   EC2: {total_ec2} | Lambda: {total_lambda} | DynamoDB: {total_ddb} | S3: {total_s3}")

class TagComplianceManager:

    TAGS_PADRAO = {
        'Environment': 'development',
        'Team': 'unassigned',
        'Project': 'unassigned',
        'CostCenter': 'unassigned'
    }
    
    def __init__(self, region: str = 'sa-east-1'):

        resultados = {
            'ec2': self._auditar_ec2(auto_fix),
            's3': self._auditar_s3(auto_fix)
        }
        
        # Calcular compliance
        total = sum(r['total'] for r in resultados.values())

        compliance = (conforme / total * 100) if total > 0 else 100

        print(f"\n📋 EC2 Instances:")
        
        response = self.ec2.describe_instances()
        total = 0
        conforme = 0
        
        for res in response['Reservations']:
            for inst in res['Instances']:
                total += 1
                tags = {t['Key']: t['Value'] for t in inst.get('Tags', [])}
                faltantes = [t for t in self.TAGS_OBRIGATORIAS if t not in tags]
                
                if not faltantes:
                    conforme += 1
                else:
                    nome = tags.get('Name', inst['InstanceId'])
                    print(f"   ⚠️ {nome}: faltam {faltantes}")
                    
                    if auto_fix:
                        novas_tags = [
                            {'Key': k, 'Value': self.TAGS_PADRAO[k]}
                            for k in faltantes
                        ]
                        self.ec2.create_tags(
                            Resources=[inst['InstanceId']],
                            Tags=novas_tags
                        )
                        print(f"      ✅ Tags padrão aplicadas")
        
        return {'total': total, 'conforme': conforme}
    
    def _auditar_s3(self, auto_fix: bool) -> dict:
        """Audita tags em buckets S3."""
        print(f"\n📋 S3 Buckets:")
        
        response = self.s3.list_buckets()
        total = len(response['Buckets'])
        conforme = 0
        
        for bucket in response['Buckets']:

                tags = {}
            
            faltantes = [t for t in self.TAGS_OBRIGATORIAS if t not in tags]
            
            if not faltantes:
                conforme += 1
            else:
                print(f"   ⚠️ {bucket['Name']}: faltam {faltantes}")
                
                if auto_fix:
                    all_tags = [{'Key': k, 'Value': v} for k, v in tags.items()]
                    all_tags.extend([
                        {'Key': k, 'Value': self.TAGS_PADRAO[k]}
                        for k in faltantes
                    ])
                    self.s3.put_bucket_tagging(
                        Bucket=bucket['Name'],
                        Tagging={'TagSet': all_tags}
                    )
                    print(f"      ✅ Tags padrão aplicadas")
        
        return {'total': total, 'conforme': conforme}

class OrphanCleaner:

    PRECO_EIP = 0.005 * 730  # $0.005/hora quando não associado

        self.ec2 = boto3.client('ec2', region_name=region)

        economia_total = 0
        
        # 1. EBS Volumes
        volumes = self._volumes_orfaos()
        economia_ebs = sum(v['size'] for v in volumes) * self.PRECO_EBS_GP3

        for v in volumes[:5]:
            print(f"   - {v['id']} ({v['size']}GB, {v['type']}) criado: {v['created']}")

            for v in volumes:
                self.ec2.delete_volume(VolumeId=v['id'])
            print(f"   ✅ {len(volumes)} volumes deletados")
        
        # 2. Elastic IPs
        eips = self._eips_orfaos()
        economia_eip = len(eips) * self.PRECO_EIP
        economia_total += economia_eip
        
        print(f"\n🌐 Elastic IPs não associados: {len(eips)}")
        for eip in eips:
            print(f"   - {eip['ip']} ({eip['allocation_id']})")
        
        if not dry_run and eips:
            for eip in eips:
                self.ec2.release_address(AllocationId=eip['allocation_id'])
            print(f"   ✅ {len(eips)} EIPs liberados")
        
        # 3. Snapshots antigos
        snaps = self._snapshots_orfaos(dias=30)
        economia_snap = sum(s['size'] for s in snaps) * self.PRECO_SNAPSHOT
        economia_total += economia_snap
        
        print(f"\n📸 Snapshots antigos sem AMI: {len(snaps)}")
        for s in snaps[:5]:
            print(f"   - {s['id']} ({s['size']}GB) de: {s['created']}")
        
        if not dry_run and snaps:
            for s in snaps:
                self.ec2.delete_snapshot(SnapshotId=s['id'])
            print(f"   ✅ {len(snaps)} snapshots deletados")
        
        # Resumo
        print(f"\n{'='*50}")
        print(f"💰 Economia estimada: ${economia_total:.2f}/mês")
        print(f"   EBS: ${economia_ebs:.2f} | EIP: ${economia_eip:.2f} | Snaps: ${economia_snap:.2f}")
        
        return {'economia_mensal': economia_total}
    
    def _volumes_orfaos(self) -> list:
        response = self.ec2.describe_volumes(
            Filters=[{'Name': 'status', 'Values': ['available']}]
        )
        return [{
            'id': v['VolumeId'],
            'size': v['Size'],
            'type': v['VolumeType'],
            'created': v['CreateTime'].strftime('%Y-%m-%d')
        } for v in response['Volumes']]
    
    def _eips_orfaos(self) -> list:
        response = self.ec2.describe_addresses()
        return [{
            'ip': addr['PublicIp'],
            'allocation_id': addr['AllocationId']
        } for addr in response['Addresses'] if 'InstanceId' not in addr and 'NetworkInterfaceId' not in addr]
    
    def _snapshots_orfaos(self, dias: int = 30) -> list:
        limite = datetime.now(timezone.utc) - timedelta(days=dias)
        
        # Obter AMIs para verificar quais snapshots são necessários
        amis = self.ec2.describe_images(Owners=['self'])
        snap_ids_em_uso = set()
        for ami in amis['Images']:
            for bdm in ami.get('BlockDeviceMappings', []):
                if 'Ebs' in bdm:
                    snap_ids_em_uso.add(bdm['Ebs'].get('SnapshotId'))
        
        # Snapshots antigos sem AMI
        response = self.ec2.describe_snapshots(OwnerIds=['self'])
        orfaos = []
        for snap in response['Snapshots']:
            if (snap['StartTime'] < limite and 
                snap['SnapshotId'] not in snap_ids_em_uso):
                orfaos.append({
                    'id': snap['SnapshotId'],
                    'size': snap['VolumeSize'],
                    'created': snap['StartTime'].strftime('%Y-%m-%d')
                })
        return orfaos

    """Gerador de relatórios de infraestrutura AWS."""
    
    def __init__(self, region: str = 'sa-east-1'):
        self.region = region
        self.ec2 = boto3.client('ec2', region_name=region)
        self.s3 = boto3.client('s3')
        self.lambda_client = boto3.client('lambda', region_name=region)
        self.sts = boto3.client('sts')
    
    def gerar(self, salvar_s3: str = None) -> str:
        """Gera relatório completo em HTML."""
        # Coletar dados
        identity = self.sts.get_caller_identity()
        instances = self._coletar_ec2()
        buckets = self._coletar_s3()
        functions = self._coletar_lambda()
        
        # Gerar HTML
        html = f"""
Relatório AWS - {datetime.now().strftime('%Y-%m-%d')}


📊 Relatório de Infraestrutura AWS


Conta: {identity['Account']} | 
   Região: {self.region} | 
   Gerado: {datetime.now().strftime('%Y-%m-%d %H:%M:%S')}



🖥️ EC2 Instances ({len(instances)})


"""
        for inst in instances:
            css_class = 'running' if inst['state'] == 'running' else 'stopped'
            html += f""

            html += f""
            html += f"\n"
        
        html += f"""


IDNomeTipoEstadoIP
{inst['id']}{inst['name']}{inst['type']}{inst['state']}{inst['ip']}



📦 S3 Buckets ({len(buckets)})


"""
        for b in buckets:
            html += f"\n"
        
        html += f"""
NomeCriado em
{b['name']}{b['created']}



⚡ Lambda Functions ({len(functions)})


"""
        for f in functions:
            html += f"\n"
        
        html += "

        filename = f"relatorio_aws_{datetime.now().strftime('%Y%m%d_%H%M%S')}.html"
        with open(filename, 'w') as f:
            f.write(html)
        print(f"✅ Relatório salvo: {filename}")
        
        # Salvar no S3
        if salvar_s3:
            self.s3.put_object(
                Bucket=salvar_s3, Key=f'relatorios/{filename}',
                Body=html.encode(), ContentType='text/html'
            )
            print(f"   ☁️ Enviado para s3://{salvar_s3}/relatorios/{filename}")
        
        return filename
    
    def _coletar_ec2(self) -> list:
        response = self.ec2.describe_instances()
        instances = []
        for res in response['Reservations']:
            for inst in res['Instances']:
                name = next(
                    (t['Value'] for t in inst.get('Tags', []) if t['Key'] == 'Name'),
                    'N/A'
                )
                instances.append({
                    'id': inst['InstanceId'],
                    'name': name,
                    'type': inst['InstanceType'],
                    'state': inst['State']['Name'],
                    'ip': inst.get('PublicIpAddress', 'N/A')
                })
        return instances
    
    def _coletar_s3(self) -> list:
        response = self.s3.list_buckets()
        return [{
            'name': b['Name'],
            'created': b['CreationDate'].strftime('%Y-%m-%d')
        } for b in response['Buckets']]
    
    def _coletar_lambda(self) -> list:
        response = self.lambda_client.list_functions()
        return [{
            'name': f['FunctionName'],
            'runtime': f.get('Runtime', 'N/A'),
            'memory': f['MemorySize']
        } for f in response['Functions']]
