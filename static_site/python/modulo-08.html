1. Fundamentos de APIs REST

APIs (Application Programming Interfaces) são o coração da comunicação entre sistemas modernos. No universo DevOps e Cloud, praticamente tudo é uma API: AWS, Azure, GCP, GitHub, Docker Hub, Kubernetes, Terraform Cloud — todos expõem APIs REST para automação. Compreender profundamente como APIs funcionam é uma habilidade fundamental para qualquer profissional de infraestrutura e desenvolvimento.

🌐 O que é uma API REST?

REST (Representational State Transfer) é um estilo arquitetural criado por Roy Fielding em 2000. Uma API RESTful segue princípios específicos que tornam a comunicação entre cliente e servidor previsível, escalável e simples de entender.

Princípios REST:

  • Client-Server — Separação clara entre quem consome (client) e quem fornece (server)
  • Stateless — Cada requisição contém TODA informação necessária; o servidor não mantém estado entre requests
  • Cacheable — Respostas podem ser cacheadas para melhorar performance
  • Uniform Interface — Interface padronizada com URLs representando recursos
  • Layered System — Camadas intermediárias (load balancers, proxies) são transparentes

# 500 Internal Server Error → Bug no servidor

# - Monitore 429 (você está excedendo limites de APIs externas)
# - 4xx alto pode indicar clientes com bugs ou ataques

1.4 Estrutura de URLs em APIs REST

# 4. QUERY PARAMETERS — Filtros e opções após o ?

# ✅ BOM — Substantivos no plural, hierarquia clara
# GET    /api/v1/servers              → Lista todos os servidores
# GET    /api/v1/servers/srv-123      → Servidor específico

2.1 GET Requests — Obtendo Dados

O método GET é o mais utilizado — serve para obter dados de um servidor sem modificar nada. É idempotente (pode ser executado múltiplas vezes com o mesmo resultado) e não possui corpo na requisição.

requests.get()GET
import requests

# ═══ GET Simples ═════════════════════════════════════════════════════
response = requests.get("https://api.github.com/users/octocat")

# O objeto Response contém TUDO sobre a resposta
print(response.status_code)     # 200 (int)
print(response.ok)              # True (status < 400)
print(response.reason)          # "OK" (texto do status)
print(response.url)             # URL final (após redirects)
print(response.elapsed)         # Tempo da requisição (timedelta)

# ═══ Acessando o Corpo da Resposta ═══════════════════════════════════

# Como texto (string)
texto = response.text
print(type(texto))              # 

# Como JSON (dict/list) — MAIS COMUM para APIs
dados = response.json()
print(type(dados))              # 
print(dados["login"])           # "octocat"
print(dados["public_repos"])    # 8

# Como bytes (para downloads binários)
conteudo = response.content
print(type(conteudo))           # 

# ═══ Acessando Headers da Resposta ═══════════════════════════════════
print(response.headers)                      # dict-like (case-insensitive)
print(response.headers["Content-Type"])      # "application/json; charset=utf-8"
print(response.headers["X-RateLimit-Remaining"])  # "57"
print(response.headers.get("X-Custom", "N/A"))    # "N/A" (seguro)

# ═══ GET com Query Parameters ════════════════════════════════════════
# Ao invés de montar a URL manualmente, use o parâmetro params
params = {
    "q": "language:python stars:>1000",
    "sort": "stars",
    "order": "desc",
    "per_page": 5
}
response = requests.get(
    "https://api.github.com/search/repositories",
    params=params
)
# URL gerada: https://api.github.com/search/repositories?q=language%3Apython+stars%3A%3E1000&sort=stars&order=desc&per_page=5

repos = response.json()["items"]
for repo in repos:
    print(f"⭐ {repo['stargazers_count']:>6,} | {repo['full_name']}")
# ⭐ 185,234 | tensorflow/tensorflow
# ⭐ 168,432 | python/cpython
# ...

2.2 POST Requests — Criando Recursos

O método POST envia dados ao servidor para criar novos recursos. Diferente do GET, o POST carrega um corpo (body) com os dados do recurso a ser criado. Não é idempotente — cada chamada pode criar um novo recurso.

requests.post()POST
import requests

# ═══ POST com JSON (mais comum em APIs REST) ═════════════════════════
# O parâmetro json= serializa automaticamente e define Content-Type
payload = {
    "title": "Bug: Login falha com caracteres especiais",
    "body": "## Descrição\nO login falha quando a senha contém ñ ou ç.",
    "labels": ["bug", "high-priority"],
    "assignees": ["dev-joao"]
}

response = requests.post(
    "https://api.github.com/repos/minha-org/meu-repo/issues",
    json=payload,                                    # Serializa para JSON
    headers={"Authorization": "Bearer ghp_xxxx"}
)

print(response.status_code)     # 201 Created
nova_issue = response.json()
print(f"Issue #{nova_issue['number']} criada: {nova_issue['html_url']}")

# ═══ POST com Form Data ══════════════════════════════════════════════
# Para APIs que esperam application/x-www-form-urlencoded
form_data = {
    "grant_type": "client_credentials",
    "client_id": "meu-client-id",
    "client_secret": "meu-secret",
    "scope": "read:user"
}
response = requests.post(
    "https://auth.exemplo.com/oauth/token",
    data=form_data               # Envia como form-urlencoded
)
token = response.json()["access_token"]

# ═══ Diferença entre json= e data= ══════════════════════════════════
# json=payload  → Content-Type: application/json
#                  Corpo: {"key": "value"}
#
# data=payload  → Content-Type: application/x-www-form-urlencoded
#                  Corpo: key=value&key2=value2
#
# data=string   → Envia a string como está (você define Content-Type)
import json
response = requests.post(
    "https://api.exemplo.com/webhook",
    data=json.dumps(payload),
    headers={"Content-Type": "application/json"}
)
# Equivalente a json=payload, mas mais verboso

2.3 PUT, PATCH e DELETE — Modificando e Removendo

Além de GET e POST, os métodos PUT, PATCH e DELETE completam as operações CRUD (Create, Read, Update, Delete) em APIs REST.

PUT / PATCH / DELETECRUD
import requests

BASE_URL = "https://api.exemplo.com/v1"
HEADERS = {"Authorization": "Bearer meu-token-aqui"}

# ═══ PUT — Substituição COMPLETA do recurso ══════════════════════════
# PUT substitui TODO o recurso. Campos não enviados são removidos/zerados.
servidor_completo = {
    "name": "web-server-01",
    "type": "t3.medium",           # era t3.micro
    "region": "us-east-1",
    "tags": {"env": "production", "team": "backend"},
    "monitoring": True
}
response = requests.put(
    f"{BASE_URL}/servers/srv-abc123",
    json=servidor_completo,
    headers=HEADERS
)
print(response.status_code)  # 200 OK

# ═══ PATCH — Atualização PARCIAL ═════════════════════════════════════
# PATCH modifica APENAS os campos enviados. Outros permanecem inalterados.
atualizacao_parcial = {
    "name": "web-server-prod-01",   # Só muda o nome
    "tags": {"env": "production"}   # Só muda as tags
}
response = requests.patch(
    f"{BASE_URL}/servers/srv-abc123",
    json=atualizacao_parcial,
    headers=HEADERS
)
print(response.status_code)  # 200 OK

# ═══ DELETE — Remoção de recurso ═════════════════════════════════════
response = requests.delete(
    f"{BASE_URL}/servers/srv-abc123",
    headers=HEADERS
)
print(response.status_code)  # 204 No Content (sucesso sem corpo)

# Alguns DELETEs retornam o recurso removido:
response = requests.delete(
    f"{BASE_URL}/dns-records/rec-xyz",
    headers=HEADERS
)
if response.status_code == 200:
    removido = response.json()
    print(f"Registro {removido['name']} removido com sucesso")

# ═══ Quando usar PUT vs PATCH? ═══════════════════════════════════════
# PUT:   Você tem o objeto completo e quer substituir tudo
#        Ex: Atualizar configuração COMPLETA de um recurso
#
# PATCH: Você quer mudar apenas 1-2 campos
#        Ex: Renomear um servidor, mudar uma tag
#
# Na prática, muitas APIs usam PATCH para quase tudo e PUT
# é menos comum em APIs modernas.

2.4 Timeout e Tratamento Básico de Erros

Nunca faça requisições sem timeout — um servidor lento pode travar seu script indefinidamente. O tratamento de erros é essencial para scripts robustos em produção.

Timeout & ErrosResiliência
import requests
from requests.exceptions import (
    RequestException,
    ConnectionError,
    Timeout,
    HTTPError
)

# ═══ Timeout ═════════════════════════════════════════════════════════
# timeout=segundos — tempo máximo para TODA a requisição
response = requests.get(
    "https://api.exemplo.com/data",
    timeout=10  # 10 segundos máximo
)

# timeout=(connect_timeout, read_timeout)
response = requests.get(
    "https://api.exemplo.com/data",
    timeout=(3.05, 27)  # 3s para conectar, 27s para ler resposta
)

# ⚠️  NUNCA FAÇA ISSO EM PRODUÇÃO:
# response = requests.get("https://api.exemplo.com/data")  # Sem timeout!
# Se o servidor travar, seu script espera PARA SEMPRE

# ═══ raise_for_status() — Exceção para erros HTTP ════════════════════
response = requests.get("https://api.exemplo.com/data", timeout=10)
response.raise_for_status()  # Levanta HTTPError se status >= 400

# ═══ Tratamento Completo de Erros ════════════════════════════════════
def fazer_requisicao_segura(url, **kwargs):
    """Faz uma requisição HTTP com tratamento completo de erros."""
    kwargs.setdefault("timeout", 30)

    try:
        response = requests.get(url, **kwargs)
        response.raise_for_status()
        return response.json()

    except Timeout:
        print(f"⏱️  Timeout ao acessar {url}")
        return None

    except ConnectionError:
        print(f"🔌 Erro de conexão com {url} — servidor fora do ar?")
        return None

    except HTTPError as e:
        status = e.response.status_code
        if status == 401:
            print("🔑 Token expirado ou inválido")
        elif status == 403:
            print("🚫 Sem permissão para este recurso")
        elif status == 404:
            print(f"❓ Recurso não encontrado: {url}")
        elif status == 429:
            retry_after = e.response.headers.get("Retry-After", "60")
            print(f"⚠️  Rate limit! Aguarde {retry_after}s")
        elif status >= 500:
            print(f"💥 Erro no servidor ({status})")
        return None

    except RequestException as e:
        print(f"❌ Erro inesperado: {e}")
        return None

# Uso:
dados = fazer_requisicao_segura("https://api.github.com/users/octocat")
if dados:
    print(f"Usuário: {dados['login']}")

⚠️ Regras de Ouro para Requisições HTTP

  • SEMPRE defina um timeout (recomendado: 30s para operações normais, 120s para uploads/downloads)
  • SEMPRE trate exceções — network é inerentemente instável
  • SEMPRE use raise_for_status() ou verifique response.ok
  • NUNCA confie que a resposta será JSON válido — use try/except no .json()
  • SEMPRE feche connections ou use Session para reuso eficiente

3. Autenticação em APIs

A autenticação é o mecanismo que prova a identidade do cliente para a API. Sem autenticação adequada, você não consegue acessar recursos protegidos. Como profissional DevOps, você lidará com múltiplos esquemas de autenticação diariamente — desde tokens simples até assinaturas criptográficas complexas como AWS SigV4.

🔐 Tipos de Autenticação — Quando usar cada uma?

  • API Key — Simples, para APIs de terceiros com acesso limitado (OpenWeather, NewsAPI)
  • Basic Auth — Username + senha codificados em Base64 (legado, usar apenas com HTTPS)
  • Bearer Token — Token OAuth 2.0 / JWT (GitHub, Slack, APIs modernas)
  • AWS SigV4 — Assinatura criptográfica para APIs AWS (gerada pelo boto3/SDK)
  • mTLS — Certificado mútuo cliente-servidor (APIs internas de alta segurança)

API Keys são a forma mais simples de autenticação. São strings únicas geradas pelo provedor da API que identificam seu aplicativo. Podem ser enviadas via header ou query parameter.

class TokenManager:
    """Gerencia tokens com renovação automática."""

    def __init__(self, client_id, client_secret, token_url):
        self.client_id = client_id
        self.client_secret = client_secret
        self.token_url = token_url
        self._token = None
        self._expires_at = datetime.min

    @property
    def token(self):
        """Retorna token válido, renovando se necessário."""
        if datetime.now() >= self._expires_at - timedelta(minutes=5):
            self._renovar()
        return self._token

    def _renovar(self):
        """Obtém novo token do servidor de autenticação."""
        response = requests.post(
            self.token_url,
            data={
                "grant_type": "client_credentials",
                "client_id": self.client_id,
                "client_secret": self.client_secret
            },
            timeout=10
        )
        response.raise_for_status()
        data = response.json()
        self._token = data["access_token"]
        self._expires_at = datetime.now() + timedelta(seconds=data["expires_in"])

    def get_headers(self):
        """Retorna headers com token atualizado."""
        return {"Authorization": f"Bearer {self.token}"}

    """Navega em dict aninhado sem risco de KeyError."""

        if isinstance(data, dict):
            data = data.get(key, default)
        elif isinstance(data, (list, tuple)) and isinstance(key, int):
            try:
                data = data[key]
            except IndexError:
                return default
        else:
            return default
    return data

4.2 Paginação — Obtendo TODOS os Resultados

APIs limitam o número de resultados por requisição (geralmente 20-100 itens). Para obter todos os dados, você precisa "paginar" — fazer múltiplas requisições sequenciais. Existem três padrões comuns de paginação.

PaginaçãoAPI
import requests
from urllib.parse import parse_qs, urlparse

# ═══ Padrão 1: Offset/Limit (mais simples) ══════════════════════════
def paginar_offset(base_url, headers, limit=100):
    """Paginação por offset/limit — comum em APIs simples."""
    todos_resultados = []
    offset = 0

    while True:
        response = requests.get(
            base_url,
            headers=headers,
            params={"offset": offset, "limit": limit},
            timeout=30
        )
        response.raise_for_status()
        dados = response.json()

        resultados = dados.get("items", dados.get("results", []))
        if not resultados:
            break

        todos_resultados.extend(resultados)
        offset += limit

        # Segurança: parar se não há mais dados
        total = dados.get("total", dados.get("total_count"))
        if total and offset >= total:
            break

    return todos_resultados

# ═══ Padrão 2: Page/Per_Page (GitHub, GitLab) ═══════════════════════
def paginar_por_pagina(base_url, headers, per_page=100, max_pages=None):
    """Paginação page/per_page — padrão GitHub."""
    todos_resultados = []
    page = 1

    while True:
        response = requests.get(
            base_url,
            headers=headers,
            params={"page": page, "per_page": per_page},
            timeout=30
        )
        response.raise_for_status()
        dados = response.json()

        if not dados:  # Página vazia = fim dos dados
            break

        todos_resultados.extend(dados)
        page += 1

        if max_pages and page > max_pages:
            break

    return todos_resultados

# ═══ Padrão 3: Link Headers (GitHub — mais robusto) ═════════════════
def paginar_com_links(url, headers):
    """Paginação seguindo Link headers — padrão RFC 5988."""
    todos_resultados = []

    while url:
        response = requests.get(url, headers=headers, timeout=30)
        response.raise_for_status()
        todos_resultados.extend(response.json())

        # O header Link contém URLs para próxima/anterior/última página
        # Link: ; rel="next", ; rel="last"
        url = response.links.get("next", {}).get("url")

    return todos_resultados

# Uso com GitHub:
headers = {"Authorization": "Bearer ghp_xxx", "Accept": "application/vnd.github.v3+json"}
todos_repos = paginar_com_links("https://api.github.com/user/repos?per_page=100", headers)
print(f"Total de repositórios: {len(todos_repos)}")

# ═══ Padrão 4: Cursor-Based (APIs modernas, Slack, Stripe) ══════════
def paginar_cursor(base_url, headers):
    """Paginação baseada em cursor — mais eficiente para grandes datasets."""
    todos_resultados = []
    cursor = None

    while True:
        params = {"limit": 100}
        if cursor:
            params["cursor"] = cursor

        response = requests.get(
            base_url,
            headers=headers,
            params=params,
            timeout=30
        )
        response.raise_for_status()
        dados = response.json()

        todos_resultados.extend(dados.get("items", []))

        # O cursor para próxima página vem na resposta
        cursor = dados.get("next_cursor") or dados.get("response_metadata", {}).get("next_cursor")
        if not cursor:
            break

    return todos_resultados

5. Tratamento de Erros e Resiliência

Redes são inerentemente instáveis. Servidores ficam fora do ar, conexões são interrompidas, timeouts acontecem. Um script DevOps robusto deve lidar graciosamente com todas essas falhas — e implementar estratégias inteligentes de retry que não sobrecarreguem APIs já em dificuldades.

🎯 Hierarquia de Erros do requests

# RequestException (base)

# │   ├── ConnectTimeout   → Timeout na conexão
# │   └── ReadTimeout      → Timeout na leitura

5.1 Retry com Exponential Backoff

Exponential backoff é a estratégia padrão para retries: a cada tentativa falha, o tempo de espera dobra. Isso evita sobrecarregar APIs que já estão com problemas (efeito "thundering herd").

Retry ManualResiliência
import requests
import time
import random
import logging

logging.basicConfig(level=logging.INFO)
logger = logging.getLogger(__name__)

# ═══ Implementação Manual de Retry com Backoff ═══════════════════════
def request_com_retry(
    method: str,
    url: str,
    max_retries: int = 3,
    backoff_base: float = 1.0,
    backoff_max: float = 60.0,
    retry_status_codes: tuple = (429, 500, 502, 503, 504),
    **kwargs
):
    """
    Faz requisição HTTP com retry automático e exponential backoff.
    
    Args:
        method: Método HTTP (GET, POST, etc.)
        url: URL da requisição
        max_retries: Número máximo de tentativas
        backoff_base: Tempo base para backoff (segundos)
        backoff_max: Tempo máximo de espera (segundos)
        retry_status_codes: Status codes que trigam retry
        **kwargs: Argumentos passados para requests.request()
    
    Returns:
        Response object
    
    Raises:
        requests.RequestException: Após esgotar todas as tentativas
    """
    kwargs.setdefault("timeout", 30)
    last_exception = None

    for attempt in range(max_retries + 1):
        try:
            response = requests.request(method, url, **kwargs)

            # Sucesso — retorna a resposta
            if response.status_code not in retry_status_codes:
                if attempt > 0:
                    logger.info(f"✅ Sucesso na tentativa {attempt + 1}")
                return response

            # Rate limit — respeitar Retry-After
            if response.status_code == 429:
                retry_after = int(response.headers.get("Retry-After", backoff_base * (2 ** attempt)))
                wait_time = min(retry_after, backoff_max)
                logger.warning(f"⚠️  Rate limit (429). Aguardando {wait_time}s...")
            else:
                # Exponential backoff com jitter
                wait_time = min(backoff_base * (2 ** attempt), backoff_max)
                wait_time += random.uniform(0, wait_time * 0.1)  # Jitter de 10%
                logger.warning(
                    f"⚠️  Status {response.status_code} — Tentativa {attempt + 1}/{max_retries + 1}. "
                    f"Aguardando {wait_time:.1f}s..."
                )

            if attempt < max_retries:
                time.sleep(wait_time)
            else:
                response.raise_for_status()

        except requests.exceptions.ConnectionError as e:
            last_exception = e
            wait_time = min(backoff_base * (2 ** attempt), backoff_max)
            logger.error(f"🔌 Erro de conexão — Tentativa {attempt + 1}/{max_retries + 1}")
            if attempt < max_retries:
                time.sleep(wait_time)

        except requests.exceptions.Timeout as e:
            last_exception = e
            logger.error(f"⏱️  Timeout — Tentativa {attempt + 1}/{max_retries + 1}")
            if attempt < max_retries:
                time.sleep(backoff_base * (2 ** attempt))

    raise requests.exceptions.RetryError(
        f"Falha após {max_retries + 1} tentativas para {url}"
    ) from last_exception

5.3 Circuit Breaker Pattern

O padrão Circuit Breaker evita que seu sistema continue fazendo requisições para um serviço que está claramente fora do ar. Após N falhas consecutivas, o "circuito abre" e requisições são imediatamente rejeitadas sem tentar a rede — protegendo tanto o seu sistema quanto o serviço em dificuldades.

Circuit BreakerPadrão
import time
from enum import Enum
from dataclasses import dataclass, field
from datetime import datetime, timedelta
import requests

class CircuitState(Enum):
    CLOSED = "closed"       # Normal — requisições passam
    OPEN = "open"           # Aberto — requisições bloqueadas
    HALF_OPEN = "half_open" # Teste — permite 1 requisição para ver se voltou

@dataclass
class CircuitBreaker:
    """
    Circuit Breaker para chamadas HTTP.
    
    Estados:
    - CLOSED: Tudo normal, requisições passam
    - OPEN: Serviço fora do ar, requisições bloqueadas imediatamente
    - HALF_OPEN: Testando se o serviço voltou (1 requisição de teste)
    """
    failure_threshold: int = 5       # Falhas para abrir o circuito
    recovery_timeout: float = 30.0   # Segundos até tentar novamente
    success_threshold: int = 2       # Sucessos para fechar o circuito
    
    _state: CircuitState = field(default=CircuitState.CLOSED, init=False)
    _failure_count: int = field(default=0, init=False)
    _success_count: int = field(default=0, init=False)
    _last_failure_time: float = field(default=0, init=False)

    @property
    def state(self) -> CircuitState:
        if self._state == CircuitState.OPEN:
            if time.time() - self._last_failure_time >= self.recovery_timeout:
                self._state = CircuitState.HALF_OPEN
                self._success_count = 0
        return self._state

    def call(self, func, *args, **kwargs):
        """Executa função protegida pelo circuit breaker."""
        current_state = self.state

        if current_state == CircuitState.OPEN:
            raise CircuitBreakerOpen(
                f"Circuit breaker ABERTO. Retry em "
                f"{self.recovery_timeout - (time.time() - self._last_failure_time):.0f}s"
            )

        try:
            result = func(*args, **kwargs)
            self._on_success()
            return result
        except Exception as e:
            self._on_failure()
            raise

    def _on_success(self):
        self._failure_count = 0
        if self._state == CircuitState.HALF_OPEN:
            self._success_count += 1
            if self._success_count >= self.success_threshold:
                self._state = CircuitState.CLOSED
        else:
            self._state = CircuitState.CLOSED

    def _on_failure(self):
        self._failure_count += 1
        self._last_failure_time = time.time()
        if self._failure_count >= self.failure_threshold:
            self._state = CircuitState.OPEN

class CircuitBreakerOpen(Exception):
    pass

6.3 Rate Limiting — Respeitando Limites de APIs

Toda API tem limites de requisições por período (rate limits). Ignorar esses limites resulta em bloqueio temporário (429) ou até permanente. Um client bem-comportado respeita e se adapta a esses limites automaticamente.

Rate LimitingControle
import requests
import time
from threading import Lock
from dataclasses import dataclass, field

# ═══ Rate Limiter Simples (Token Bucket) ═════════════════════════════
@dataclass
class RateLimiter:
    """
    Rate limiter usando Token Bucket algorithm.
    Garante que não excedemos o limite da API.
    """
    calls_per_second: float = 10.0      # Requisições por segundo
    _last_call: float = field(default=0, init=False)
    _lock: Lock = field(default_factory=Lock, init=False)

    def wait(self):
        """Aguarda o tempo necessário para respeitar o rate limit."""
        with self._lock:
            now = time.time()
            min_interval = 1.0 / self.calls_per_second
            elapsed = now - self._last_call
            
            if elapsed < min_interval:
                sleep_time = min_interval - elapsed
                time.sleep(sleep_time)
            
            self._last_call = time.time()

# ═══ Respeitando Headers de Rate Limit ═══════════════════════════════
class APIComRateLimit:
    """Client que respeita os headers de rate limit da API."""

    def __init__(self, base_url, token):
        self.base_url = base_url
        self.session = requests.Session()
        self.session.headers.update({"Authorization": f"Bearer {token}"})
        self.rate_limiter = RateLimiter(calls_per_second=5)

    def request(self, method, endpoint, **kwargs):
        """Faz requisição respeitando rate limits."""
        self.rate_limiter.wait()
        
        url = f"{self.base_url}{endpoint}"
        kwargs.setdefault("timeout", 30)
        
        response = self.session.request(method, url, **kwargs)
        
        # Monitorar headers de rate limit
        remaining = response.headers.get("X-RateLimit-Remaining")
        limit = response.headers.get("X-RateLimit-Limit")
        reset = response.headers.get("X-RateLimit-Reset")
        
        if remaining is not None:
            remaining = int(remaining)
            if remaining < 10:
                print(f"⚠️  Rate limit baixo: {remaining}/{limit} restantes")
            if remaining == 0 and reset:
                wait_until = int(reset) - int(time.time())
                if wait_until > 0:
                    print(f"🛑 Rate limit esgotado. Aguardando {wait_until}s...")
                    time.sleep(wait_until + 1)
                    return self.request(method, endpoint, **kwargs)
        
        # Se recebeu 429, aguardar
        if response.status_code == 429:
            retry_after = int(response.headers.get("Retry-After", 60))
            print(f"🛑 Rate limited! Aguardando {retry_after}s...")
            time.sleep(retry_after)
            return self.request(method, endpoint, **kwargs)
        
        return response

async def buscar_multiplos(urls, headers=None, max_concurrent=10):
    """
    Busca múltiplas URLs simultaneamente com limite de concorrência.

        urls: Lista de URLs para buscar
        headers: Headers da requisição

9. Construindo um Client API Robusto

Ao invés de espalhar chamadas requests.get() por todo o código, a prática profissional é encapsular a comunicação com uma API em uma classe cliente reutilizável. Isso centraliza autenticação, retry, logging, tratamento de erros e facilita testes unitários.

🏗️ Anatomia de um API Client Profissional

  • Base URL configurável — Suporta diferentes ambientes (dev, staging, prod)
  • Autenticação centralizada — Token gerenciado em um único lugar
  • Retry automático — Resiliência contra falhas transitórias
  • Logging estruturado — Rastreabilidade de todas as chamadas
  • Type hints — Autocompleção e documentação inline
  • Error handling consistente — Exceções customizadas e mensagens claras
  • Testabilidade — Fácil de mockar em testes unitários

class APIError(Exception):
    """Erro base para a API CloudTrilhas."""
    def __init__(self, message: str, status_code: int = None, response: dict = None):

@dataclass

    base_url: str = "https://api.cloudtrilhas.com/v1"
    timeout: int = 30
    max_retries: int = 3
    backoff_factor: float = 0.5
    verify_ssl: bool = True
    log_level: str = "INFO"

# ═══ API Client Principal ════════════════════════════════════════════
class CloudTrilhasAPI:
    """
    Client robusto para a API CloudTrilhas.
    
    Features:
    - Autenticação via Bearer Token
    - Retry automático com exponential backoff
    - Connection pooling
    - Logging estruturado
    - Tratamento de erros com exceções específicas
    - Paginação automática

        servidores = api.listar_servidores(status="running")
        servidor = api.criar_servidor(name="web-01", type="t3.micro")

        self.config = config or APIConfig()
        self.logger = logging.getLogger(f"cloudtrilhas.{self.__class__.__name__}")
        self.logger.setLevel(self.config.log_level)

        self._session = self._criar_session(token)

    def _criar_session(self, token: str) -> requests.Session:
        """Cria session configurada com retry e headers padrão."""
        session = requests.Session()
        
        # Headers padrão
        session.headers.update({
            "Authorization": f"Bearer {token}",
            "Content-Type": "application/json",
            "Accept": "application/json",
            "User-Agent": "CloudTrilhas-Python-Client/1.0"
        })
        
        # Retry strategy
        retry = Retry(
            total=self.config.max_retries,
            backoff_factor=self.config.backoff_factor,
            status_forcelist=[500, 502, 503, 504],
            allowed_methods=["GET", "POST", "PUT", "PATCH", "DELETE"]
        )
        
        adapter = HTTPAdapter(max_retries=retry, pool_connections=10, pool_maxsize=20)
        session.mount("https://", adapter)
        session.mount("http://", adapter)
        
        return session

    def _request(
        self,
        method: str,
        endpoint: str,
        params: Dict = None,
        json_data: Dict = None,
        **kwargs
    ) -> Dict[str, Any]:
        """
        Método interno para fazer requisições com tratamento padronizado.
        
        Args:
            method: HTTP method (GET, POST, PUT, PATCH, DELETE)
            endpoint: Path do endpoint (ex: /servers)
            params: Query parameters
            json_data: Body JSON
            **kwargs: Argumentos extras para requests
            
        Returns:
            Dict com dados da resposta
            
        Raises:
            AuthenticationError: Token inválido
            PermissionError: Sem permissão
            NotFoundError: Recurso não encontrado
            RateLimitError: Limite excedido
            ServerError: Erro no servidor
            APIError: Outros erros
        """
        url = f"{self.config.base_url}{endpoint}"
        start_time = time.time()
        
        try:
            response = self._session.request(
                method=method,
                url=url,
                params=params,
                json=json_data,
                timeout=self.config.timeout,
                verify=self.config.verify_ssl,
                **kwargs
            )
            
            elapsed = time.time() - start_time
            self.logger.info(
                f"{method} {endpoint} → {response.status_code} ({elapsed:.2f}s)"
            )
            
            # Tratar erros HTTP
            if response.status_code >= 400:
                self._handle_error(response)
            
            # Retornar dados
            if response.status_code == 204:
                return {}
            return response.json()
            
        except requests.exceptions.Timeout:
            self.logger.error(f"Timeout em {method} {endpoint}")
            raise APIError(f"Timeout após {self.config.timeout}s para {endpoint}")
            
        except requests.exceptions.ConnectionError:
            self.logger.error(f"Erro de conexão em {method} {endpoint}")
            raise APIError(f"Não foi possível conectar a {self.config.base_url}")

    def _handle_error(self, response: requests.Response):
        """Converte erros HTTP em exceções específicas."""
        try:
            error_body = response.json()
            message = error_body.get("message") or error_body.get("error", "Erro desconhecido")
        except ValueError:
            message = response.text[:200]
        
        status = response.status_code
        
        if status == 401:
            raise AuthenticationError(message, status_code=status)
        elif status == 403:
            raise PermissionError(message, status_code=status)
        elif status == 404:
            raise NotFoundError(message, status_code=status)
        elif status == 429:
            retry_after = int(response.headers.get("Retry-After", 60))
            raise RateLimitError(message, retry_after=retry_after, status_code=status)
        elif status >= 500:
            raise ServerError(message, status_code=status)
        else:
            raise APIError(message, status_code=status)

    # ═══ Paginação Automática ════════════════════════════════════════
    def _paginar(self, endpoint: str, params: Dict = None) -> List[Dict]:
        """Busca todas as páginas de um endpoint paginado."""
        params = params or {}
        params.setdefault("per_page", 100)
        params["page"] = 1
        
        todos = []
        while True:
            dados = self._request("GET", endpoint, params=params)
            items = dados.get("items", dados.get("data", []))
            
            if not items:
                break
            
            todos.extend(items)
            
            # Verificar se há mais páginas
            total = dados.get("total", dados.get("total_count"))
            if total and len(todos) >= total:
                break
            
            params["page"] += 1
        
        return todos

    # ═══ Métodos Públicos — Servidores ═══════════════════════════════
    def listar_servidores(self, status: str = None, tag: str = None) -> List[Dict]:
        """Lista todos os servidores com filtros opcionais."""
        params = {}
        if status:
            params["status"] = status
        if tag:
            params["tag"] = tag
        return self._paginar("/servers", params)

    def obter_servidor(self, server_id: str) -> Dict:
        """Obtém detalhes de um servidor específico."""
        return self._request("GET", f"/servers/{server_id}")

    def criar_servidor(self, name: str, type: str, region: str = "us-east-1", **kwargs) -> Dict:
        """Cria um novo servidor."""
        payload = {"name": name, "type": type, "region": region, **kwargs}
        return self._request("POST", "/servers", json_data=payload)

    def atualizar_servidor(self, server_id: str, **campos) -> Dict:
        """Atualiza campos de um servidor."""
        return self._request("PATCH", f"/servers/{server_id}", json_data=campos)

    def deletar_servidor(self, server_id: str) -> Dict:
        """Remove um servidor."""
        return self._request("DELETE", f"/servers/{server_id}")

    # ═══ Métodos Públicos — Deployments ══════════════════════════════
    def listar_deploys(self, server_id: str = None, status: str = None) -> List[Dict]:
        """Lista deployments com filtros."""
        params = {}
        if server_id:
            params["server_id"] = server_id
        if status:
            params["status"] = status
        return self._paginar("/deployments", params)

    def criar_deploy(self, server_id: str, version: str, **kwargs) -> Dict:
        """Inicia um novo deployment."""
        payload = {"server_id": server_id, "version": version, **kwargs}
        return self._request("POST", "/deployments", json_data=payload)

    # ═══ Context Manager ═════════════════════════════════════════════
    def __enter__(self):
        return self

    def __exit__(self, *args):
        self.close()

    def close(self):
        """Fecha a session e libera conexões."""
        self._session.close()
        self.logger.debug("Session fechada")

10. Webhooks e API Callbacks

Até agora consumimos APIs (pull — nós buscamos dados). Webhooks são o inverso (push — o servidor nos envia dados quando algo acontece). São fundamentais para automação em tempo real: notificações de deploy, triggers de CI/CD, alertas de monitoramento e integrações entre serviços.

def request_com_retry_exercicio(url, max_retries=3, base_delay=1.0, timeout=5):
    """
    Faz requisição com retry e exponential backoff.
    Retorna Response em caso de sucesso, None se todas falharem.
    """
    for attempt in range(max_retries + 1):
        try:
            response = requests.get(url, timeout=timeout)
            
            if response.status_code == 429:
                retry_after = int(response.headers.get("Retry-After", base_delay * (2 ** attempt)))
                print(f"  ⚠️  429 Rate Limit — aguardando {retry_after}s (tentativa {attempt+1})")
                time.sleep(retry_after)
                continue
            
            if response.status_code >= 500:
                delay = base_delay * (2 ** attempt) + random.uniform(0, 1)
                print(f"  ⚠️  {response.status_code} — retry em {delay:.1f}s (tentativa {attempt+1})")
                if attempt < max_retries:
                    time.sleep(delay)
                continue
            
            return response
        
        except requests.exceptions.Timeout:
            delay = base_delay * (2 ** attempt)
            print(f"  ⏱️  Timeout — retry em {delay:.1f}s (tentativa {attempt+1})")
            if attempt < max_retries:
                time.sleep(delay)
        
        except requests.exceptions.ConnectionError:
            delay = base_delay * (2 ** attempt)
            print(f"  🔌 Conexão falhou — retry em {delay:.1f}s (tentativa {attempt+1})")
            if attempt < max_retries:
                time.sleep(delay)
    
    print(f"  ❌ Todas as {max_retries + 1} tentativas falharam!")
    return None

@dataclass

@dataclass
class HealthResult:
    """Resultado da verificação de saúde."""
    name: str
    url: str
    status_code: Optional[int]
    response_time_ms: float
    health: str  # healthy, degraded, unhealthy
    error: Optional[str] = None
    timestamp: str = ""

    def __post_init__(self):
        if not self.timestamp:

class HealthChecker:
    """Monitor de saúde para múltiplos serviços."""
    
    THRESHOLDS = {
        "healthy": 1000,    # < 1000ms
        "degraded": 3000,   # 1000-3000ms
    }
    
    def __init__(self, services: List[ServiceConfig], parallel: bool = True):
        self.services = services
        self.parallel = parallel
        self.history: List[List[HealthResult]] = []
    
    def _check_single(self, service: ServiceConfig) -> HealthResult:
        """Verifica um único serviço."""
        start = time.time()
        
        try:
            response = requests.get(service.url, timeout=service.timeout)
            elapsed_ms = (time.time() - start) * 1000
            
            # Determinar saúde
            if response.status_code != service.expected_status:
                health = "unhealthy"
                error = f"Expected {service.expected_status}, got {response.status_code}"
            elif elapsed_ms < self.THRESHOLDS["healthy"]:
                health = "healthy"
                error = None
            elif elapsed_ms < self.THRESHOLDS["degraded"]:
                health = "degraded"
                error = None
            else:
                health = "unhealthy"
                error = f"Slow response: {elapsed_ms:.0f}ms"
            
            return HealthResult(
                name=service.name,
                url=service.url,
                status_code=response.status_code,
                response_time_ms=elapsed_ms,
                health=health,
                error=error
            )
            
        except requests.exceptions.Timeout:
            elapsed_ms = (time.time() - start) * 1000
            return HealthResult(
                name=service.name, url=service.url,
                status_code=None, response_time_ms=elapsed_ms,
                health="unhealthy", error="Timeout"
            )
        except requests.exceptions.ConnectionError:
            elapsed_ms = (time.time() - start) * 1000
            return HealthResult(
                name=service.name, url=service.url,
                status_code=None, response_time_ms=elapsed_ms,
                health="unhealthy", error="Connection refused"
            )
    
    def check_all(self) -> List[HealthResult]:
        """Verifica todos os serviços (paralelo ou sequencial)."""
        if self.parallel:
            with ThreadPoolExecutor(max_workers=len(self.services)) as executor:
                futures = {executor.submit(self._check_single, s): s for s in self.services}
                results = [futures[f] for f in as_completed(futures)]
                # Re-ordenar conforme ordem original

                future_map = {executor.submit(self._check_single, s): s for s in self.services}
                for future in as_completed(future_map):
                    results.append(future.result())
        else:
            results = [self._check_single(s) for s in self.services]
        
        self.history.append(results)
        return results
    
    def print_report(self, results: List[HealthResult]):

class RelatorioBuilder:
    """Constrói relatório semanal integrando múltiplas fontes."""
    
    def __init__(self, github_token: str, repo: str):
        self.repo = repo
        self.session = requests.Session()
        self.session.headers.update({
            "Authorization": f"Bearer {github_token}",
            "Accept": "application/vnd.github.v3+json"
        })
        self.inicio = (datetime.utcnow() - timedelta(days=7)).isoformat() + "Z"
        self.fim = datetime.utcnow().isoformat() + "Z"
    
    def _buscar_github(self) -> Dict:
        """Busca métricas do GitHub da última semana."""
        logger.info("Buscando dados do GitHub...")
        
        # Commits da semana
        r = self.session.get(
            f"https://api.github.com/repos/{self.repo}/commits",
            params={"since": self.inicio, "per_page": 100},
            timeout=15
        )
        commits = r.json() if r.ok else []
        
        # Contribuidores por commits
        autores = {}
        for c in commits:
            autor = c.get("commit", {}).get("author", {}).get("name", "unknown")
            autores[autor] = autores.get(autor, 0) + 1
        
        top_contrib = sorted(autores.items(), key=lambda x: -x[1])[:5]
        
        return {
            "total_commits": len(commits),
            "top_contribuidores": [{"nome": a, "commits": c} for a, c in top_contrib]
        }
    
    def _simular_monitoramento(self) -> Dict:
        """Simula dados de monitoramento (substituir por API real)."""
        logger.info("Coletando dados de monitoramento...")
        return {
            "uptime_percent": round(random.uniform(99.5, 99.99), 2),
            "latencia_p95_ms": round(random.uniform(50, 300), 1),
            "total_erros_5xx": random.randint(0, 50)
        }
    
    def _simular_custos(self) -> Dict:
        """Simula dados de custos (substituir por AWS Cost Explorer API)."""
        logger.info("Coletando dados de custos...")
        servicos = {
            "EC2": round(random.uniform(100, 500), 2),
            "Lambda": round(random.uniform(10, 50), 2),
            "S3": round(random.uniform(5, 30), 2),
            "RDS": round(random.uniform(50, 200), 2),
            "CloudFront": round(random.uniform(20, 100), 2)
        }
        total = sum(servicos.values())
        return {
            "custo_total_usd": round(total, 2),
            "custo_por_servico": servicos,
            "variacao_custo_percent": round(random.uniform(-10, 15), 1)
        }
    
    def gerar(self) -> RelatorioSemanal:
        """Gera relatório completo."""
        github = self._buscar_github()
        monitoring = self._simular_monitoramento()
        custos = self._simular_custos()
        
        relatorio = RelatorioSemanal(
            periodo_inicio=self.inicio[:10],
            periodo_fim=self.fim[:10],

            top_contribuidores=github["top_contribuidores"],
            uptime_percent=monitoring["uptime_percent"],
            latencia_p95_ms=monitoring["latencia_p95_ms"],
            total_erros_5xx=monitoring["total_erros_5xx"],
            custo_total_usd=custos["custo_total_usd"],
            custo_por_servico=custos["custo_por_servico"],
            variacao_custo_percent=custos["variacao_custo_percent"]
        )
        
        # Salvar
        with open("relatorio_semanal.json", "w") as f:
            json.dump(asdict(relatorio), f, indent=2, default=str)
        
        return relatorio
    
    def imprimir(self, r: RelatorioSemanal):

        print(f"   Repositório: {self.repo}")

        print(f"   Erros 5xx: {r.total_erros_5xx}")

def paginar(url, headers):
    resultados = []
    while url:
        r = requests.get(url, headers=headers, timeout=30)
        r.raise_for_status()
        resultados.extend(r.json())
        url = r.links.get("next", {}).get("url")
    return resultados
