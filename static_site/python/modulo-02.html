🐍 Python — Módulo 02

Estruturas de Controle: if, for, while

Controle o fluxo de execução do programa com condicionais e loops.

1. Condicionais

if / elif / elseCondicional
# Estrutura completa
nota = 7.5

if nota >= 9:
    conceito = "A"
elif nota >= 7:
    conceito = "B"
elif nota >= 5:
    conceito = "C"
else:
    conceito = "D"

print(f"Nota {nota} = Conceito {conceito}")

# Operador ternário
status = "Aprovado" if nota >= 7 else "Reprovado"

# Match/case (Python 3.10+)
match conceito:
    case "A":
        print("Excelente!")
    case "B":
        print("Bom trabalho!")
    case _:
        print("Continue estudando!")

2. Loops

forLoop
# Iterando sobre sequências
frutas = ["maçã", "banana", "uva"]
for fruta in frutas:
    print(fruta)

# range()
for i in range(5):        # 0, 1, 2, 3, 4
    print(i)

for i in range(1, 11, 2): # 1, 3, 5, 7, 9
    print(i)

# enumerate (índice + valor)
for i, fruta in enumerate(frutas):
    print(f"{i}: {fruta}")
whileLoop
# Loop com condição
contador = 0
while contador < 5:
    print(f"Contagem: {contador}")
    contador += 1

# break e continue
for i in range(10):
    if i == 3:
        continue  # pula o 3
    if i == 7:
        break     # para no 7
    print(i)

# while True com break
while True:
    resp = input("Sair? (s/n): ")
    if resp.lower() == "s":
        break
