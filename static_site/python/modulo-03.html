Funções e Módulos

Funções organizam código em blocos reutilizáveis. Módulos permitem dividir o projeto em arquivos.

1. Funções

defFunções
# Função básica
def saudacao(nome, saudacao="Olá"):
    """Retorna uma saudação personalizada."""
    return f"{saudacao}, {nome}!"

print(saudacao("Ricardo"))
print(saudacao("Ana", "Bom dia"))

# *args e **kwargs
def soma(*numeros):
    return sum(numeros)

print(soma(1, 2, 3, 4))  # 10

def criar_perfil(**dados):
    return {k: v for k, v in dados.items()}

perfil = criar_perfil(nome="Ricardo", cargo="DevOps")
lambdaFunções

Funções anônimas de uma linha.

# Lambda
dobro = lambda x: x * 2
print(dobro(5))  # 10

# Com sorted
alunos = [("Ana", 8), ("Bia", 9), ("Carlos", 7)]
ordenados = sorted(alunos, key=lambda x: x[1], reverse=True)

# Com map e filter
numeros = [1, 2, 3, 4, 5]
pares = list(filter(lambda x: x % 2 == 0, numeros))
dobros = list(map(lambda x: x * 2, numeros))
List ComprehensionPythonic

Forma concisa e eficiente de criar listas.

# Básico
quadrados = [x**2 for x in range(10)]

# Com filtro
pares = [x for x in range(20) if x % 2 == 0]

# Aninhado
matriz = [[i*j for j in range(3)] for i in range(3)]

# Dict comprehension
nomes = ["ana", "bia", "carlos"]
tamanhos = {n: len(n) for n in nomes}

# Set comprehension
unicos = {x % 5 for x in range(20)}
