🐍 Python — Módulo 01

Fundamentos: Variáveis, Tipos e Operadores

Python é uma linguagem de alto nível, interpretada e com tipagem dinâmica. Ideal para automação, dados, web e IA.

1. Variáveis e Tipos de Dados

VariáveisBásico

Em Python, variáveis são criadas na atribuição. Não é necessário declarar tipo.

# Tipos primitivos
nome = "Ricardo"          # str
idade = 30                # int
altura = 1.75             # float
ativo = True              # bool
nulo = None               # NoneType

# Verificar tipo
print(type(nome))         # <class 'str'>
print(isinstance(idade, int))  # True
f-stringsFormatação

F-strings são a forma moderna e eficiente de formatar strings em Python 3.6+.

# f-strings (Python 3.6+)
nome = "Ricardo"
idade = 30
print(f"Olá, {nome}! Você tem {idade} anos.")

# Expressões dentro de f-strings
preco = 49.90
print(f"Preço: R${preco:.2f}")
print(f"{'Python':^20}")      # centralizado
print(f"{1024:_}")            # 1_024 (separador)

2. Operadores

AritméticosOperadores
a, b = 10, 3
print(a + b)    # 13
print(a - b)    # 7
print(a * b)    # 30
print(a / b)    # 3.333...
print(a // b)   # 3 (divisão inteira)
print(a % b)    # 1 (módulo)
print(a ** b)   # 1000 (potência)
Comparação e LógicosOperadores
# Comparação
x = 5
print(x == 5)    # True
print(x != 3)    # True
print(x > 3)     # True
print(x >= 5)    # True

# Lógicos
print(x > 3 and x < 10)  # True
print(x > 10 or x < 3)   # False
print(not (x > 10))       # True

3. Entrada e Conversão de Tipos

input / castingI/O
# Entrada do usuário (sempre retorna str)
nome = input("Seu nome: ")
idade = int(input("Sua idade: "))
peso = float(input("Seu peso: "))

# Conversões (casting)
numero_str = "42"
numero_int = int(numero_str)      # 42
numero_float = float(numero_str)  # 42.0
texto = str(123)                  # "123"
booleano = bool(1)                # True (0 = False)
