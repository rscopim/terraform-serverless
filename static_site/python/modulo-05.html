Manipulação de Arquivos — Fundamentos

A capacidade de ler e escrever arquivos é uma das habilidades mais fundamentais em programação. Em DevOps e automação cloud, você constantemente manipula arquivos de configuração, logs, relatórios e dados. Python oferece ferramentas poderosas e elegantes para trabalhar com arquivos de forma segura e eficiente.

📂 A Função open() — Porta de Entrada para Arquivos

A função built-in open() é o ponto de partida para qualquer operação com arquivos em Python. Ela retorna um objeto de arquivo (file object) que permite realizar operações de leitura, escrita ou ambas, dependendo do modo especificado.

Sintaxe Básica da Função open()

# Sintaxe completa da função open()
open(file, mode='r', buffering=-1, encoding=None, errors=None, newline=None, closefd=True, opener=None)

# Parâmetros mais utilizados:
# file     → caminho do arquivo (string ou Path object)
# mode     → modo de abertura (padrão: 'r' para leitura)
# encoding → codificação de caracteres (recomendado: 'utf-8')
# errors   → como tratar erros de codificação

💡 Dica Importante

Sempre especifique o encoding explicitamente ao trabalhar com arquivos de texto. O encoding padrão varia entre sistemas operacionais (UTF-8 no Linux/macOS, cp1252 no Windows), o que pode causar bugs difíceis de detectar em ambientes diferentes.

🔑 Modos de Abertura de Arquivo

O parâmetro mode controla como o arquivo será aberto. Você pode combinar modos de operação com modos de tipo para ter controle total sobre o comportamento.

Modo Descrição Se arquivo não existe Se arquivo existe
'r' Leitura (read) — modo padrão ❌ FileNotFoundError Lê do início
'w' Escrita (write) — cria/sobrescreve ✅ Cria novo arquivo ⚠️ Apaga conteúdo anterior
'a' Append — adiciona ao final ✅ Cria novo arquivo Escreve após conteúdo existente
'x' Criação exclusiva — falha se existir ✅ Cria novo arquivo ❌ FileExistsError
'b' Modo binário (combina com r/w/a/x) Trabalha com bytes, não strings
't' Modo texto (padrão, combina com r/w/a/x) Trabalha com strings Unicode
'+' Leitura E escrita simultâneas Combina com r/w/a

Exemplos de Combinações de Modos

# Modo texto (padrão) — leitura
arquivo = open('config.txt', 'r', encoding='utf-8')  # ou simplesmente 'rt'

# Modo texto — escrita (CUIDADO: apaga conteúdo anterior!)
arquivo = open('output.txt', 'w', encoding='utf-8')

# Modo texto — append (adiciona ao final sem apagar)
arquivo = open('log.txt', 'a', encoding='utf-8')

# Modo binário — leitura (para imagens, PDFs, etc.)
arquivo = open('imagem.png', 'rb')

# Modo binário — escrita
arquivo = open('backup.bin', 'wb')

# Leitura e escrita simultâneas
arquivo = open('dados.txt', 'r+', encoding='utf-8')

# Criação exclusiva — seguro para evitar sobrescrita acidental
arquivo = open('novo_relatorio.txt', 'x', encoding='utf-8')

🛡️ Context Manager (with statement) — SEMPRE Use!

O with statement é a forma correta e segura de trabalhar com arquivos em Python. Ele garante que o arquivo será fechado automaticamente, mesmo que ocorra uma exceção durante o processamento. Isso evita vazamentos de recursos e corrupção de dados.

❌ Forma INCORRETA — Sem Context Manager

# ❌ NUNCA faça isso em código de produção
arquivo = open('dados.txt', 'r', encoding='utf-8')
conteudo = arquivo.read()
# Se ocorrer uma exceção aqui, o arquivo nunca será fechado!
arquivo.close()  # Pode não ser executado em caso de erro

# ❌ Mesmo com try/finally, é verboso e propenso a erros
arquivo = open('dados.txt', 'r', encoding='utf-8')
try:
    conteudo = arquivo.read()
    processar(conteudo)
finally:
    arquivo.close()

✅ Forma CORRETA — Com Context Manager (with)

# ✅ SEMPRE use with — limpo, seguro e pythonico
with open('dados.txt', 'r', encoding='utf-8') as arquivo:
    conteudo = arquivo.read()
    # O arquivo será fechado automaticamente ao sair do bloco
    # Mesmo que ocorra uma exceção!

# ✅ Múltiplos arquivos simultaneamente
with open('entrada.txt', 'r', encoding='utf-8') as entrada, \
     open('saida.txt', 'w', encoding='utf-8') as saida:
    for linha in entrada:
        saida.write(linha.upper())

# ✅ Python 3.10+ — Parênteses para múltiplos context managers
with (
    open('config.json', 'r', encoding='utf-8') as config,
    open('log.txt', 'a', encoding='utf-8') as log,
    open('output.csv', 'w', encoding='utf-8') as output
):
    dados = json.load(config)
    log.write(f"Processando {len(dados)} registros\n")
    # ... processar dados

⚠️ Por que SEMPRE usar with?

  • Segurança: O arquivo é fechado mesmo com exceções
  • Recursos: Evita vazamento de file descriptors (limite do SO)
  • Dados: Garante que buffers são descarregados (flush) antes de fechar
  • Pythônico: É o padrão aceito pela comunidade Python
  • DevOps: Scripts de longa duração podem esgotar file descriptors sem with

📖 Leitura de Arquivos — Métodos Essenciais

Python oferece vários métodos para ler o conteúdo de arquivos, cada um adequado para diferentes cenários. A escolha do método correto impacta diretamente na performance e uso de memória do seu script.

Método read() — Lê Todo o Conteúdo

# read() — Lê o arquivo inteiro como uma única string
with open('config.txt', 'r', encoding='utf-8') as f:
    conteudo = f.read()
    print(type(conteudo))  # <class 'str'>
    print(len(conteudo))   # Número total de caracteres

# read(n) — Lê exatamente n caracteres
with open('grande_arquivo.log', 'r', encoding='utf-8') as f:
    primeiros_100 = f.read(100)  # Lê apenas 100 caracteres
    proximos_50 = f.read(50)     # Continua de onde parou

# ⚠️ CUIDADO: read() carrega TUDO na memória!
# Para arquivos grandes (GBs), use iteração por linhas
# Exemplo: arquivo de log de 5GB vai consumir 5GB+ de RAM

Método readline() — Lê Uma Linha por Vez

# readline() — Lê uma linha (incluindo \n)
with open('/var/log/syslog', 'r', encoding='utf-8') as f:
    primeira_linha = f.readline()   # "Jan  1 00:00:01 server kernel: ...\n"
    segunda_linha = f.readline()    # Próxima linha
    
    # readline() retorna '' (string vazia) no final do arquivo
    while True:
        linha = f.readline()
        if not linha:  # String vazia = fim do arquivo
            break
        print(linha.rstrip('\n'))  # Remove \n do final

# readline(n) — Lê até n caracteres da linha atual
with open('dados.txt', 'r', encoding='utf-8') as f:
    inicio = f.readline(20)  # Máximo de 20 caracteres da primeira linha

Método readlines() — Retorna Lista de Linhas

# readlines() — Retorna uma lista onde cada elemento é uma linha
with open('hosts.txt', 'r', encoding='utf-8') as f:
    linhas = f.readlines()
    # ['192.168.1.1 server1\n', '192.168.1.2 server2\n', ...]

# Cada linha mantém o \n no final
for linha in linhas:
    ip, hostname = linha.strip().split()
    print(f"Host: {hostname} → IP: {ip}")

# readlines(hint) — Lê linhas até atingir hint bytes
with open('grande.log', 'r', encoding='utf-8') as f:
    # Lê linhas até acumular ~4096 bytes
    bloco = f.readlines(4096)

✅ Iteração Direta — A Forma Mais Eficiente

# ✅ MELHOR PRÁTICA: Iterar diretamente sobre o arquivo
# Usa pouca memória, pois lê uma linha por vez (lazy)
with open('/var/log/auth.log', 'r', encoding='utf-8') as f:
    for linha in f:
        if 'Failed password' in linha:
            print(f"[ALERTA] Tentativa de login falha: {linha.strip()}")

# Contar linhas de forma eficiente (sem carregar tudo na memória)
with open('access.log', 'r', encoding='utf-8') as f:
    total_linhas = sum(1 for _ in f)
    print(f"Total de requisições: {total_linhas}")

# Filtrar e processar linhas
with open('terraform.tfstate', 'r', encoding='utf-8') as f:
    recursos = [linha.strip() for linha in f if '"type"' in linha]
    print(f"Recursos Terraform encontrados: {len(recursos)}")

# Processar arquivo grande em chunks (blocos)
def processar_em_blocos(caminho, tamanho_bloco=8192):
    """Processa arquivo grande em blocos de bytes."""
    with open(caminho, 'r', encoding='utf-8') as f:
        while True:
            bloco = f.read(tamanho_bloco)
            if not bloco:
                break
            yield bloco

Modo Append — Adicionando ao Final do Arquivo

# Modo 'a' — Append: adiciona ao final sem apagar conteúdo existente
# Perfeito para logs!
import datetime

def registrar_log(mensagem, arquivo='app.log'):
    """Registra uma mensagem com timestamp no arquivo de log."""

📍 Posição do Cursor — seek() e tell()

Todo arquivo aberto possui um "cursor" (file pointer) que indica a posição atual de leitura/escrita. Os métodos seek() e tell() permitem controlar essa posição.

Controlando a Posição no Arquivo

# tell() — Retorna a posição atual do cursor (em bytes)
with open('dados.txt', 'r', encoding='utf-8') as f:
    print(f.tell())       # 0 (início do arquivo)
    f.read(10)
    print(f.tell())       # 10 (após ler 10 caracteres)
    f.readline()
    print(f.tell())       # posição após a primeira linha completa

# seek(offset, whence) — Move o cursor para uma posição específica
# whence: 0 = início (padrão), 1 = posição atual, 2 = final do arquivo
with open('log.txt', 'r', encoding='utf-8') as f:
    f.seek(0)       # Vai para o início
    f.seek(100)     # Vai para o byte 100
    
# ⚠️ Em modo texto, seek() só aceita:
# - seek(0) para ir ao início
# - seek(posição_do_tell) para posição retornada por tell()
# Para seek arbitrário, use modo binário ('rb')

# Exemplo prático: ler as últimas N linhas de um log (como tail)
def tail(arquivo, n=10):
    """Retorna as últimas n linhas de um arquivo (similar ao tail)."""
    with open(arquivo, 'rb') as f:
        # Vai para o final do arquivo
        f.seek(0, 2)  # whence=2 → relativo ao final
        tamanho = f.tell()
        
        linhas = []
        bloco = min(tamanho, 8192)
        
        while len(linhas) <= n and f.tell() > 0:
            # Move para trás
            pos = max(f.tell() - bloco, 0)
            f.seek(pos)
            dados = f.read(min(bloco, tamanho - pos))
            linhas = dados.split(b'\n') + linhas
            f.seek(pos)
        
        # Retorna as últimas n linhas
        return [l.decode('utf-8') for l in linhas[-n:] if l]

# Uso: últimas 20 linhas do syslog
ultimas = tail('/var/log/syslog', 20)
for linha in ultimas:
    print(linha)

🌐 Encoding — Codificação de Caracteres

A codificação (encoding) define como caracteres são representados em bytes no arquivo. Escolher o encoding correto é crucial para evitar erros com acentos, emojis e caracteres especiais.

Trabalhando com Diferentes Encodings

# UTF-8 — Padrão universal (recomendado!)
with open('texto.txt', 'r', encoding='utf-8') as f:
    conteudo = f.read()

# Latin-1 (ISO-8859-1) — Legado, comum em sistemas Windows antigos
with open('legado.txt', 'r', encoding='latin-1') as f:
    conteudo = f.read()

# CP1252 — Windows padrão para português
with open('windows_file.txt', 'r', encoding='cp1252') as f:
    conteudo = f.read()

# Detectar encoding automaticamente (necessita chardet)
# pip install chardet
import chardet

def detectar_encoding(caminho):
    """Detecta o encoding de um arquivo."""
    with open(caminho, 'rb') as f:
        resultado = chardet.detect(f.read())
    return resultado['encoding'], resultado['confidence']

encoding, confianca = detectar_encoding('arquivo_misterioso.txt')
print(f"Encoding: {encoding} (confiança: {confianca:.0%})")

# Converter encoding de um arquivo
def converter_encoding(entrada, saida, encoding_origem, encoding_destino='utf-8'):
    """Converte um arquivo de um encoding para outro."""
    with open(entrada, 'r', encoding=encoding_origem) as f_in:
        conteudo = f_in.read()
    with open(saida, 'w', encoding=encoding_destino) as f_out:
        f_out.write(conteudo)

converter_encoding('legado.txt', 'moderno.txt', 'latin-1', 'utf-8')

Tratamento de Erros de Encoding

# O parâmetro errors controla o que fazer com caracteres inválidos
# errors='strict'  → Levanta UnicodeDecodeError (padrão)
# errors='ignore'  → Ignora caracteres inválidos

# Substituir por marcador
with open('arquivo_corrompido.log', 'r', encoding='utf-8', errors='replace') as f:
    conteudo = f.read()  # Caracteres inválidos viram '�'

# Em scripts DevOps, 'replace' ou 'ignore' são úteis para logs
# que podem ter sido parcialmente corrompidos
with open('/var/log/messages', 'r', encoding='utf-8', errors='replace') as f:
    for linha in f:
        if 'ERROR' in linha:
            print(linha.strip())

🖼️ Modo Binário — Imagens, PDFs e Dados Brutos

O modo binário ('rb', 'wb') trabalha com bytes ao invés de strings. É essencial para arquivos que não são texto puro, como imagens, PDFs, executáveis, arquivos compactados, etc.

Leitura e Escrita Binária

# Copiar um arquivo binário (imagem, PDF, etc.)
def copiar_arquivo(origem, destino, tamanho_bloco=65536):
    """Copia arquivo binário em blocos para uso eficiente de memória."""
    with open(origem, 'rb') as f_in, open(destino, 'wb') as f_out:
        while True:
            bloco = f_in.read(tamanho_bloco)
            if not bloco:
                break
            f_out.write(bloco)

copiar_arquivo('backup_db.tar.gz', '/mnt/backup/backup_db.tar.gz')

# Verificar tipo de arquivo pelo "magic number" (primeiros bytes)
def identificar_tipo(caminho):
    """Identifica o tipo de arquivo pelos primeiros bytes."""
    magic_numbers = {
        b'\x89PNG': 'PNG Image',
        b'\xff\xd8\xff': 'JPEG Image',
        b'%PDF': 'PDF Document',
        b'PK\x03\x04': 'ZIP Archive',
        b'\x1f\x8b': 'GZIP Archive',
        b'GIF87a': 'GIF Image',
        b'GIF89a': 'GIF Image',
    }
    
    with open(caminho, 'rb') as f:
        header = f.read(8)
    
    for magic, tipo in magic_numbers.items():
        if header.startswith(magic):
            return tipo
    return 'Desconhecido'

print(identificar_tipo('documento.pdf'))  # "PDF Document"
print(identificar_tipo('foto.jpg'))       # "JPEG Image"

# Calcular hash MD5 de arquivo (verificação de integridade)
import hashlib

def calcular_md5(caminho):
    """Calcula o hash MD5 de um arquivo."""
    hash_md5 = hashlib.md5()
    with open(caminho, 'rb') as f:
        for bloco in iter(lambda: f.read(8192), b''):
            hash_md5.update(bloco)
    return hash_md5.hexdigest()

md5 = calcular_md5('terraform_1.7.0_linux_amd64.zip')
print(f"MD5: {md5}")

# Calcular SHA256 (mais seguro, usado em deploys)
def calcular_sha256(caminho):
    """Calcula o hash SHA256 de um arquivo."""
    hash_sha = hashlib.sha256()
    with open(caminho, 'rb') as f:
        for bloco in iter(lambda: f.read(8192), b''):
            hash_sha.update(bloco)
    return hash_sha.hexdigest()

sha = calcular_sha256('app-deploy.tar.gz')
print(f"SHA256: {sha}")

Módulo pathlib — Caminhos Modernos

O módulo pathlib (Python 3.4+) é a forma moderna e orientada a objetos de trabalhar com caminhos de arquivo. Ele substitui as funções do módulo os.path por uma API mais intuitiva, elegante e multiplataforma. Em projetos DevOps, pathlib é indispensável para manipular caminhos de forma segura entre Windows e Linux.

🏗️ Criando Objetos Path

Um objeto Path representa um caminho no sistema de arquivos. Ele pode ser criado de várias formas e oferece operações poderosas para navegação e manipulação.

Criação e Operações Básicas com Path

from pathlib import Path, PurePath, PureWindowsPath, PurePosixPath

# Criar Path a partir de string
caminho = Path('/etc/nginx/nginx.conf')
caminho_win = Path(r'C:\Users\admin\Documents\config.yaml')

# Path do diretório atual
atual = Path('.')       # ou Path.cwd()
home = Path.home()      # /home/usuario ou C:\Users\usuario

# Construir caminhos com operador / (MUITO elegante!)
base = Path('/opt/app')
config = base / 'config' / 'settings.yaml'
# Resultado: /opt/app/config/settings.yaml

# joinpath() — alternativa ao operador /
logs = base.joinpath('logs', '2024', 'janeiro')
# Resultado: /opt/app/logs/2024/janeiro

# Path a partir de múltiplas partes
projeto = Path('/', 'home', 'deploy', 'apps', 'api-gateway')
# Resultado: /home/deploy/apps/api-gateway

# Path relativo
relativo = Path('src') / 'modules' / 'auth.py'
# Resultado: src/modules/auth.py

# Converter para absoluto
absoluto = relativo.resolve()
# Resultado: /home/usuario/projeto/src/modules/auth.py

# Expandir ~ (home do usuário)
config_user = Path('~/.aws/credentials').expanduser()
# Resultado: /home/usuario/.aws/credentials

🔍 Propriedades do Path — Anatomia de um Caminho

Objetos Path expõem propriedades úteis para extrair informações sobre cada componente do caminho, sem necessidade de manipulação manual de strings.

Propriedades Essenciais

from pathlib import Path

caminho = Path('/var/log/nginx/access.log.gz')

# Propriedades do caminho
print(caminho.name)      # 'access.log.gz'     — nome completo do arquivo
print(caminho.stem)      # 'access.log'        — nome sem última extensão
print(caminho.suffix)    # '.gz'               — última extensão
print(caminho.suffixes)  # ['.log', '.gz']     — todas as extensões
print(caminho.parent)    # /var/log/nginx      — diretório pai
print(caminho.parents)   # Sequência de todos os pais:
                         # [PosixPath('/var/log/nginx'),
                         #  PosixPath('/var/log'),
                         #  PosixPath('/var'),
                         #  PosixPath('/')]

print(caminho.parts)     # ('/', 'var', 'log', 'nginx', 'access.log.gz')
print(caminho.anchor)    # '/' (raiz do caminho)
print(caminho.root)      # '/'

# Verificar se é absoluto ou relativo
print(caminho.is_absolute())   # True
print(Path('src/app.py').is_absolute())  # False

# Modificar componentes do caminho

def atualizar_env(caminho, chave, valor):
    """Atualiza ou adiciona variável em arquivo .env"""
    env_path = Path(caminho)
    
    if env_path.exists():
        linhas = env_path.read_text(encoding='utf-8').splitlines()
    else:
        linhas = []
    
    # Procurar e substituir a chave
    encontrada = False
    for i, linha in enumerate(linhas):
        if linha.startswith(f'{chave}='):
            linhas[i] = f'{chave}={valor}'
            encontrada = True
            break
    
    if not encontrada:
        linhas.append(f'{chave}={valor}')
    
    env_path.write_text('\n'.join(linhas) + '\n', encoding='utf-8')

Quando trabalhamos com CSVs de milhões de linhas (comum em logs e métricas), precisamos técnicas eficientes para evitar esgotar a memória.

Técnicas para CSVs Grandes

import csv
from pathlib import Path

# Processar CSV grande linha por linha (streaming)
def contar_por_status(caminho):
    """Conta registros por status sem carregar tudo na memória."""
    contadores = {}
    
    with open(caminho, 'r', encoding='utf-8') as f:
        leitor = csv.DictReader(f)
        for registro in leitor:
            status = registro['status']
            contadores[status] = contadores.get(status, 0) + 1
    
    return contadores

# Processar em lotes (batches)
def processar_em_lotes(caminho, tamanho_lote=1000):
    """Processa CSV em lotes para operações em batch."""
    with open(caminho, 'r', encoding='utf-8') as f:
        leitor = csv.DictReader(f)
        lote = []
        
        for registro in leitor:
            lote.append(registro)
            
            if len(lote) >= tamanho_lote:
                yield lote
                lote = []
        
        # Último lote (pode ter menos que tamanho_lote)
        if lote:
            yield lote

# Uso com processamento em batch
for i, lote in enumerate(processar_em_lotes('grande.csv', 5000)):
    print(f"Processando lote {i+1}: {len(lote)} registros")
    # Inserir no banco, enviar para API, etc.

# Filtrar CSV grande gerando novo CSV menor
def filtrar_csv(entrada, saida, funcao_filtro):
    """Filtra linhas de CSV grande baseado em condição."""
    with open(entrada, 'r', encoding='utf-8') as f_in, \
         open(saida, 'w', encoding='utf-8', newline='') as f_out:
        
        leitor = csv.DictReader(f_in)
        escritor = csv.DictWriter(f_out, fieldnames=leitor.fieldnames)
        escritor.writeheader()
        
        total = 0
        filtrados = 0
        for registro in leitor:
            total += 1
            if funcao_filtro(registro):
                escritor.writerow(registro)
                filtrados += 1
    
    print(f"Filtrados: {filtrados}/{total} registros")

# Exemplo: Filtrar apenas erros 5xx de um log de acesso
filtrar_csv(
    'access_log.csv',
    'erros_5xx.csv',
    lambda r: r.get('status_code', '').startswith('5')

🔧 Serialização Customizada — Tipos Não Padrão

JSON só suporta tipos básicos (dict, list, str, int, float, bool, None). Para serializar datas, objetos Path, sets e outros tipos Python, precisamos de serialização customizada.

Custom Encoder e Parâmetro default

import json
import datetime
from pathlib import Path
from decimal import Decimal

# Problema: Tipos não suportados causam TypeError
dados = {
    'timestamp': datetime.datetime.now(),
    'caminho': Path('/var/log/app.log'),
    'preco': Decimal('29.99'),
    'tags': {'web', 'production', 'v2'},
}

# ❌ Isso gera TypeError!
# json.dumps(dados)  # TypeError: Object of type datetime is not JSON serializable

# ✅ Solução 1: Função default (simples e prática)
def serializar_custom(obj):
    """Serializa tipos Python que JSON não suporta nativamente."""
    if isinstance(obj, datetime.datetime):
        return obj.isoformat()
    elif isinstance(obj, datetime.date):
        return obj.isoformat()
    elif isinstance(obj, Path):
        return str(obj)
    elif isinstance(obj, Decimal):
        return float(obj)
    elif isinstance(obj, set):
        return sorted(list(obj))
    elif isinstance(obj, bytes):
        return obj.decode('utf-8')
    raise TypeError(f"Tipo não serializável: {type(obj).__name__}")

resultado = json.dumps(dados, default=serializar_custom, indent=2)
print(resultado)
# {
#   "timestamp": "2024-01-15T14:30:22.123456",
#   "caminho": "/var/log/app.log",
#   "preco": 29.99,
#   "tags": ["production", "v2", "web"]
# }

# ✅ Solução 2: JSONEncoder customizado (mais organizado)
class DevOpsEncoder(json.JSONEncoder):
    """Encoder JSON personalizado para tipos comuns em DevOps."""
    
    def default(self, obj):
        if isinstance(obj, datetime.datetime):
            return obj.isoformat()
        elif isinstance(obj, datetime.date):
            return obj.isoformat()
        elif isinstance(obj, Path):
            return str(obj)
        elif isinstance(obj, Decimal):
            return float(obj)
        elif isinstance(obj, set):
            return sorted(list(obj))
        elif isinstance(obj, bytes):
            import base64
            return base64.b64encode(obj).decode('ascii')
        return super().default(obj)

# Uso do encoder customizado
resultado = json.dumps(dados, cls=DevOpsEncoder, indent=2)

# Salvar em arquivo com encoder customizado
with open('relatorio.json', 'w', encoding='utf-8') as f:
    json.dump(dados, f, cls=DevOpsEncoder, indent=2, ensure_ascii=False)

# ✅ Solução 3: Preparar dados antes de serializar
def preparar_para_json(obj):
    """Converte recursivamente um objeto para tipos JSON-compatíveis."""
    if isinstance(obj, dict):
        return {k: preparar_para_json(v) for k, v in obj.items()}
    elif isinstance(obj, (list, tuple)):
        return [preparar_para_json(item) for item in obj]
    elif isinstance(obj, set):
        return sorted([preparar_para_json(item) for item in obj])
    elif isinstance(obj, datetime.datetime):
        return obj.isoformat()
    elif isinstance(obj, Path):
        return str(obj)
    elif isinstance(obj, Decimal):
        return float(obj)
    return obj

dados_preparados = preparar_para_json(dados)
json_final = json.dumps(dados_preparados, indent=2)

def deep_merge(base, override):
    """Faz merge profundo de dois dicionários (override sobrescreve base)."""
    resultado = base.copy()

        if (chave in resultado and 
            isinstance(resultado[chave], dict) and 
            isinstance(valor, dict)):
            resultado[chave] = deep_merge(resultado[chave], valor)
        else:
            resultado[chave] = valor
    
    return resultado

⚠️ Cuidados com JSON

  • JSON não suporta comentários — use JSONC ou YAML se precisar de comentários
  • Trailing commas — JSON não aceita vírgula após o último item
  • Single quotes — JSON obriga aspas duplas, não aceita simples
  • Precisão numérica — Floats podem perder precisão; use strings para valores monetários
  • Segurança — Nunca use eval() para parsear JSON! Sempre json.loads()
  • Tamanho — Para arquivos JSON muito grandes (> 1GB), considere ijson (streaming)

Retry Pattern — Tentativas com Backoff

import time
import random

def retry(funcao, max_tentativas=3, delay_base=1, backoff=2, excecoes=(Exception,)):
    """
    Decorator/função que implementa retry com exponential backoff.
    
    Args:
        funcao: Função a ser executada
        max_tentativas: Número máximo de tentativas
        delay_base: Delay inicial em segundos
        backoff: Multiplicador do delay a cada tentativa
        excecoes: Tuple de exceções que devem triggar retry
    """
    for tentativa in range(1, max_tentativas + 1):
        try:
            resultado = funcao()
            return resultado
        except excecoes as e:
            if tentativa == max_tentativas:
                print(f"❌ Falhou após {max_tentativas} tentativas: {e}")
                raise
            
            # Calcular delay com jitter (aleatoriedade)
            delay = delay_base * (backoff ** (tentativa - 1))
            jitter = random.uniform(0, delay * 0.1)
            tempo_espera = delay + jitter
            
            print(f"⚠️ Tentativa {tentativa}/{max_tentativas} falhou: {e}")
            print(f"   Aguardando {tempo_espera:.1f}s antes de tentar novamente...")
            time.sleep(tempo_espera)

# Decorator de retry (versão avançada)
import functools

def com_retry(max_tentativas=3, delay=1, excecoes=(Exception,)):
    """Decorator que adiciona retry automático a uma função."""
    def decorator(func):
        @functools.wraps(func)
        def wrapper(*args, **kwargs):
            for tentativa in range(1, max_tentativas + 1):
                try:
                    return func(*args, **kwargs)
                except excecoes as e:
                    if tentativa == max_tentativas:
                        raise
                    time.sleep(delay * tentativa)
            return None
        return wrapper
    return decorator

@com_retry(max_tentativas=3, delay=2, excecoes=(ConnectionError, TimeoutError))
def buscar_dados_api(endpoint):

Logging — Registro Profissional de Erros

O módulo logging é a forma profissional de registrar eventos, erros e informações em aplicações Python. Diferente do print(), o logging oferece níveis de severidade, formatação configurável, múltiplos destinos (arquivo, console, rede) e é desenhado para código de produção. Em DevOps, bom logging é a diferença entre encontrar a causa raiz de um problema em 5 minutos ou 5 horas.

import sys

# CONFIGURAÇÃO PROFISSIONAL
# ══════════════════════════════════════

def configurar_logging(nome_app, nivel=logging.INFO, log_dir='logs'):
    """Configura logging profissional com múltiplos handlers."""
    from pathlib import Path
    
    # Criar diretório de logs
    Path(log_dir).mkdir(parents=True, exist_ok=True)
    
    # Criar logger principal
    logger = logging.getLogger(nome_app)
    logger.setLevel(logging.DEBUG)  # Captura tudo, handlers filtram
    
    # Formato para arquivo (detalhado)
    formato_arquivo = logging.Formatter(
        '%(asctime)s [%(levelname)8s] %(name)s.%(funcName)s:%(lineno)d — %(message)s',
        datefmt='%Y-%m-%d %H:%M:%S'
    )
    
    # Formato para console (compacto)
    formato_console = logging.Formatter(
        '%(asctime)s [%(levelname)s] %(message)s',
        datefmt='%H:%M:%S'
    )
    
    # Handler 1: Console (INFO+)
    console_handler = logging.StreamHandler(sys.stdout)
    console_handler.setLevel(logging.INFO)
    console_handler.setFormatter(formato_console)
    
    # Handler 2: Arquivo rotativo por tamanho (DEBUG+)
    # Rotaciona quando chega a 10MB, mantém 5 backups
    arquivo_handler = RotatingFileHandler(
        f'{log_dir}/{nome_app}.log',
        maxBytes=10*1024*1024,  # 10 MB
        backupCount=5,
        encoding='utf-8'
    )
    arquivo_handler.setLevel(logging.DEBUG)
    arquivo_handler.setFormatter(formato_arquivo)
    
    # Handler 3: Arquivo separado para ERROS
    erro_handler = RotatingFileHandler(
        f'{log_dir}/{nome_app}_errors.log',
        maxBytes=5*1024*1024,  # 5 MB
        backupCount=10,
        encoding='utf-8'
    )
    erro_handler.setLevel(logging.ERROR)
    erro_handler.setFormatter(formato_arquivo)
    
    # Handler 4: Rotação diária (para audit logs)
    audit_handler = TimedRotatingFileHandler(
        f'{log_dir}/{nome_app}_audit.log',
        when='midnight',      # Rotaciona à meia-noite
        interval=1,           # A cada 1 dia
        backupCount=30,       # Mantém 30 dias
        encoding='utf-8'
    )
    audit_handler.setLevel(logging.INFO)
    audit_handler.setFormatter(formato_arquivo)
    
    # Adicionar handlers ao logger
    logger.addHandler(console_handler)
    logger.addHandler(arquivo_handler)
    logger.addHandler(erro_handler)
    logger.addHandler(audit_handler)
    
    return logger

class JSONFormatter(logging.Formatter):
    """Formatter que gera logs em formato JSON (para CloudWatch, ELK, etc)."""

        if hasattr(record, 'extra_data'):
            log_entry['data'] = record.extra_data
        
        return json.dumps(log_entry, ensure_ascii=False)

💡 Boas Práticas de Logging em DevOps

  • Use __name__ como nome do logger: logger = logging.getLogger(__name__) — permite filtrar por módulo

    """

    """

        'status': int(match.group(6)),

        self.arquivo = Path(arquivo)

    def _garantir_arquivo(self):

        registros = []
        try:
            with open(self.arquivo, 'r', encoding='utf-8') as f:
                reader = csv.DictReader(f)

        except FileNotFoundError:
            self._garantir_arquivo()

    def _salvar_todos(self, registros):
        """Salva todos os registros no CSV (reescreve)."""
        with open(self.arquivo, 'w', encoding='utf-8', newline='') as f:
            writer = csv.DictWriter(f, fieldnames=self.CAMPOS)
            writer.writeheader()
            writer.writerows(registros)
    
    def _proximo_id(self):
        """Gera o próximo ID disponível."""
        registros = self._ler_todos()
        if not registros:
            return '1'
        return str(max(int(r['id']) for r in registros) + 1)

        # Validações

        # Verificar duplicata
        existentes = self._ler_todos()
        for reg in existentes:
            if reg['hostname'] == hostname:
                raise ValueError(f"Hostname '{hostname}' já existe (ID: {reg['id']})")
            if reg['ip'] == ip:
                raise ValueError(f"IP '{ip}' já está em uso por '{reg['hostname']}'")
        
        novo = {
            'id': self._proximo_id(),
            'hostname': hostname,
            'ip': ip,

import json
from pathlib import Path
from copy import deepcopy

class ConfigManager:
    """
    Gerenciador de configuração com suporte a:
    - Herança de ambientes (base + overlay)
    - Valores padrão
    - Validação de campos obrigatórios
    - Variáveis de ambiente como override
    """
    
    def __init__(self, config_dir='config'):
        self.config_dir = Path(config_dir)
        self._config = {}
        self._ambiente = None
    
    def carregar(self, ambiente='development'):
        """
        Carrega configuração com herança:
        1. config/base.json (configuração base)
        2. config/{ambiente}.json (override do ambiente)
        3. Variáveis de ambiente (override final)
        """
        self._ambiente = ambiente
        
        # Carregar base
        base_path = self.config_dir / 'base.json'
        if base_path.exists():
            self._config = self._ler_json(base_path)
        else:
            raise FileNotFoundError(f"Configuração base não encontrada: {base_path}")
        
        # Carregar overlay do ambiente
        env_path = self.config_dir / f'{ambiente}.json'
        if env_path.exists():
            overlay = self._ler_json(env_path)
            self._config = self._deep_merge(self._config, overlay)
        
        # Aplicar variáveis de ambiente (prefixo APP_)
        self._aplicar_env_vars()
        
        return self
    
    def _ler_json(self, path):
        """Lê e parseia arquivo JSON com tratamento de erros."""
        try:
            with open(path, 'r', encoding='utf-8') as f:
                return json.load(f)
        except json.JSONDecodeError as e:
            raise ValueError(f"JSON inválido em {path}: {e.msg} (linha {e.lineno})")
    
    def _deep_merge(self, base, override):
        """Merge profundo: override sobrescreve base, recursivamente."""
        resultado = deepcopy(base)
        for chave, valor in override.items():
            if (chave in resultado and 
                isinstance(resultado[chave], dict) and 
                isinstance(valor, dict)):
                resultado[chave] = self._deep_merge(resultado[chave], valor)
            else:
                resultado[chave] = deepcopy(valor)
        return resultado
    
    def _aplicar_env_vars(self):
        """Aplica variáveis de ambiente como override (APP_DATABASE__HOST → database.host)."""
        import os
        prefixo = 'APP_'
        
        for chave, valor in os.environ.items():
            if chave.startswith(prefixo):
                # APP_DATABASE__HOST → ['database', 'host']
                partes = chave[len(prefixo):].lower().split('__')
                self._definir_aninhado(partes, valor)
    
    def _definir_aninhado(self, chaves, valor):
        """Define valor em dict aninhado usando lista de chaves."""
        atual = self._config
        for chave in chaves[:-1]:
            if chave not in atual:
                atual[chave] = {}
            atual = atual[chave]
        
        # Tentar converter para tipo adequado
        atual[chaves[-1]] = self._converter_tipo(valor)
    
    def _converter_tipo(self, valor):
        """Converte string para tipo Python apropriado."""
        if valor.lower() == 'true':
            return True
        if valor.lower() == 'false':
            return False
        try:
            return int(valor)
        except ValueError:
            pass
        try:
            return float(valor)
        except ValueError:
            pass
        return valor
    
    def get(self, chave_pontilhada, padrao=None):
        """
        Obtém valor usando notação pontilhada.
        Ex: config.get('database.host') → config['database']['host']
        """
        chaves = chave_pontilhada.split('.')
        atual = self._config
        
        for chave in chaves:
            if isinstance(atual, dict) and chave in atual:
                atual = atual[chave]
            else:
                return padrao
        
        return atual
    
    def set(self, chave_pontilhada, valor):
        """Define valor usando notação pontilhada."""
        chaves = chave_pontilhada.split('.')
        self._definir_aninhado(chaves, valor)
    
    def validar(self, campos_obrigatorios):
        """Valida que todos os campos obrigatórios estão presentes."""
        ausentes = []
        for campo in campos_obrigatorios:
            if self.get(campo) is None:
                ausentes.append(campo)
        
        if ausentes:
            raise ValueError(
                f"Campos obrigatórios ausentes na configuração ({self._ambiente}):\n"
                + "\n".join(f"  - {c}" for c in ausentes)
            )
    
    def salvar(self, caminho=None):
        """Salva a configuração atual em arquivo JSON."""
        if caminho is None:
            caminho = self.config_dir / f'{self._ambiente}_merged.json'
        
        with open(caminho, 'w', encoding='utf-8') as f:
            json.dump(self._config, f, indent=2, ensure_ascii=False)
        
        print(f"✅ Configuração salva: {caminho}")
    
    def __repr__(self):
        return f"ConfigManager(ambiente={self._ambiente}, chaves={len(self._config)})"

        elif self.formato_origem == 'csv':

        elif self.formato_origem == 'yaml':

            self.dados = list(reader)

        if not HAS_YAML:
            raise ImportError("PyYAML não instalado. Execute: pip install pyyaml")
        with open(path, 'r', encoding='utf-8') as f:
            self.dados = yaml.safe_load(f)

        """Salva dados no formato especificado (ou detecta pela extensão)."""
        if self.dados is None:
            raise ValueError("Nenhum dado carregado. Use carregar() primeiro.")
        
        path = Path(caminho)
        if formato is None:
            formato = self.detectar_formato(caminho)
        
        path.parent.mkdir(parents=True, exist_ok=True)
        
        if formato == 'json':
            self._salvar_json(path)
        elif formato == 'csv':
            self._salvar_csv(path)
        elif formato == 'yaml':
            self._salvar_yaml(path)

            raise ValueError("Lista de dados está vazia")

class SistemaBackup:

            'erros': 0,

        }

        """Configura logging para o sistema de backup."""
        logger = logging.getLogger('backup')
        logger.setLevel(logging.DEBUG)

        ch = logging.StreamHandler()
        ch.setLevel(logging.INFO)
        ch.setFormatter(logging.Formatter(

        ))

        Path('logs').mkdir(exist_ok=True)

        fh.setFormatter(logging.Formatter(

        ))
        logger.addHandler(fh)
        
        return logger
    
    def _carregar_config(self, path):

        default_config = {
            'origens': [],
            'destino': '/tmp/backups',
            'compactar': True,
            'verificar_integridade': True,
            'extensoes_ignorar': ['.tmp', '.log', '.pyc'],
            'tamanho_max_mb': 100,
        }

                default_config.update(config)
                self.logger.info(f"Configuração carregada: {path}")
        except FileNotFoundError:
            self.logger.warning(f"Config não encontrada, usando padrões: {path}")
        except json.JSONDecodeError as e:
            self.logger.error(f"Config inválida: {e}")

        """Calcula SHA256 para verificação de integridade."""
        sha256 = hashlib.sha256()
        with open(caminho, 'rb') as f:
            for bloco in iter(lambda: f.read(65536), b''):
                sha256.update(bloco)
        return sha256.hexdigest()

        # Ignorar por extensão

            return True
        
        # Ignorar por tamanho
        try:
            tamanho_mb = arquivo.stat().st_size / (1024 * 1024)

                self.logger.warning(
                    f"Ignorando (muito grande): {arquivo.name} "
                    f"({tamanho_mb:.1f} MB > {self.config['tamanho_max_mb']} MB)"

            return True

                destino_final = destino_gz

            self.estatisticas['arquivos_copiados'] += 1
            self.estatisticas['bytes_transferidos'] += tamanho

            if not origem.exists():
                self.logger.warning(f"Origem não existe: {origem}")
                continue
            
            self.logger.info(f"\nProcessando: {origem}")
            
            if origem.is_file():
                if not self._deve_ignorar(origem):
                    self._copiar_arquivo(origem, destino_base / origem.name)
            else:
                for arquivo in origem.rglob('*'):
                    if arquivo.is_file() and not self._deve_ignorar(arquivo):
                        rel = arquivo.relative_to(origem)
                        self._copiar_arquivo(arquivo, destino_base / origem.name / rel)
                    elif self._deve_ignorar(arquivo):

class TransformacaoError(Exception):
    """Erro durante transformação de dados."""
    def __init__(self, mensagem, registro=None, campo=None):
        super().__init__(mensagem)
        self.registro = registro

class PipelineTransformacao:
    """
    Pipeline configurável para transformação de dados.
    
    Fluxo: Fonte → Transformações → Filtros → Validação → Destino
    """
    
    def __init__(self, nome='pipeline'):
        self.nome = nome
        self.transformacoes = []
        self.filtros = []
        self.validacoes = []
        self.erros = []
        self.stats = {'lidos': 0, 'transformados': 0, 'filtrados': 0, 'erros': 0}
    
    def adicionar_transformacao(self, nome, funcao):
        """Adiciona uma transformação ao pipeline."""
        self.transformacoes.append({'nome': nome, 'funcao': funcao})
        return self
    
    def adicionar_filtro(self, nome, funcao):
        """Adiciona um filtro (retorna True para manter, False para remover)."""
        self.filtros.append({'nome': nome, 'funcao': funcao})
        return self
    
    def adicionar_validacao(self, nome, funcao):
        """Adiciona validação (levanta exceção se inválido)."""
        self.validacoes.append({'nome': nome, 'funcao': funcao})
        return self
    
    def _carregar_fonte(self, caminho):
        """Carrega dados da fonte (detecta formato)."""
        path = Path(caminho)
        sufixo = path.suffix.lower()
        
        if sufixo == '.json':
            with open(path, 'r', encoding='utf-8') as f:
                dados = json.load(f)
                return dados if isinstance(dados, list) else [dados]
        
        elif sufixo == '.csv':
            with open(path, 'r', encoding='utf-8') as f:
                return list(csv.DictReader(f))
        
        else:
            raise ValueError(f"Formato não suportado: {sufixo}")
    
    def _aplicar_transformacoes(self, registro):
        """Aplica todas as transformações em um registro."""
        resultado = registro.copy()
        
        for t in self.transformacoes:
            try:
                resultado = t['funcao'](resultado)
            except Exception as e:
                raise TransformacaoError(
                    f"Erro na transformação '{t['nome']}': {e}",
                    registro=registro
                )
        
        return resultado
    
    def _aplicar_filtros(self, registro):
        """Aplica filtros. Retorna True se deve manter."""
        for f in self.filtros:
            try:
                if not f['funcao'](registro):
                    return False
            except Exception:
                return False
        return True
    
    def _validar(self, registro):
        """Aplica validações. Levanta exceção se inválido."""
        for v in self.validacoes:
            try:
                v['funcao'](registro)
            except Exception as e:
                raise TransformacaoError(
                    f"Validação '{v['nome']}' falhou: {e}",
                    registro=registro
                )

        logger.info(f"Pipeline '{self.nome}' iniciado")
        logger.info(f"  Entrada: {entrada}")
        logger.info(f"  Saída: {saida}")

            dados = self._carregar_fonte(entrada)
            self.stats['lidos'] = len(dados)
            logger.info(f"  Registros carregados: {len(dados)}")
        except Exception as e:
            logger.error(f"Erro ao carregar fonte: {e}")
            raise
        
        # Processar cada registro
        resultados = []
        for i, registro in enumerate(dados):
            try:

                    self.stats['filtrados'] += 1
                    continue

                self._validar(transformado)

                self.stats['transformados'] += 1
                
            except TransformacaoError as e:

from pathlib import Path
from datetime import datetime

# Nota: Em produção, use uma biblioteca como 'cryptography'

logger = logging.getLogger('secrets_manager')

class SecretManagerError(Exception):

    pass

class SecretNotFoundError(SecretManagerError):

    pass

class SimpleSecretManager:
    """
    Gerenciador de secrets com armazenamento criptografado.
    
    NOTA: Para produção, use AWS Secrets Manager, HashiCorp Vault
    ou similar. Este é um exemplo educacional.
    """
    
    def __init__(self, arquivo='secrets.enc.json', audit_log='secrets_audit.log'):
        self.arquivo = Path(arquivo)
        self.audit_log = Path(audit_log)
        self._chave = None
        self._dados = None
        self._configurar_audit_log()
    
    def _configurar_audit_log(self):
        """Configura logging de auditoria."""
        handler = logging.FileHandler(self.audit_log, encoding='utf-8')
        handler.setFormatter(logging.Formatter(
            '%(asctime)s [AUDIT] %(message)s'
        ))
        logger.addHandler(handler)
        logger.setLevel(logging.INFO)
    
    def _derivar_chave(self, senha):
        """Deriva chave de criptografia a partir da senha master."""
        # Em produção, use PBKDF2, scrypt ou argon2
        salt = b'cloudtrilhas_salt_educacional'
        return hashlib.pbkdf2_hmac('sha256', senha.encode(), salt, 100000)
    
    def _criptografar(self, texto):
        """Criptografia simples XOR (educacional - use Fernet em produção!)."""
        if not self._chave:
            raise SecretManagerError("Vault não desbloqueado")
        
        dados = texto.encode('utf-8')
        chave_expandida = (self._chave * ((len(dados) // len(self._chave)) + 1))[:len(dados)]
        cifrado = bytes(a ^ b for a, b in zip(dados, chave_expandida))
        return base64.b64encode(cifrado).decode('ascii')
    
    def _descriptografar(self, texto_cifrado):
        """Descriptografa dados."""
        if not self._chave:
            raise SecretManagerError("Vault não desbloqueado")
        
        cifrado = base64.b64decode(texto_cifrado.encode('ascii'))
        chave_expandida = (self._chave * ((len(cifrado) // len(self._chave)) + 1))[:len(cifrado)]
        dados = bytes(a ^ b for a, b in zip(cifrado, chave_expandida))
        return dados.decode('utf-8')

        if self.arquivo.exists():
            raise SecretManagerError("Vault já existe. Use desbloquear().")

        self._dados = {

            'criado_em': datetime.now().isoformat(),
            'secrets': {},

@contextmanager
def timer(nome, logger):
    """Context manager para medir tempo de operações."""
    inicio = time.time()
    logger.info(f"⏱️ Iniciando: {nome}")
    try:
        yield
    finally:
        duracao = time.time() - inicio
        logger.info(f"⏱️ {nome}: {duracao:.2f}s")

def retry_com_backoff(funcao, max_tentativas=3, delay=1, excecoes=(Exception,), logger=None):
    """Executa função com retry e exponential backoff."""
    for tentativa in range(1, max_tentativas + 1):
        try:
            return funcao()
        except excecoes as e:
            if tentativa == max_tentativas:
                if logger:
                    logger.error(f"Falhou após {max_tentativas} tentativas: {e}")
                raise
            espera = delay * (2 ** (tentativa - 1))
            if logger:
                logger.warning(f"Tentativa {tentativa} falhou: {e}. Retry em {espera}s...")
            time.sleep(espera)

            time.sleep(0.3)  # Simular transferência
            self.logger.info(f"  ✅ {servidor}: Deploy concluído")
        
        self._registrar_evento('deploy_servidores', 'sucesso')
    
    def _etapa_health_check(self):
        """Verifica saúde dos servidores após deploy."""
        self.logger.info("Executando health checks...")
        self.estado = 'verificando'
        
        def verificar():
            # Simular health check com possibilidade de falha transitória
            time.sleep(0.2)
            return True
        
        for servidor in self.config['servidores']:
            try:
                resultado = retry_com_backoff(
                    verificar,
                    max_tentativas=3,
                    delay=1,
                    excecoes=(ConnectionError, TimeoutError),
                    logger=self.logger
                )
                self.logger.info(f"  ✅ {servidor}: Saudável")
            except Exception as e:
                raise HealthCheckError(
                    f"Servidor {servidor} não respondeu",
                    contexto={'servidor': servidor, 'erro': str(e)}
                )
        
        self._registrar_evento('health_check', 'sucesso')
    
    def _executar_rollback(self):
        """Executa rollback em caso de falha."""
        self.logger.warning("🔄 Iniciando ROLLBACK...")
        self.estado = 'rollback'
        
        try:
            for servidor in self.config.get('servidores', []):
                self.logger.info(f"  ← Revertendo {servidor}...")
                time.sleep(0.2)
            
            self.logger.info("  ✅ Rollback concluído com sucesso")
            self._registrar_evento('rollback', 'sucesso')
            
        except Exception as e:
            self.logger.critical(f"🚨 ROLLBACK FALHOU: {e}")
            self._registrar_evento('rollback', 'falha', str(e))
            raise RollbackError(f"Rollback falhou: {e}")
    
    def _gerar_relatorio(self, sucesso, duracao):

        relatorio = {

            'ambiente': self.config['ambiente'],

            'historico': self.historico,

        }
        
        # Salvar relatório
