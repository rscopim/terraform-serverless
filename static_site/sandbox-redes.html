🧮 Calculadora de Subnet / CIDR

Informe um IP e o prefixo (CIDR) para calcular rede, broadcast, faixa de hosts e classe.

Preencha os campos e clique em Calcular.

🗺️ Tabela de Roteamento

Adicione rotas (destino/prefixo via gateway) e teste um IP de destino. O simulador aplica longest-prefix match.

📶 Modelo OSI / TCP-IP

Clique em uma camada para ver os detalhes: papel, equivalente TCP/IP, PDU, protocolos e dispositivos típicos.

🖧 Montar Rede + Roteamento

Escolha o tamanho da rede. O simulador cria as sub-redes (LANs) ligadas a um roteador central (R1). Sua missão: criar as rotas até todas as LANs se comunicarem.

💡 Dica: tudo roda no seu navegador — nenhum dado é enviado a servidores. Use os simuladores para resolver os exercícios ou para estudar livremente conceitos de endereçamento, roteamento e camadas de rede.
