Conceitos de Cloud

Benefícios da cloud computing, modelos de implantação e serviço, Well-Architected Framework, Cloud Adoption Framework e estratégias de migração.

6 Benefícios da Cloud Computing

Vantagens fundamentais da computação em nuvem segundo a AWS:

#BenefícioDescrição
1Trocar CAPEX por OPEXSem investimento inicial em data centers. Pague apenas pelo que usar (pay-as-you-go).
2Economias de escalaAWS agrega uso de milhares de clientes, resultando em preços menores.
3Parar de adivinhar capacidadeEscale para cima ou para baixo conforme a demanda real, sem over/under-provisioning.
4Aumentar velocidade e agilidadeRecursos disponíveis em minutos (vs. semanas em on-premises).
5Parar de gastar com data centersFoque no negócio, não em manter infraestrutura física.
6Alcance global em minutosDeploy em múltiplas regiões ao redor do mundo com poucos cliques.

💡 Dica para o exame: Esses 6 benefícios são cobrados diretamente. Memorize cada um e saiba associar cenários a eles.

Modelos de Implantação (Deployment Models)

Cloud PúblicaPublic
• Recursos 100% na nuvem (AWS, Azure, GCP)
• Sem infraestrutura on-premises
• Máxima elasticidade e agilidade
• Pay-as-you-go
• Exemplo: startup que nasce na AWS
On-Premises (Private Cloud)Privada
• Infraestrutura no data center próprio
• Virtualização e automação local
• Controle total sobre hardware
• Sem benefícios de elasticidade da cloud
• Exemplo: empresa com requisitos regulatórios rígidos
HíbridaHybrid
• Combina cloud pública + on-premises
• Conectados via VPN ou Direct Connect
• Dados sensíveis on-prem, workloads elásticos na cloud
• AWS Outposts: hardware AWS no seu data center
• Exemplo: banco com dados regulados + apps na cloud

Modelos de Serviço (IaaS / PaaS / SaaS)

ModeloVocê GerenciaAWS GerenciaExemplos AWS
IaaS (Infrastructure as a Service)OS, runtime, apps, dadosHardware, rede, virtualizaçãoEC2, VPC, EBS
PaaS (Platform as a Service)Apps e dadosOS, runtime, hardware, redeElastic Beanstalk, RDS, Lambda
SaaS (Software as a Service)Apenas configuraçãoTudo (infra + app)Amazon WorkMail, Amazon Chime

🎯 Para o exame: IaaS = máximo controle, mais responsabilidade | PaaS = foco no código | SaaS = apenas usa o software. EC2 = IaaS, Beanstalk = PaaS.

Well-Architected Framework — 6 Pilares

Framework da AWS para projetar arquiteturas seguras, resilientes, eficientes e econômicas:

PilarFocoPalavras-chave
1. Excelência OperacionalExecutar e monitorar sistemas para entregar valor de negócioIaC, automação, runbooks, observabilidade, melhoria contínua
2. SegurançaProteger informações, sistemas e ativosIAM, criptografia, rastreabilidade, menor privilégio, defesa em profundidade
3. ConfiabilidadeGarantir que workloads funcionem corretamente e se recuperem de falhasRecuperação de desastres, auto scaling, multi-AZ, backups
4. Eficiência de PerformanceUsar recursos computacionais de forma eficienteTipo certo de recurso, monitoramento, experimentação, serverless
5. Otimização de CustosEvitar gastos desnecessáriosPay-as-you-go, Reserved Instances, right-sizing, desligar recursos ociosos
6. SustentabilidadeMinimizar impacto ambiental dos workloadsEficiência energética, right-sizing, regiões sustentáveis, reduzir desperdício

Princípios de Design na Cloud

Princípios GeraisDesign
• Pare de adivinhar capacidade
• Teste sistemas em escala de produção
• Automatize para facilitar experimentação
• Permita arquiteturas evolutivas
• Construa com dados (data-driven)
• Melhore através de game days
Conceitos ImportantesCloud
• Design for failure (tudo falha, planeje para isso)
• Decouple components (componentes independentes)
• Think parallel (escale horizontalmente)
• Elasticity (escale automaticamente)
• Disposable resources (recursos descartáveis)
• Automation (IaC, auto scaling, self-healing)

AWS Cloud Adoption Framework (CAF) — 6 Perspectivas

Framework para planejar a migração para a cloud, organizado em 6 perspectivas:

PerspectivaFocoStakeholders
BusinessAlinhar TI com objetivos de negócio, ROI, business caseCEO, CFO, gerentes de negócio
PeopleCultura, treinamento, gestão de mudanças organizacionaisRH, gerentes de pessoas
GovernanceOrquestrar iniciativas de cloud, compliance, riscoCIO, gerentes de programa, arquitetos enterprise
PlatformArquitetura, infraestrutura, provisionamento de recursosCTO, arquitetos, engenheiros
SecurityControles de segurança, compliance, gestão de riscosCISO, equipe de segurança
OperationsOperações do dia-a-dia, monitoramento, incident managementGerentes de operações, SRE

💡 Dica: Business + People + Governance = foco em negócio | Platform + Security + Operations = foco em técnico.

7 Rs — Estratégias de Migração

Estratégias para migrar workloads para a cloud:

EstratégiaDescriçãoQuando Usar
Rehost (Lift & Shift)Mover para a cloud sem alteraçõesMigração rápida, sem refatoração
Replatform (Lift & Reshape)Pequenas otimizações sem mudar a arquitetura coreMigrar DB para RDS, app para Beanstalk
Refactor / Re-architectRedesenhar usando serviços cloud-nativeMáximo benefício da cloud, microserviços
RepurchaseTrocar por solução SaaS (ex: CRM → Salesforce)Substituir software legado por SaaS
RetireDesligar/descontinuar a aplicaçãoApp não é mais necessária
RetainManter on-premises (não migrar agora)Compliance, dependências, não está pronto
RelocateMover infraestrutura para cloud sem comprar novo hardwareVMware Cloud on AWS, mover hypervisor

🎯 Para o exame: Rehost = mais rápido/simples | Refactor = mais benefícios da cloud | Retire = desligar | Retain = não migrar.

AWS Snow Family

Dispositivos físicos para migração de dados em larga escala e edge computing:

DispositivoCapacidadeCaso de Uso
Snowcone8 TB HDD / 14 TB SSDLocais remotos, edge computing, espaços pequenos (2.1 kg)
Snowball Edge Storage Optimized80 TBMigração de dados em larga escala, storage local temporário
Snowball Edge Compute Optimized42 TB + GPUEdge computing, ML em locais remotos, processamento local
Snowmobile100 PB (caminhão)Migração de exabytes de dados (data centers inteiros)

💡 Quando usar Snow Family: Quando a transferência pela rede levaria semanas/meses. Regra geral: se leva mais de 1 semana pela rede, considere Snow Family.
