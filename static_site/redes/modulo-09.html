Automação de Redes com Python e Ansible

Automatize configurações, coleta de dados e gerenciamento de dispositivos de rede.

1. Python para Redes — Netmiko

NetmikoPython

Biblioteca para conexão SSH com dispositivos de rede (Cisco, Juniper, Arista, etc.).

from netmiko import ConnectHandler

# Conexão com switch/router
device = {
    "device_type": "cisco_ios",
    "host": "192.168.1.1",
    "username": "admin",
    "password": "senha123",
}

# Comandos show
with ConnectHandler(**device) as conn:
    output = conn.send_command("show ip interface brief")
    print(output)

    # Configuração
    commands = [
        "interface loopback 99",
        "ip address 10.99.99.1 255.255.255.0",
        "description Criado via Python",
    ]
    conn.send_config_set(commands)
    conn.save_config()
ParamikoPython

Biblioteca SSH de baixo nível. Base do Netmiko.

import paramiko

# Conexão SSH direta
client = paramiko.SSHClient()
client.set_missing_host_key_policy(paramiko.AutoAddPolicy())
client.connect("192.168.1.1", username="admin", password="senha123")

# Executar comando
stdin, stdout, stderr = client.exec_command("show version")
print(stdout.read().decode())
client.close()

# Automação em massa
devices = ["192.168.1.1", "192.168.1.2", "192.168.1.3"]
for ip in devices:
    client.connect(ip, username="admin", password="senha123")
    stdin, stdout, stderr = client.exec_command("show running-config")
    with open(f"backup_{ip}.txt", "w") as f:
        f.write(stdout.read().decode())
    client.close()

2. Ansible para Redes

Ansible Network AutomationIaC
# inventory.yml
all:
  children:
    switches:
      hosts:
        sw01:
          ansible_host: 192.168.1.10
        sw02:
          ansible_host: 192.168.1.11
      vars:
        ansible_network_os: cisco.ios.ios
        ansible_connection: ansible.netcommon.network_cli
        ansible_user: admin
        ansible_password: senha123

---
# playbook-vlan.yml
- name: Configurar VLANs nos switches
  hosts: switches
  gather_facts: no
  tasks:
    - name: Criar VLAN 100
      cisco.ios.ios_vlans:
        config:
          - vlan_id: 100
            name: PRODUCAO
            state: active
        state: merged

    - name: Backup da configuração
      cisco.ios.ios_config:
        backup: yes

    - name: Coletar informações
      cisco.ios.ios_facts:
        gather_subset: all
      register: facts

    - name: Exibir hostname
      debug:
        msg: "{{ facts.ansible_facts.ansible_net_hostname }}"
Execução AnsibleCLI
# Instalar collections de rede
ansible-galaxy collection install cisco.ios
ansible-galaxy collection install ansible.netcommon

# Executar playbook
ansible-playbook -i inventory.yml playbook-vlan.yml

# Comandos ad-hoc
ansible switches -i inventory.yml -m cisco.ios.ios_command \
  -a "commands='show vlan brief'"

# Verificar conectividade
ansible switches -i inventory.yml -m ping
