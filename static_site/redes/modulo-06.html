Roteamento

Roteamento estático, dinâmico (OSPF, BGP), e conceitos de encaminhamento de pacotes.

1. Roteamento Estático

Rotas EstáticasConfig
# Conceito: administrador define manualmente as rotas
# Uso: redes pequenas, rotas específicas, backup

# Cisco IOS
Router(config)# ip route 10.0.0.0 255.255.255.0 192.168.1.1
Router(config)# ip route 0.0.0.0 0.0.0.0 203.0.113.1    # default route

# Linux
ip route add 10.0.0.0/24 via 192.168.1.1
ip route add default via 203.0.113.1

# Verificação
Router# show ip route
Router# show ip route static

Vantagens: simples, sem overhead, previsível
Desvantagens: não escala, sem failover automático

2. OSPF (Open Shortest Path First)

OSPFIGP
# Protocolo Link-State, usa algoritmo Dijkstra (SPF)
# Métrica: custo (baseado em bandwidth)
# AD (Administrative Distance): 110

# Conceitos:
# - Áreas (Area 0 = backbone, obrigatória)
# - LSA (Link-State Advertisements)
# - DR/BDR (Designated Router em redes multi-acesso)
# - Hello packets (10s em broadcast, 40s dead)

# Configuração básica
Router(config)# router ospf 1
Router(config-router)# network 192.168.1.0 0.0.0.255 area 0
Router(config-router)# network 10.0.0.0 0.0.0.255 area 1
Router(config-router)# passive-interface gi0/0

# Verificação
Router# show ip ospf neighbor
Router# show ip ospf interface brief
Router# show ip route ospf

3. BGP (Border Gateway Protocol)

BGPEGP
# Protocolo Path-Vector, usado entre Sistemas Autônomos (AS)
# "O protocolo da Internet" — conecta ISPs e grandes redes
# AD: eBGP = 20, iBGP = 200

# Conceitos:
# - AS (Autonomous System): rede sob administração única
# - eBGP: entre ASes diferentes
# - iBGP: dentro do mesmo AS
# - Prefixos e AS-PATH
# - Políticas de roteamento (route-maps, prefix-lists)

# Configuração básica
Router(config)# router bgp 65001
Router(config-router)# neighbor 203.0.113.1 remote-as 65002
Router(config-router)# network 192.168.0.0 mask 255.255.0.0
Router(config-router)# address-family ipv4 unicast

# Verificação
Router# show ip bgp summary
Router# show ip bgp
Router# show ip bgp neighbors
