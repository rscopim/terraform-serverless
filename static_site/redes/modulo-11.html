Observabilidade e Monitoramento

SNMP, Prometheus, Grafana e ferramentas para monitorar a saúde e performance da rede.

1. SNMP (Simple Network Management Protocol)

SNMPProtocolo
Componentes:
- Manager (NMS): coleta dados dos dispositivos
- Agent: software no dispositivo que responde queries
- MIB: banco de dados hierárquico de objetos gerenciáveis
- OID: identificador único de cada objeto

Operações:
- GET: consulta valor de um OID
- SET: altera valor de um OID
- TRAP: dispositivo envia alerta ao manager
- WALK: percorre toda a árvore MIB

Versões:
- SNMPv1: community strings (texto plano) — inseguro
- SNMPv2c: melhorias, mas ainda sem criptografia
- SNMPv3: autenticação + criptografia (recomendado!)

# Configuração (Cisco)
Router(config)# snmp-server community READONLY ro
Router(config)# snmp-server community READWRITE rw
Router(config)# snmp-server host 10.0.0.100 version 2c READONLY
Router(config)# snmp-server enable traps

# Consulta via Linux
snmpwalk -v2c -c READONLY 192.168.1.1 system
snmpget -v2c -c READONLY 192.168.1.1 sysUpTime.0

2. Prometheus + Grafana

PrometheusMétricas
# Prometheus: coleta e armazena métricas time-series
# Modelo pull: Prometheus busca métricas nos targets

# prometheus.yml
global:
  scrape_interval: 15s

scrape_configs:
  - job_name: 'network-devices'
    static_configs:
      - targets:
          - '192.168.1.1:9116'  # SNMP Exporter
          - '192.168.1.2:9116'

  - job_name: 'snmp'
    metrics_path: /snmp
    params:
      module: [if_mib]
    static_configs:
      - targets:
          - 192.168.1.1
          - 192.168.1.2
    relabel_configs:
      - source_labels: [__address__]
        target_label: __param_target

# Queries PromQL
rate(ifHCInOctets{ifDescr="GigabitEthernet0/0"}[5m]) * 8  # bps
ifOperStatus == 2  # interfaces down
increase(ifInErrors[1h])  # erros na última hora
GrafanaDashboards
# Grafana: visualização de métricas com dashboards

Dashboards de rede típicos:
- Utilização de banda por interface
- Status de interfaces (up/down)
- Latência e perda de pacotes
- Top talkers (hosts com mais tráfego)
- Erros e descartes por porta
- Uptime dos dispositivos

Alertas:
- Interface down → Slack/PagerDuty
- Utilização > 80% → E-mail
- Latência > 100ms → Ticket
- Erros crescentes → Investigar

Ferramentas complementares:
- SNMP Exporter: bridge Prometheus ↔ SNMP
- Blackbox Exporter: probes ICMP/HTTP/TCP
- Node Exporter: métricas de servidores Linux

3. Outras Ferramentas de Monitoramento

ZabbixNMS
Plataforma completa de monitoramento:
- SNMP, ICMP, agentes
- Auto-discovery de dispositivos
- Templates prontos (Cisco, Linux, etc.)
- Mapas de rede visuais
- Alertas e escalation
- Relatórios e SLA
Netflow / sFlowFluxo
Análise de tráfego por fluxo:
- Quem está comunicando com quem
- Quais aplicações consomem banda
- Detecção de anomalias

Ferramentas:
- ntopng
- Elastiflow
- PRTG
- SolarWinds NTA

# Cisco NetFlow config
Router(config)# flow exporter EXPORT
Router(config-flow-exporter)# destination 10.0.0.100
Router(config-flow-exporter)# transport udp 2055
