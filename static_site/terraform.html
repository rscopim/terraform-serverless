📚 Estrutura do Curso

4 Módulos Progressivos

Siga os módulos na ordem. Cada módulo adiciona novos recursos à infraestrutura construída no anterior.

Módulo 01Iniciante

VPC Completa

Estrutura de arquivos Terraform, Provider AWS, recursos de rede (VPC, Subnets, IGW, NAT, Route Tables), variáveis, outputs e comandos essenciais.
Módulo 02Intermediário

VPC + EC2

Security Groups, instâncias EC2, Key Pairs, User Data, Data Sources e funções Terraform.
Módulo 03Avançado I

VPC + EC2 + RDS

RDS MySQL, DB Subnet Group, Security Groups com referência cruzada, variáveis sensíveis e Locals.
Módulo 04Avançado II

VPC + EC2 + RDS + S3

S3 Bucket com versionamento, Bucket Policy, IAM Role, Instance Profile, Lifecycle Rules e terraform import.
Pré-requisitos: Conta AWS (Free Tier é suficiente), Terraform v1.5+ instalado, AWS CLI configurado, VS Code recomendado.
