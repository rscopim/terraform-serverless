Fundamentos de IA Generativa

Foundation Models, LLMs, conceitos técnicos (tokens, embeddings, context window), limitações, Amazon Bedrock e serviços AWS de IA generativa.

Foundation Models e Tipos de Modelos

Foundation Models (FMs)Base

Modelos massivos pré-treinados em grandes volumes de dados que podem ser adaptados para múltiplas tarefas.

Características:
• Pré-treinados em dados internet-scale
• Adaptáveis via prompt, fine-tuning ou RAG
• Um modelo → múltiplas tarefas
• Exemplos: Claude, Llama, Titan, Jurassic
Large Language Models (LLMs)Texto

Foundation Models especializados em linguagem natural. Processam e geram texto.

Características:
• Treinados em corpus de texto massivo
• Entendem e geram linguagem natural
• Bilhões de parâmetros
• Exemplos: Claude (Anthropic), GPT, Llama (Meta)
Modelos MultimodaisMulti-input

Processam e geram múltiplos tipos de conteúdo (texto + imagem + áudio + vídeo).

Características:
• Input/output em múltiplas modalidades
• Entendem contexto cross-modal
• Exemplos: Claude 3 (texto+imagem), Amazon Nova
Diffusion ModelsImagem

Geram imagens a partir de texto (text-to-image). Aprendem a remover ruído progressivamente.

Características:
• Text-to-image, image-to-image
• Processo iterativo de denoising
• Exemplos: Stable Diffusion, DALL-E, Amazon Titan Image
Agentic AIAgentes

Sistemas de IA que podem planejar, executar ações e usar ferramentas autonomamente para completar tarefas complexas.

Características:
• Planejamento e raciocínio multi-step
• Uso de ferramentas (APIs, databases)
• Tomada de decisão autônoma
• AWS: Bedrock Agents, Strands Agents SDK

Conceitos Técnicos Fundamentais

TokensUnidade

Unidade básica de processamento de texto em LLMs. Não é exatamente uma palavra.

• 1 token ≈ 4 caracteres em inglês
• 1 token ≈ ¾ de uma palavra
• "Inteligência" pode ser 2-3 tokens
• Impacta: custo, latência, context window
• Tokenização varia por modelo
EmbeddingsVetores

Representação numérica (vetor) de texto/imagem em espaço multidimensional. Captura significado semântico.

• Texto → vetor de números [0.2, -0.5, 0.8, ...]
• Textos similares = vetores próximos
• Base para busca semântica
• Usado em RAG e recomendações
• Amazon Titan Embeddings
Context WindowLimite

Quantidade máxima de tokens que o modelo pode processar em uma única interação (input + output).

• Medido em tokens (ex: 200K tokens)
• Inclui: prompt + contexto + resposta
• Maior window = mais contexto disponível
• Trade-off: custo e latência aumentam
• Claude: até 200K tokens
Vector DatabasesArmazenamento

Bancos de dados otimizados para armazenar e buscar embeddings (vetores) por similaridade.

• Busca por similaridade (não por keyword)
• Essencial para RAG
• AWS: OpenSearch Serverless, Aurora, Neptune
• Operação: nearest neighbor search
• Índices: HNSW, IVF, etc.
Inferência em GenAIGeração

Processo de gerar output a partir de um prompt. Controlado por parâmetros de geração.

Parâmetros importantes:
• Temperature: criatividade (0=determinístico, 1=criativo)
• Top-p: nucleus sampling (diversidade)
• Top-k: limita vocabulário considerado
• Max tokens: tamanho máximo da resposta
• Stop sequences: quando parar de gerar
Token-Based PricingCusto

Modelo de cobrança baseado no número de tokens processados (input + output).

• Input tokens: custo por token enviado
• Output tokens: custo por token gerado
• Output geralmente mais caro que input
• Bedrock: pay-per-use ou Provisioned Throughput
• Otimização: prompts concisos, max_tokens

Capacidades e Limitações de LLMs

Entender as limitações é crucial para o exame e para uso responsável:

LimitaçãoDescriçãoMitigação
Alucinações (Hallucinations)Modelo gera informações falsas com alta confiança, inventando fatos, citações ou dadosRAG (grounding com dados reais), Guardrails, validação humana, citação de fontes
Knowledge CutoffModelo só conhece dados até a data de treinamento — não sabe eventos recentesRAG com dados atualizados, Knowledge Bases, busca em tempo real
Comportamento EstocásticoMesma pergunta pode gerar respostas diferentes (não-determinístico)Temperature = 0, seed fixo (quando disponível), validação de output
Viés (Bias)Modelo reflete vieses presentes nos dados de treinamento (gênero, raça, cultura)SageMaker Clarify, Bedrock Guardrails, avaliação de fairness, dados diversos
Limite de ContextoNão pode processar mais tokens que o context window permiteChunking, summarização, RAG seletivo, modelos com window maior
Raciocínio MatemáticoPode errar cálculos complexos e raciocínio lógico multi-stepChain-of-thought prompting, ferramentas externas (calculadora), validação
Falta de Conhecimento ProprietárioNão conhece dados internos da empresa (documentos, políticas, produtos)RAG com Knowledge Bases, fine-tuning com dados corporativos

🎯 Para o exame: "Como reduzir alucinações?" → RAG (Retrieval-Augmented Generation) com Knowledge Bases. "Como adicionar dados atuais?" → RAG. "Como controlar conteúdo?" → Guardrails.

Amazon Bedrock — Serviço Principal de GenAI

Serviço gerenciado que oferece acesso a Foundation Models de múltiplos provedores via API. É o serviço mais cobrado no exame para GenAI.

ComponenteFunçãoDetalhes
Model AccessAcesso a FMs de múltiplos provedoresAnthropic (Claude), Meta (Llama), AI21, Cohere, Stability AI, Amazon (Titan, Nova)
Knowledge BasesRAG gerenciadoConecta FMs a dados corporativos (S3, web crawlers). Chunking automático, embeddings, vector store
AgentsAgentes autônomos com açõesLLM + ferramentas (APIs, Lambda). Planejam e executam tarefas multi-step automaticamente
GuardrailsControle de conteúdo e segurançaFiltros de tópicos, PII, palavras proibidas, grounding check. Aplica a qualquer FM
Fine-tuningCustomização de modelosAdaptar FM com dados próprios. Continued pre-training ou instruction fine-tuning
Model EvaluationAvaliar e comparar modelosBenchmarks automáticos e avaliação humana. Comparar FMs para seu caso de uso
Provisioned ThroughputCapacidade reservadaThroughput garantido para workloads de produção com alta demanda
Bedrock StudioInterface visual para prototiparTestar prompts, comparar modelos, criar aplicações sem código

💡 Conceito-chave RAG: Retrieval-Augmented Generation = buscar informações relevantes em uma base de conhecimento e incluí-las no prompt antes de gerar a resposta. Reduz alucinações e adiciona conhecimento atualizado/proprietário.

Outros Serviços AWS de IA Generativa

SageMaker JumpStartModel Hub

Hub de modelos pré-treinados para deploy com um clique. Inclui Foundation Models e modelos de ML clássico.

• Deploy de FMs em sua conta (infraestrutura própria)
• Fine-tuning com seus dados
• Mais controle sobre infraestrutura
• Modelos: Llama, Falcon, Mistral, etc.
• Diferença do Bedrock: você gerencia a infra
Amazon Q DeveloperCódigo

Assistente de IA para desenvolvedores. Gera código, explica, debugga e transforma aplicações.

• Autocompletar código (IDE)
• Chat para perguntas técnicas
• Transformação de código (Java 8→17)
• Scan de segurança
• Integração: VS Code, JetBrains, CLI
Amazon Q BusinessEnterprise

Assistente de IA para funcionários. Responde perguntas usando dados internos da empresa.

• Conecta a 40+ data sources
• Respeita permissões existentes (ACL)
• Busca em documentos corporativos
• Summarização, Q&A, geração
• Não requer conhecimento de ML
PartyRockPlayground

Playground gratuito para experimentar GenAI. Criar apps simples com prompts sem código e sem conta AWS.

• Sem necessidade de conta AWS
• Interface drag-and-drop
• Criar apps com prompts
• Educacional e prototipagem rápida
• Powered by Bedrock
Bedrock AgentCoreInfraestrutura

Infraestrutura gerenciada para deploy e operação de agentes de IA em produção.

• Runtime gerenciado para agentes
• Observabilidade e monitoramento
• Gerenciamento de sessões e memória
• Identity e access management
• Escala automática
Amazon NovaAmazon FM

Família de Foundation Models da própria Amazon, disponíveis no Bedrock.

Modelos:
• Nova Micro: texto, mais rápido e barato
• Nova Lite: multimodal (texto+imagem+vídeo)
• Nova Pro: multimodal, melhor equilíbrio
• Nova Premier: mais capaz (complexo)
• Nova Canvas: geração de imagens
• Nova Reel: geração de vídeos
