Banco de Dados: VPC + EC2 + RDS com Conditions e Mappings

Adicione um banco de dados RDS à infraestrutura com subnets dedicadas, conditions para multi-ambiente e mappings regionais.

1. Conditions e Mappings

ConditionsLógica

Conditions controlam a criação condicional de recursos baseado em parâmetros.

Conditions:
  IsProd:
    !Equals [!Ref Environment, prod]
  IsNotProd:
    !Not [!Equals [!Ref Environment, prod]]
  CreateReadReplica:
    !And
      - !Equals [!Ref Environment, prod]
      - !Equals [!Ref EnableReplica, "true"]
  IsUsEast1:
    !Equals [!Ref "AWS::Region", us-east-1]

# Uso em Resources
Resources:
  ReadReplica:
    Type: AWS::RDS::DBInstance
    Condition: CreateReadReplica
    Properties:
      SourceDBInstanceIdentifier: !Ref Database
      DBInstanceClass: db.t3.medium
MappingsLookup

Mappings são tabelas de lookup estáticas para valores por região ou ambiente.

Mappings:
  EnvironmentConfig:
    dev:
      InstanceType: db.t3.micro
      MultiAZ: "false"
      BackupRetention: 1
      AllocatedStorage: 20
    staging:
      InstanceType: db.t3.small
      MultiAZ: "false"
      BackupRetention: 3
      AllocatedStorage: 50
    prod:
      InstanceType: db.r5.large
      MultiAZ: "true"
      BackupRetention: 7
      AllocatedStorage: 100

# Uso com FindInMap
Resources:
  Database:
    Properties:
      DBInstanceClass: !FindInMap
        - EnvironmentConfig
        - !Ref Environment
        - InstanceType
      MultiAZ: !FindInMap
        - EnvironmentConfig
        - !Ref Environment
        - MultiAZ

2. DBSubnetGroup e RDS Instance

RDSBanco de Dados

RDS requer um DBSubnetGroup com pelo menos 2 subnets em AZs diferentes para alta disponibilidade.

  PrivateSubnet2:
    Type: AWS::EC2::Subnet
    Properties:
      VpcId: !Ref VPC
      CidrBlock: "10.0.11.0/24"
      AvailabilityZone: !Select [1, !GetAZs ""]
      Tags:
        - Key: Name
          Value: !Sub "${AWS::StackName}-private-2"

  DatabaseSubnetGroup:
    Type: AWS::RDS::DBSubnetGroup
    Properties:
      DBSubnetGroupDescription: "Subnets para RDS"
      SubnetIds:
        - !Ref PrivateSubnet1
        - !Ref PrivateSubnet2
      Tags:
        - Key: Name
          Value: !Sub "${AWS::StackName}-db-subnet-group"

  DatabaseSG:
    Type: AWS::EC2::SecurityGroup
    Properties:
      GroupDescription: "Security Group para RDS"
      VpcId: !Ref VPC
      SecurityGroupIngress:
        - IpProtocol: tcp
          FromPort: 3306
          ToPort: 3306
          SourceSecurityGroupId: !Ref WebServerSG
          Description: "MySQL apenas do Web Server"

  Database:
    Type: AWS::RDS::DBInstance
    DeletionPolicy: Snapshot
    UpdateReplacePolicy: Snapshot
    Properties:
      DBInstanceIdentifier: !Sub "${AWS::StackName}-db"
      Engine: mysql
      EngineVersion: "8.0"
      DBInstanceClass: !FindInMap [EnvironmentConfig, !Ref Environment, InstanceType]
      AllocatedStorage: !FindInMap [EnvironmentConfig, !Ref Environment, AllocatedStorage]
      StorageType: gp3
      MasterUsername: admin
      MasterUserPassword: !Ref DBPassword
      DBSubnetGroupName: !Ref DatabaseSubnetGroup
      VPCSecurityGroups:
        - !Ref DatabaseSG
      MultiAZ: !FindInMap [EnvironmentConfig, !Ref Environment, MultiAZ]
      BackupRetentionPeriod: !FindInMap [EnvironmentConfig, !Ref Environment, BackupRetention]
      DeletionProtection: !If [IsProd, true, false]
      StorageEncrypted: true
      Tags:
        - Key: Name
          Value: !Sub "${AWS::StackName}-database"
        - Key: Environment
          Value: !Ref Environment

Outputs:
  DatabaseEndpoint:
    Description: "Endpoint do RDS"
    Value: !GetAtt Database.Endpoint.Address
    Export:
      Name: !Sub "${AWS::StackName}-DBEndpoint"
  DatabasePort:
    Description: "Porta do RDS"
    Value: !GetAtt Database.Endpoint.Port
