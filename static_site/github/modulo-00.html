🐙 Git & GitHub — Módulo 00

Configuração de Conta

Criação de conta GitHub, SSH keys, 2FA, perfil profissional. Antes de versionar código, configure seu ambiente corretamente.

1. Configuração Inicial do Git

git configEssencial

Define identidade e preferências globais do Git.

# Identidade (obrigatório)
git config --global user.name "Seu Nome"
git config --global user.email "seu@email.com"

# Preferências úteis
git config --global init.defaultBranch main
git config --global core.editor "code --wait"
git config --global pull.rebase true

# Verificar configurações
git config --list
git config --global --list

2. Chave SSH e Autenticação

ssh-keygenAutenticação

Gera par de chaves para autenticação sem senha no GitHub.

# Gerar chave SSH (Ed25519 recomendado)
ssh-keygen -t ed25519 -C "seu@email.com"

# Iniciar o ssh-agent
eval "$(ssh-agent -s)"
ssh-add ~/.ssh/id_ed25519

# Copiar chave pública para adicionar no GitHub
cat ~/.ssh/id_ed25519.pub

# Testar conexão
ssh -T git@github.com
# Hi usuario! You've successfully authenticated
