GitHub: Projects, Pages, Environments e Segurança

GitHub Projects, Pages, Environments, Branch Protection, CODEOWNERS, Dependabot. Recursos avançados para gestão de projetos e segurança.

1. Branch Protection Rules

Branch ProtectionSegurança

Proteja branches importantes contra push direto e merges sem review.

# Settings → Branches → Add rule
# Branch name pattern: main

# Regras recomendadas:
✅ Require a pull request before merging
  ✅ Require approvals (mínimo 1)
  ✅ Dismiss stale pull request approvals
✅ Require status checks to pass
  ✅ Require branches to be up to date
  → Selecione: CI Pipeline, Tests
✅ Require conversation resolution
✅ Require signed commits (opcional)
✅ Do not allow bypassing the above settings

# Resultado: ninguém faz push direto na main
# Todo código passa por PR + CI + Review
CODEOWNERSGovernança

Define responsáveis automáticos por review.

# .github/CODEOWNERS

# Donos globais (review em tudo)
* @tech-lead @senior-dev

# Por diretório
/src/auth/     @security-team
/infra/        @devops-team
/docs/         @tech-writer

# Por extensão
*.tf           @devops-team
*.yml          @devops-team
*.test.ts      @qa-team

# Resultado: PRs que tocam esses arquivos
# automaticamente pedem review dos owners
EnvironmentsDeploy

Controle deploys com aprovações e secrets por ambiente.

# Settings → Environments

# Ambiente: production
# - Required reviewers: @tech-lead
# - Wait timer: 5 minutes
# - Deployment branches: main only
# - Secrets: AWS_ROLE_ARN, CF_DIST_ID

# Ambiente: staging
# - No protection rules
# - Deployment branches: develop, release/*
# - Secrets: AWS_ROLE_ARN_STAGING

# No workflow:
jobs:
  deploy:
    environment: production  # ← ativa proteções
    runs-on: ubuntu-latest

GitHub PagesDeploy

Hospede sites estáticos gratuitamente.

# Settings → Pages

# Source: GitHub Actions (recomendado)
# ou
# Source: Deploy from branch (gh-pages)

# Workflow para Pages:
# .github/workflows/pages.yml
name: Deploy to GitHub Pages
on:
  push:
    branches: [main]
jobs:
  deploy:
    runs-on: ubuntu-latest
    permissions:
      pages: write
      id-token: write
    environment:
      name: github-pages
    steps:
      - uses: actions/checkout@v4
      - uses: actions/upload-pages-artifact@v3
        with:
          path: './dist'
      - uses: actions/deploy-pages@v4
