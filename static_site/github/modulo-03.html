🐙 Git & GitHub — Módulo 03

Colaboração: Fork, Pull Request e Code Review

Fork, Pull Request, Code Review, Issues, Templates. Aprenda o fluxo profissional de contribuição em projetos.

1. Fork e Contribuição

Fork WorkflowColaboração

Fluxo completo para contribuir em projetos open source.

# 1. Fork no GitHub (botão Fork)

# 2. Clone do seu fork
git clone git@github.com:SEU-USER/projeto.git
cd projeto

# 3. Adicione o repositório original como upstream
git remote add upstream git@github.com:ORIGINAL/projeto.git

# 4. Crie branch para sua contribuição
git checkout -b fix/corrige-typo

# 5. Faça suas mudanças e commit
git add .
git commit -m "fix: corrige typo na documentação"

# 6. Push para seu fork
git push origin fix/corrige-typo

# 7. Abra Pull Request no GitHub (origin → upstream)

# 8. Manter fork atualizado
git fetch upstream
git checkout main
git merge upstream/main
git push origin main

2. Pull Requests e Code Review

Pull RequestGitHub

Boas práticas para criar PRs eficientes.

# Título claro e descritivo
feat: implementa autenticação OAuth2

# Descrição com template:
## O que foi feito
- Implementa login com Google
- Adiciona middleware de auth

## Como testar
1. Rodar `npm run dev`
2. Acessar /login
3. Clicar em "Login com Google"

## Screenshots
(se aplicável)

Closes #42
Code ReviewBoas Práticas

Checklist para revisar código de colegas.

# O que verificar no Code Review:

✅ Código funciona conforme descrito?
✅ Testes foram adicionados/atualizados?
✅ Sem código duplicado?
✅ Nomes de variáveis claros?
✅ Sem secrets hardcoded?
✅ Performance aceitável?
✅ Documentação atualizada?

# Tipos de comentário:
# 🔴 Blocker — precisa corrigir
# 🟡 Suggestion — melhoria opcional
# 💬 Question — dúvida/discussão
IssuesGitHub

Organize trabalho com Issues e Labels.

# Criar Issue com template:
## Descrição do Bug
Ao clicar em "Salvar", nada acontece.

## Passos para Reproduzir
1. Acessar /settings
2. Alterar nome
3. Clicar "Salvar"

## Comportamento Esperado
Dados salvos com sucesso.

## Ambiente
- Browser: Chrome 120
- OS: Ubuntu 22.04

# Labels úteis:
# bug, enhancement, documentation
# good first issue, help wanted
GitHub CLIProdutividade

Gerencie PRs e Issues pelo terminal.

# Instalar: https://cli.github.com
gh auth login

# Pull Requests
gh pr create --title "feat: login"
gh pr list
gh pr checkout 42
gh pr merge 42 --squash

# Issues
gh issue create --title "Bug: login"
gh issue list --label "bug"
gh issue close 42

# Repos
gh repo create meu-projeto --public
gh repo clone user/repo
