Resolução de Conflitos

Identificar, resolver e prevenir conflitos de merge. Conflitos acontecem quando duas pessoas editam o mesmo trecho — saber resolvê-los é essencial.

1. Entendendo e Resolvendo Conflitos

Conflito de MergeEssencial

Anatomia de um conflito e como resolver.

# Quando o Git não consegue resolver automaticamente:
<<<<<<< HEAD
const titulo = "Versão da branch atual";
=======
const titulo = "Versão da branch incoming";
>>>>>>> feature/nova-funcionalidade

# Resolução:
# 1. Edite o arquivo — escolha uma versão ou combine
const titulo = "Versão final combinada";

# 2. Remova os marcadores (<<<<, ====, >>>>)

# 3. Adicione e commite
git add arquivo-resolvido.js
git commit -m "fix: resolve conflito no título"

# Ferramentas visuais:
git mergetool              # abre ferramenta configurada
# VS Code: aceitar current/incoming/both

Abortar e RecomeçarSegurança

Quando a resolução fica complexa demais.

# Abortar merge em andamento
git merge --abort

# Abortar rebase em andamento
git rebase --abort

# Voltar ao estado anterior
git reset --hard HEAD

# Ver estado antes do conflito
git stash
git log --oneline --graph
