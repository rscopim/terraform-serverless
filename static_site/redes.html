12 Módulos Progressivos

Módulo 01Iniciante

Fundamentos de Redes

Tipos de rede, topologias, meios de transmissão, dispositivos.
Módulo 02Iniciante

Modelo OSI e TCP/IP

7 camadas OSI, TCP/IP, TCP vs UDP, 3-way handshake, portas.
Módulo 03Intermediário

Endereçamento IP e Sub-redes

IPv4, CIDR, subnetting, IPs privados/públicos, IPv6.
Módulo 04Intermediário

Comandos de Diagnóstico

ping, traceroute, nslookup, dig, netstat, ss, nmap, tcpdump, ip.
Módulo 05Intermediário

Switches e VLANs

Switching, tabela MAC, VLANs, trunking 802.1Q, STP/RSTP.
Módulo 06Avançado

Roteamento

Rotas estáticas, OSPF, BGP, comparação de protocolos.
Módulo 07Avançado

Segurança de Redes

ACLs, iptables, ufw, IDS/IPS, boas práticas.
Módulo 08Avançado

Serviços de Rede

DNS, DHCP, NAT/PAT, VPN (IPSec, WireGuard).
Módulo 09Especialista

Automação de Redes

Python (Netmiko, Paramiko), Ansible para redes.
Módulo 10Especialista

SD-WAN

Conceitos, componentes, políticas, SASE.
Módulo 11Especialista

Observabilidade

SNMP, Prometheus, Grafana, Zabbix, NetFlow.
Módulo 12Especialista

Design de Redes

3-tier, spine-leaf, alta disponibilidade, documentação.
Pré-requisitos: Computador com acesso à internet. Cisco Packet Tracer (gratuito) ou GNS3 para labs. Certificações alinhadas: CompTIA Network+, CCNA 200-301, CCNP ENCOR.
